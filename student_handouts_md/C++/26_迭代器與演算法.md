## Section II. 今天的學習方式

1. 看到演算法時先標示：
   ```text
   輸入 iterator 類別
   是否修改元素
   輸出位置
   回傳值
   ```
2. 看到範圍時讀成：
   ```text
   [first, last)
   ```
3. 任何解參考前先確認：
   ```cpp
   iterator != last
   ```
4. 需要跨容器泛化時使用 iterator，不依賴 index。
5. 對 list 等非 random access iterator 使用：
   ```cpp
   next()
   advance()
   distance()
   ```
6. 複製到空 vector 時使用：
   ```cpp
   back_inserter(destination)
   ```
7. 查詢操作優先使用 const iterator。
8. 修改容器結構後重新檢查 iterator 是否仍有效。
9. 集合演算法前先確認輸入已排序。
10. 所有合法完整程式使用嚴格 C++17 選項檢查。

| 語法 | 用途 |
| --- | --- |
| `container.begin()` | 第一個元素位置 |
| `container.end()` | 最後元素之後 |
| `container.cbegin()` | 唯讀第一個位置 |

| `distance(first, last)` | 計算距離 |
| `advance(iterator, n)` | 原地移動 iterator |

![Iterator 不一定是真正指標](images/lesson_26/CPP_Lesson_26_img03_iterator_not_always_pointer.png)

```cpp

using namespace std;

        10,
        20,
        30
    };

        auto iterator =
            values.cbegin();
        iterator !=
            values.cend();
        ++iterator

        cout << *iterator
             << " ";
    }

    cout << '\n';

    return 0;
}
```

## Section XIII. Const Iterator Object

以下不同：

```cpp
const auto iterator =
    values.begin();
```

Iterator 物件本身不能重新指向其他位置，但若它指向可修改元素，仍可能透過它修改元素。

因此「iterator 本身 const」不等於「指向 const 元素」。

#include <iostream>
#include <iterator>
#include <list>
using namespace std;

    list<int> values{
        100,
        4,

        2,

        next(

#include <iostream>
#include <iterator>
#include <vector>
using namespace std;

        -2,
        3,

        2,
        -1,
        3
    };

        source.cbegin(),
        source.cend(),
        back_inserter(
            positiveValues

        }
    );

        positiveValues.cbegin(),

# Part AE：Mermaid 流程圖

## Section LXXXV. 迭代器與演算法流程圖

### 1. Iterator 走訪

```mermaid
flowchart TD
    A[iterator 等於 first] --> B{iterator 等於 last 嗎}
    B -- 是 --> C[完成]
    B -- 否 --> D[解參考目前元素]
    D --> E[處理元素]
    E --> F[遞增 iterator]
    F --> B
```

### 2. 選擇 Iterator 移動方式

```mermaid
flowchart TD
    A[需要移動 n 個位置] --> B{Random access iterator 嗎}
    B -- 是 --> C[可使用 iterator 加 n]
    B -- 否 --> D[使用 next 或 advance]
    D --> E{需要保留原 iterator 嗎}
    E -- 是 --> F[next]
    E -- 否 --> G[advance]
```

### 3. Output Iterator

```mermaid
flowchart TD
    A[演算法產生一個結果] --> B{目的容器已有空間嗎}
    B -- 是 --> C[寫入 destination begin]
    B -- 否 --> D{在尾端加入嗎}
    D -- 是 --> E[back_inserter]
    D -- 否 --> F{在前端加入嗎}
    F -- 是 --> G[front_inserter]
    F -- 否 --> H[inserter]
```

### 4. Algorithm Pipeline

```mermaid
flowchart TD
    A[原始資料] --> B[copy_if 過濾]
    B --> C[transform 轉換]
    C --> D[sort 排序]
    D --> E[unique 加 erase 去重]
    E --> F[accumulate 累加]
    F --> G[輸出結果]
```

### 5. Safe Erase Loop

```mermaid
flowchart TD
    A[iterator 指向目前元素] --> B{到 end 嗎}
    B -- 是 --> C[完成]
    B -- 否 --> D{要刪除嗎}
    D -- 是 --> E[iterator 等於 erase 回傳值]
    D -- 否 --> F[遞增 iterator]
    E --> B
    F --> B
```

### 6. Iterator Category

```mermaid
flowchart TD
    A[Input] --> B[Forward]
    B --> C[Bidirectional]
    C --> D[Random Access]
    D --> E[Contiguous C++20]
    A --> F[Output 為另一條能力方向]
```

### 7. 集合演算法

```mermaid
flowchart TD
    A[兩個輸入範圍] --> B{都已依同規則排序嗎}
    B -- 否 --> C[先排序或不能安全使用]
    B -- 是 --> D[set_union set_intersection merge]
    D --> E[使用 output iterator 保存結果]
```

### 8. Iterator Safety

```mermaid
flowchart TD
    A[準備使用 iterator] --> B[確認所屬容器]
    B --> C[確認未到 end]
    C --> D[確認容器結構未改變]
    D --> E[確認 iterator category 足夠]
    E --> F[安全讀寫元素]
```
