# Lesson 21：Classes and Objects 類別與物件

> 這堂課的重點：把「資料」與「操作這些資料的行為」整理成同一個自訂型態。你會學習 `class`、object、data member、member function、`public`、`.` 成員存取運算子、建立多個物件、物件狀態、類別內外的成員函式定義，以及如何把物件放進函式、陣列與 `vector` 中使用。

## Section II. 今天的學習方式

1. 看到一個類別時，先標出：
   ```text
   類別名稱
   成員資料
   成員函式
   public 區域
   ```
2. 看到一個物件時，先問：
   ```text
   這個物件是哪一個類別的實例？
   ```
3. 看到：
   ```cpp
   student.score
   ```
   要讀成：
   ```text
   student 這個物件的 score 成員
   ```
4. 看到：
   ```cpp
   student.printInfo()
   ```
   要讀成：
   ```text
   呼叫 student 這個物件的 printInfo 成員函式
   ```
5. 每建立一個新物件，都先想：
   ```text
   它有自己獨立的一份成員資料
   ```
6. 類別設計先從一句話開始：
   ```text
   這個類別代表什麼？
   ```
7. 接著列出：
   ```text
   它需要保存哪些資料？
   它需要做哪些事情？
   ```
8. 本章為了專注 class / object 基礎，許多資料成員會先放在 `public:`。
9. 不要把本章的 `public` 資料成員當成大型專案的最終設計方式；完整封裝會在下一章整理。
10. 遇到成員函式時，確認它正在操作「哪一個物件」的資料。
11. 使用 `vector<物件>` 時，要同時追蹤迴圈位置與目前物件。
12. 完整合法範例使用嚴格 C++17 選項檢查。

## Section III. 核心語法對照

| 語法 | 用途 |
| --- | --- |
| `class Student { ... };` | 定義 `Student` 類別 |
| `Student student;` | 建立一個 `Student` 物件 |
| `public:` | 後方成員可以從類別外直接存取 |
| `int score;` | 成員資料 data member |
| `void printInfo() { ... }` | 成員函式 member function |
| `student.score` | 存取物件的資料成員 |

| `vector<Student>` | 儲存多個 `Student` 物件 |
| `Player makePlayer()` | 一般函式回傳物件 |
| `void printStudent(Student student)` | 將物件以傳值方式傳入函式 |

# Part D：成員函式 Member Functions

## Section XVI. 把行為放進類別

只有資料：

```cpp
class Counter {
public:
    int value;
};
```

如果 `Counter` 應該可以自己增加數值，可以加入：

```cpp
void increment() {
    ++value;
}
```

變成：

```cpp
class Counter {
public:
    int value;

    void increment() {
        ++value;
    }
};
```

## Section XVII. 呼叫成員函式

```cpp
counter.increment();
```

和一般函式：

```cpp
increment();
```

不同。

前者明確表示：

```text
讓 counter 這個物件執行 increment()
```

## Section XVIII. 成員函式可以存取自己的資料

```cpp
// VALIDATE
#include <iostream>
using namespace std;

class Counter {
public:
    int value;

    void increment() {
        ++value;
    }

    void print() {
        cout << value << '\n';
    }
};

int main() {
    Counter counter;
    counter.value = 10;

    counter.increment();
    counter.increment();
    counter.print();

    return 0;
}
```

輸出：

```text
12
```

在：

```cpp
void increment() {
    ++value;
}
```

裡面的 `value` 指的是：

```text
目前呼叫這個成員函式的物件自己的 value
```

## Section XX. 有參數的成員函式

成員函式與一般函式一樣，也可以有參數：

## Section XXI. 完整 Counter 範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

class Counter {
public:
    int value;

    void reset() {
        value = 0;
    }

    void increment() {
        ++value;
    }

    void increaseBy(int amount) {
        value += amount;
    }

    int getValue() {
        return value;
    }
};

int main() {
    Counter counter;
    counter.value = 7;

    counter.increment();
    counter.increaseBy(4);

    cout << counter.getValue() << '\n';

    counter.reset();
    cout << counter.getValue() << '\n';

    return 0;
}
```

輸出：

```text
12
0
```

> 本章的 `getValue()` 只是示範「成員函式可以回傳值」。下一章才會正式從封裝角度整理 getter / setter。

## Section XXVII. 加入最低值限制

如果不希望生命值小於 `0`：

```cpp
void takeDamage(int damage) {
    hp -= damage;

    if (hp < 0) {
        hp = 0;
    }
}
```

這樣「受到傷害後如何更新 hp」的規則就放在 `Player` 裡。

---

## Section XXVIII. 完整 Player 範例

<p align="center">
  <img
    src="images/lesson_21/CPP_Lesson_21_img14_player_state_rule.png"
    alt="Player：成員函式保護狀態規則"
    width="700">
</p>

```cpp
// VALIDATE
#include <iostream>
#include <string>
using namespace std;

class Player {
public:
    string name;
    int hp;

    void takeDamage(int damage) {
        if (damage < 0) {
            return;
        }

        hp -= damage;

        if (hp < 0) {
            hp = 0;
        }
    }

    void heal(int amount) {
        if (amount > 0) {
            hp += amount;
        }
    }

    bool isAlive() {
        return hp > 0;
    }
};

int main() {
    Player player;

    player.name = "Knight";
    player.hp = 100;

    player.takeDamage(35);
    cout << player.hp << '\n';

    player.heal(10);
    cout << player.hp << '\n';

    player.takeDamage(100);
    cout << player.hp << '\n';
    cout << player.isAlive() << '\n';

    return 0;
}
```

## Section XXX. 最重要的基本差異

若沒有自己寫 access specifier：

```cpp
struct Example {
    int value;
};
```

`value` 預設是：

```text
public
```

但：

```cpp
class Example {
    int value;
};
```

`value` 預設是：

```text
private
```

## Section XXXI. 本章為什麼一直寫 `public:`？

因為：

```cpp
class Student {
public:
    string name;
};
```

才能在類別外直接：

```cpp
student.name = "Amy";
```

如果寫成：

```cpp
class Student {
    string name;
};
```

外部直接存取 `name` 會失敗。

## Section XXXII. `class` 和 `struct` 不只是「有沒有函式」

錯誤觀念：

```text
struct 只能放資料
class 才能放函式
```

這在 C++ 中不正確。

兩者都可以有：

```text
成員資料
成員函式
```

本階段可以先使用以下習慣：

```text
struct → 偏向單純資料集合
class  → 偏向資料 + 行為的物件模型
```

這是設計習慣，不是「struct 不能有函式」的語法限制。

# Part S：常見錯誤提醒

## Section LXXII. 常見錯誤

1. 把 `class` 名稱與物件名稱混在一起。
2. 定義類別後忘記真正建立物件。
3. 類別定義最後忘記分號。
4. 成員資料宣告後忘記分號。
5. 使用物件成員時忘記 `.`。
6. 把 `student.score` 寫成 `student score`。
7. 把 `student.print()` 寫成 `Student.print()`，但 `print()` 是一般非 static 成員函式。
8. `class` 中忘記 `public:`，卻從外部直接存取成員。
9. 誤以為 `class` 預設成員是 `public`。
10. 誤以為 `struct` 不能有成員函式。
11. 誤以為兩個相同類別的物件會共用一般成員資料。
12. 修改 `first.score` 卻以為 `second.score` 也會一起改變。
13. 呼叫成員函式時忘記 `()`。
14. 成員函式宣告有參數，但呼叫時漏掉引數。
15. 成員函式回傳 `bool`，卻沒有在所有必要路徑提供正確結果。
16. 類別外定義成員函式時忘記 `ClassName::`。
17. 類別外定義的函式名稱與類別內宣告不一致。
18. 類別內宣告參數型態與類別外定義不同。
19. 物件傳值進函式後，期待修改副本會改到原物件。
20. `vector<Student>` 中把 `students[index]` 誤以為是 `int` 索引本身，而不是一個 `Student` 物件。
21. range-based for 使用傳值副本修改資料，卻期待原 `vector` 改變。
22. 多層成員存取時漏掉其中一個 `.`，例如把 `player.position.x` 寫錯。
23. 類別包含太多互不相關的資料與函式。
24. 成員名稱太模糊，例如大量使用 `a`、`b`、`x1`，使物件意義不清楚。
25. 為了「物件導向」而把所有一般函式強行塞進類別。
26. 在尚未設定成員資料前就使用其值。
27. 忘記驗證會改變物件狀態的輸入，例如負數傷害或負數存款。
28. 把類別定義寫在 `main()` 中後又想在其他函式使用該型態，造成作用域問題。
29. 把「類別」想成已經存在的一筆資料；其實還需要建立物件。
30. 還沒學封裝前就急著混入 constructor、destructor、inheritance 等太多新概念。

# Part T：Mermaid 流程圖

## Section LXXIII. 類別與物件流程圖

### 1. 從類別到物件

```mermaid
flowchart TD
    A[定義 class] --> B[描述成員資料]
    B --> C[描述成員函式]
    C --> D[建立 object]
    D --> E[設定物件狀態]
    E --> F[呼叫物件行為]
```

### 2. 成員存取

```mermaid
flowchart LR
    A[物件 student] --> B[使用點運算子]
    B --> C[score 成員]
    B --> D[passed 成員函式]
```

### 3. 多個物件

```mermaid
flowchart TD
    A[Student 類別] --> B[first 物件]
    A --> C[second 物件]
    B --> D[first 自己的 name 與 score]
    C --> E[second 自己的 name 與 score]
```

### 4. 呼叫成員函式

```mermaid
flowchart TD
    A[counter.increment] --> B[進入 counter 的 increment]
    B --> C[讀取 counter.value]
    C --> D[value 加 1]
    D --> E[回到呼叫位置]
```

### 5. 修改物件狀態

```mermaid
flowchart TD
    A[目前 hp] --> B[呼叫 takeDamage]
    B --> C[hp 減少 damage]
    C --> D{hp 小於 0 嗎}
    D -- 是 --> E[hp 設為 0]
    D -- 否 --> F[保留目前 hp]
    E --> G[新狀態]
    F --> G
```

### 6. vector 中搜尋物件

```mermaid
flowchart TD
    A[從第一個物件開始] --> B{還有物件嗎}
    B -- 否 --> G[搜尋結束]
    B -- 是 --> C[取得目前 Student]
    C --> D{姓名符合嗎}
    D -- 是 --> E[處理目前物件]
    D -- 否 --> F[前往下一個]
    E --> G
    F --> B
```

### 7. 物件組合

```mermaid
flowchart TD
    A[Player 物件] --> B[name]
    A --> C[Position 物件]
    C --> D[x]
    C --> E[y]
```

### 8. 類別設計思考

```mermaid
flowchart TD
    A[這個類別代表什麼] --> B[需要保存哪些資料]
    B --> C[需要做哪些事情]
    C --> D{資料與行為相關嗎}
    D -- 是 --> E[放入同一類別]
    D -- 否 --> F[考慮拆成其他類別或一般函式]
```
