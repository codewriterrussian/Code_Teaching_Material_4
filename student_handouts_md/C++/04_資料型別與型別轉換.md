# Lesson 04：Data Types and Type Conversions 資料型別與型別轉換

> 這堂課的重點：理解資料型別會決定變數可以保存什麼資料、需要多少記憶體，以及資料在轉換時可能發生什麼變化。本章會介紹整數、浮點數、字元、布林值、常數與 `sizeof`，再學習隱性轉換、`static_cast` 和大括號初始化的窄化檢查。

> 本章的資料型別、常見大小、科學記號、字元編碼、`bool`、`sizeof`、`const` 與 `constexpr` 依照原始 C++ 入門講義整理。原講義只以 `static_cast<int>(ch)` 示範明確轉型；更完整的一般型別轉換規則會標示為「教材補充」。

# Part A：資料型別的用途

## Section IV. 什麼是資料型別？

資料型別告訴 C++：

```text
這一塊資料準備保存什麼
應如何解讀這些資料
可以進行哪些運算
```

例如：

```cpp
int age = 18;
double height = 175.5;
char grade = 'A';
bool passed = true;
```

---

## Section V. 型別影響哪些事情？

資料型別會影響：

1. 可以保存的資料種類。
2. 需要的記憶體空間。
3. 可以表示的數值範圍。
4. 數值精度。
5. 可以使用的運算方式。
6. 輸入與輸出時的解讀方式。

---

## Section VI. 選擇型別的第一步

可以先問：

```text
資料是否包含小數？
```

- 不包含小數：考慮整數型別。
- 包含小數：考慮浮點數型別。

再問：

```text
資料是否只有真或假？
```

- 是：使用 `bool`。

再問：

```text
資料是否只有一個字元？
```

- 是：使用 `char`。

# Part B：整數型別

## Section VII. 整數是什麼？

整數不包含小數部分，例如：

```text
-10
0
25
1000
```

C++ 常見整數型別：

```cpp
short
int
long
long long
```

---

## Section VIII. 整數型別範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    short smallNumber = 100;
    int studentCount = 30;
    long population = 23000000L;
    long long worldPopulation = 8000000000LL;

    cout << smallNumber << '\n';
    cout << studentCount << '\n';
    cout << population << '\n';
    cout << worldPopulation << '\n';

    return 0;
}
```

---

## Section IX. 常見大小

| 型別 | 常見大小 | 一般用途 |
| --- | ---: | --- |
| `short` | 2 位元組 | 較小範圍整數 |
| `int` | 4 位元組 | 最常使用的整數型別 |
| `long` | 4 或 8 位元組 | 大小依平台而定 |
| `long long` | 8 位元組 | 較大範圍整數 |



<p align="center">
  <img src="images/CPP_Lesson_04_img02_integer_types.png" alt="C++ 常見整數型別的大小與用途" width="700">
</p>> 表格中的大小是常見情況，不是所有電腦都固定相同。應使用 `sizeof` 檢查目前環境。

---

## Section X. 為什麼一般先選 `int`？

對大多數普通整數資料：

```cpp
int studentCount = 30;
int score = 95;
int age = 15;
```

`int` 通常最自然，也最容易閱讀。

不需要只因為數值目前很小，就一定改用 `short`。

---

## Section XI. `long` 的大小不固定

在不同平台：

```text
sizeof(long)
```

可能不同。

因此不應只看到 `long` 就假設它一定是八位元組。

---

## Section XII. 整數字面常數後綴

```cpp
long population = 23000000L;
long long worldPopulation = 8000000000LL;
```

後綴：

| 後綴 | 意義 |
| --- | --- |
| `L` | `long` |
| `LL` | `long long` |

本章不要求每個整數都加後綴；當常值很大或希望明確指定型別時，後綴可以幫助表達意圖。

# Part C：浮點數型別

## Section XIII. 浮點數是什麼？

浮點數可保存包含小數部分的數值，例如：

```text
3.14
36.5
168.75
-0.25
```

常見型別：

```cpp
float
double
```

---

## Section XIV. `float` 與 `double`

```cpp
float temperature = 36.5f;
double height = 168.75;
```

| 型別 | 常見大小 | 約略十進位有效位數 |
| --- | ---: | ---: |
| `float` | 4 位元組 | 約 6～7 位 |
| `double` | 8 位元組 | 約 15～16 位 |



<p align="center">
  <img src="images/CPP_Lesson_04_img03_float_vs_double.png" alt="float 與 double 的常見大小和精度比較" width="700">
</p>---

## Section XV. 小數常值預設是 `double`

```cpp
double first = 3.14;
float second = 3.14f;
```

沒有後綴的：

```cpp
3.14
```

預設為 `double`。

加上：

```cpp
f
```

可明確表示 `float`：

```cpp
3.14f
```

---

## Section XVI. 完整浮點數範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    float temperature = 36.5f;
    double height = 168.75;

    cout << "Temperature: "
         << temperature
         << '\n';

    cout << "Height: "
         << height
         << '\n';

    return 0;
}
```

---

## Section XVII. 精度不是顯示的小數位數

`float` 與 `double` 的精度，指的是能可靠表示的有效數字數量，不只是畫面顯示幾位小數。

例如：

```text
1234567
1.234567
0.0001234567
```

都涉及有效數字概念。

輸出格式控制會在後續章節介紹。

---

## Section XVIII. 浮點數通常是近似值

許多十進位小數無法以二進位浮點數精確表示。

因此：

```cpp
double value = 0.1;
```

在記憶體中的表示可能只是非常接近 `0.1`。

這不表示 C++ 計算錯誤，而是浮點表示方式的限制。

# Part G：`sizeof`

## Section XXXI. 查詢型別大小

基本語法：

```cpp
sizeof(資料型別)
```

例如：

```cpp
sizeof(int)
sizeof(double)
```

結果單位是：

```text
byte 位元組
```

---

## Section XXXII. 查詢變數大小

```cpp
int age = 15;

cout << sizeof(age);
```

結果等同目前環境中的：

```cpp
sizeof(int)
```

因為 `age` 的型別是 `int`。

## Section XXXIII. 完整 `sizeof` 範例

```cpp
// VALIDATE
#include <iostream>

int main() {
    cout << "short: "

         << " bytes\n";

    cout << "int: "

         << " bytes\n";

    cout << "long: "
         << sizeof(long)
         << " bytes\n";

    cout << "long long: "
         << sizeof(long long)
         << " bytes\n";

    cout << "float: "
         << sizeof(float)
         << " bytes\n";

    cout << "double: "
         << sizeof(double)
         << " bytes\n";

    cout << "char: "
         << sizeof(char)
         << " byte\n";

    cout << "bool: "
         << sizeof(bool)
         << " bytes\n";

    return 0;
}
```

可能結果：

```text

float: 4 bytes

bool: 1 byte
```

## Section XXXV. `sizeof(char)` 的特殊性

C++ 規定：

```cpp
sizeof(char)
```

一定是：

```text
1
```

這裡的 `1` 表示一個 C++ 位元組。

其他型別的大小都以這個單位計算。

---

## Section XXXVI. 整數大小關係

整數型別通常符合：

```text
sizeof(short)
<= sizeof(int)
<= sizeof(long)
<= sizeof(long long)
```

這不表示相鄰型別一定大小不同。

例如某個平台可能有：

```text
sizeof(long) == sizeof(long long)
```

## Section XLI. 為什麼通常不優先用 `#define`？

原始講義列出：

```cpp
#define DAYS_PER_WEEK 7
```

現代 C++ 通常更偏好：

```cpp
constexpr int DAYS_PER_WEEK = 7;
```

原因：

- 有明確資料型別。
- 編譯器較容易檢查。
- 遵守一般名稱與作用域規則。
- 除錯時資訊通常更清楚。

# Part I：型別轉換概念

## Section XLII. 什麼是型別轉換？

型別轉換表示：

```text
將一個型別的值
轉成另一個型別可以表示的值
```

例如：

```text
int → double
double → int
char → int
```

---

## Section XLIII. 兩種轉換方式

### 隱性轉換 Implicit Conversion

編譯器依照程式情境自動轉換：

```cpp
int count = 3;
double value = count;
```

`count` 的整數值會轉成 `double`。

### 明確轉換 Explicit Conversion

程式設計者明確寫出目標型別：

```cpp
double value = 3.8;
int result = static_cast<int>(value);
```

<p align="center">
  <img src="images/CPP_Lesson_04_img10_implicit_vs_explicit.png" alt="隱性型別轉換與 static_cast 明確轉換的差異" width="700">
</p>

---

## Section XLIV. 為什麼需要理解轉換？

轉換可能：

- 保留完整資料。
- 捨去小數部分。
- 降低精度。
- 改變顯示方式。
- 超出目標型別可表示範圍。

因此不能只看程式能否編譯。

---

# Part J：隱性數值轉換

## Section XLV. 整數轉浮點數

```cpp
int count = 3;
double value = count;
```

結果概念上：

```text
count = 3
value = 3.0
```

---

## Section XLVI. 完整範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    int count = 3;
    double value = count;

    cout << count << '\n';
    cout << value << '\n';

    return 0;
}
```

預設輸出可能都是：

```text
3
3
```

雖然顯示相同，兩個變數型別仍不同。

---

## Section XLVII. 浮點數轉整數

```cpp
double price = 19.95;
int whole = price;
```

轉換後：

```text
whole = 19
```

小數部分會向零方向捨去，不是四捨五入。

---

## Section XLVIII. 負數的情況

```cpp
double value = -3.9;
int result = value;
```

結果為：

```text
-3
```

<p align="center">
  <img src="images/CPP_Lesson_04_img11_truncate_toward_zero.png" alt="浮點數轉整數時向零方向捨去" width="700">
</p>

因為是向零方向捨去。

---

## Section XLIX. 精度降低

```cpp
double precise = 1.23456789012345;
float lessPrecise = precise;
```

`float` 通常能保存的有效位數較少，因此可能損失部分精度。

# Part K：使用 `static_cast`

## Section L. 基本語法

```cpp
static_cast<目標型別>(值)
```

例如：

```cpp
static_cast<int>(3.9)
static_cast<double>(5)
```

---

## Section LI. 明確浮點數轉整數

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    double value = 3.9;
    int result = static_cast<int>(value);

    cout << result << '\n';

    return 0;
}
```

輸出：

```text
3
```

---

## Section LII. 明確整數轉浮點數

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    int total = 7;
    int count = 2;

    double average =
        static_cast<double>(total) / count;

    cout << average << '\n';

    return 0;
}
```

輸出：

```text
3.5
```

`static_cast<double>(total)` 讓除法使用浮點數計算。

整數除法的詳細規則會在下一章「運算子與表示式」說明。

---

## Section LIII. 轉換不會修改原變數

```cpp
double value = 8.75;
int whole = static_cast<int>(value);
```

執行後：

```text
value = 8.75
whole = 8
```

`value` 本身沒有被改成整數。

---

## Section LIV. 字元轉整數

原始講義使用：

```cpp
char ch = 'a';

cout << static_cast<int>(ch);
```

這是同一種 `static_cast` 語法。

它將字元值轉成對應整數值，以便顯示編碼。

# Part L：窄化轉換

## Section LV. 什麼是窄化？

教材補充：

若轉換可能失去資料，可稱為窄化轉換，例如：

```text
double → int
double → float
long long → short
```

---

## Section LVI. 可能失去什麼？

### 小數部分

```cpp
3.9 → 3
```

### 精度

```text
double → float
```

### 可表示範圍

很大的整數轉成較小整數型別時，目標型別可能無法完整表示。

---

## Section LVII. 傳統初始化可能允許窄化

```cpp
double price = 19.95;
int whole = price;
```

編譯器可能允許，但 `whole` 只保存：

```text
19
```

使用嚴格警告選項可以幫助發現部分風險，但不能取代程式設計者理解轉換。

---

## Section LVIII. 大括號初始化的檢查

```cpp
int value{10};
double price{19.95};
```

大括號初始化會拒絕部分明顯的窄化轉換。

錯誤概念：

```cpp
int value{3.14};
```

因為 `3.14` 不能在不失去小數的情況下保存成 `int`。

---

## Section LIX. 比較兩種寫法

可能編譯但遺失小數：

```cpp
int first = 3.14;
```

會被大括號初始化拒絕：

```cpp
int second{3.14};
```

  <img src="images/CPP_Lesson_04_img12_narrowing_braces.png" alt="傳統初始化與大括號初始化的窄化檢查" width="700">
</p>

大括號不是所有轉換問題的完整解決方案，但能攔截部分明顯窄化。

# Part R：常見錯誤提醒

## Section LXX. 常見錯誤

### 錯誤 1：以為所有平台型別大小相同

應使用 `sizeof` 檢查目前環境。

---

### 錯誤 2：假設 `long` 一定是八位元組

`long` 可能是四或八位元組。

---

### 錯誤 3：大整數沒有適合型別

非常大的整數可能超出普通 `int` 範圍。

---

### 錯誤 4：將小數保存到 `int`

```cpp
int price = 19.95;
```

小數部分會遺失。

---

### 錯誤 5：忘記 `float` 後綴

```cpp
float value = 3.14;
```

來源字面常數是 `double`，再轉成 `float`。

較明確：

```cpp
float value = 3.14f;
```

---

### 錯誤 6：混淆單引號與雙引號

```cpp
char grade = "A";
```

應使用：

```cpp
char grade = 'A';
```

---

### 錯誤 7：假設一個中文字只需要一個 `char`

UTF-8 中文字通常由多個位元組組成。

---

### 錯誤 8：以為 `bool` 預設輸出文字

通常預設顯示 `1` 或 `0`。

---

### 錯誤 9：把 `sizeof` 結果當成位元

`sizeof` 的單位是位元組，不是 bit。

---

### 錯誤 10：修改 `const`

```cpp
const int DAYS = 7;
DAYS = 8;
```

不合法。

---

### 錯誤 11：把 `#define` 當成具型別變數

巨集取代不具備與 `constexpr` 相同的型別與作用域行為。

---

### 錯誤 12：以為浮點轉整數會四捨五入

實際是向零方向捨去小數部分。

---

### 錯誤 13：沒有注意隱性轉換

```cpp
int result = 3.9;
```

程式可能編譯，但資料已經改變。

---

### 錯誤 14：以為 `static_cast` 不會遺失資料

明確寫出轉型只表示意圖清楚，不代表轉換沒有資料損失。

---

### 錯誤 15：以為轉型會修改原變數

轉型通常產生新的轉換後值。

---

### 錯誤 16：整數除法後才轉成 `double`

```cpp
double average = total / count;
```

若兩邊都是整數，除法已先捨去小數。

---

### 錯誤 17：以為大括號能阻止所有風險

大括號可拒絕部分窄化，但仍需理解型別範圍與精度。

---

### 錯誤 18：為了節省空間過度使用較小型別

型別選擇也要考慮可讀性、介面與運算便利性。

---

# Part S：Mermaid 流程圖

## Section LXXI. 型別選擇與轉換流程

### 1. 選擇基本型別

```mermaid
flowchart TD
    A[準備保存資料] --> B{只有真或假嗎}
    B -- 是 --> C[使用 bool]
    B -- 否 --> D{只有單一字元嗎}
    D -- 是 --> E[使用 char]
    D -- 否 --> F{包含小數嗎}
    F -- 是 --> G[使用 float 或 double]
    F -- 否 --> H[使用整數型別]
```

---

### 2. 選擇浮點型別

```mermaid
flowchart TD
    A[需要保存小數] --> B{需要較高精度嗎}
    B -- 是 --> C[使用 double]
    B -- 否 --> D[可以考慮 float]
```

---

### 3. 型別大小檢查

```mermaid
flowchart LR
    A[選擇型別] --> B[使用 sizeof]
    B --> C[取得目前平台位元組大小]
    C --> D[不要只依賴常見表格]
```

---

### 4. 型別轉換判斷

```mermaid
flowchart TD
    A[準備轉換資料] --> B[寫出來源型別與目標型別]
    B --> C{可能遺失小數嗎}
    C -- 是 --> D[確認是否接受資料損失]
    C -- 否 --> E{可能降低精度或超出範圍嗎}
    E -- 是 --> D
    E -- 否 --> F[進行轉換]
    D --> G[必要時改用更合適型別]
```
