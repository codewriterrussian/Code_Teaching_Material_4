| 題型 | 建議 |

# Part A：因數問題

## Section IV. 什麼是因數？

若：

```text
n % divisor == 0
```

表示 `divisor` 可以整除 `n`，因此是 `n` 的因數。

例如 `12` 的正因數：

```text
1, 2, 3, 4, 6, 12
```

---

![圖：CPP_Lesson_11_img04_factor_candidate_filter](images/lesson_11/CPP_Lesson_11_img04_factor_candidate_filter.png)

## Section V. 列出所有因數

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    if (n <= 0) {
        cout << "Please enter a positive integer.\n";
        return 0;
    }

    for (int divisor = 1; divisor <= n; ++divisor) {
        if (n % divisor == 0) {
            cout << divisor << '\n';
        }
    }

    return 0;
}
```

## Section VII. 因數總和

```cpp
long long factorSum = 0;

for (int divisor = 1; divisor <= n; ++divisor) {
    if (n % divisor == 0) {
        factorSum += divisor;
    }
}
```

---

## Section VIII. 因數配對

若：

```text
divisor × quotient = n
```

則兩者通常成對出現。

例如 `36`：

```text
1 × 36
2 × 18
3 × 12
4 × 9
6 × 6
```

因此可以只檢查：

```cpp
divisor * divisor <= n
```

但要注意平方數中間的因數不能重複計算。

---

![圖：CPP_Lesson_11_img05_factor_pairs_sqrt](images/lesson_11/CPP_Lesson_11_img05_factor_pairs_sqrt.png)

## Section IX. 使用因數配對計數

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    if (n <= 0) {
        cout << "Invalid input\n";
        return 0;
    }

    int factorCount = 0;

    for (
        int divisor = 1;
        divisor <= n / divisor;
        ++divisor
    ) {
        if (n % divisor == 0) {
            int pairedFactor = n / divisor;

            if (divisor == pairedFactor) {
                ++factorCount;
            } else {
                factorCount += 2;
            }
        }
    }

    cout << factorCount << '\n';

    return 0;
}
```

使用：

```cpp
divisor <= n / divisor
```

可避免 `divisor * divisor` 可能溢位。

# Part B：質數

## Section X. 質數定義

質數是：

```text
大於 1
而且正因數只有 1 與自己
```

因此：

```text
0、1、負數都不是質數
```



## Section XVII. 為什麼每個候選數都要重設旗標？

錯誤：

```cpp
bool isPrime = true;

for (每個 candidate) {
    // ...
}
```

若某次變成 `false`，後續候選數可能永遠保持 `false`。

正確：

```cpp
for (每個 candidate) {
    bool isPrime = true;
}
```

# Part C：完全數

## Section XVIII. 完全數定義

若一個正整數等於它的真因數總和，就稱為完全數。

真因數：

```text
不包含自己本身的正因數
```

例如：

```text
6 的真因數：1、2、3
1 + 2 + 3 = 6
```

所以 `6` 是完全數。

---

## Section XIX. 完全數判斷

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    long long properFactorSum = 0;

    for (int divisor = 1; divisor < n; ++divisor) {
        if (n % divisor == 0) {
            properFactorSum += divisor;
        }
    }

    if (n > 1 && properFactorSum == n) {
        cout << "Perfect number\n";
    } else {
        cout << "Not a perfect number\n";
    }

    return 0;
}
```

# Part D：最大公因數

## Section XX. 列舉法

兩個正整數的共同因數中，最大的就是最大公因數。

---

![圖：CPP_Lesson_11_img11_gcd_common_factors](images/lesson_11/CPP_Lesson_11_img11_gcd_common_factors.png)

## Section XXI. 基本列舉法

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    int first;
    int second;
    cin >> first >> second;

    if (first < 0) {
        first = -first;
    }

    if (second < 0) {
        second = -second;
    }

    int limit =
        first < second ? first : second;

    int gcd = 0;

    for (int divisor = 1; divisor <= limit; ++divisor) {
        if (
            first % divisor == 0 &&
            second % divisor == 0
        ) {
            gcd = divisor;
        }
    }

    cout << gcd << '\n';

    return 0;
}
```

若兩數都是 `0`，本程式輸出 `0` 作為教材約定；數學上 `gcd(0, 0)` 通常不定義。

---

## Section XXII. 輾轉相除法

核心關係：

```text
gcd(a, b) = gcd(b, a % b)
```

持續更新，直到：

```text
b == 0
```

此時 `a` 是最大公因數。

---

![圖：CPP_Lesson_11_img12_euclidean_algorithm](images/lesson_11/CPP_Lesson_11_img12_euclidean_algorithm.png)

## Section XXIII. 完整輾轉相除法

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    long long a;
    long long b;

    cin >> a >> b;

    if (a < 0) {
        a = -a;
    }

    if (b < 0) {
        b = -b;
    }

    while (b != 0) {
        long long remainder =
            a % b;

        a = b;
        b = remainder;
    }

    cout << a << '\n';

    return 0;
}
```

---

## Section XXIV. 追蹤例子

求：

```text
gcd(48, 18)
```

| `a` | `b` | `a % b` |
| ---: | ---: | ---: |
| 48 | 18 | 12 |
| 18 | 12 | 6 |
| 12 | 6 | 0 |

結果：

```text
6
```

# Part E：最小公倍數

## Section XXV. 基本關係

對非零整數：

```text
lcm(a, b) = |a / gcd(a, b) × b|
```

先除後乘可降低中間乘積溢位風險。

---

## Section XXVI. 完整最小公倍數

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    long long first;
    long long second;

    cin >> first >> second;

    long long a = first;
    long long b = second;

    if (a < 0) {
        a = -a;
    }

    if (b < 0) {
        b = -b;
    }

    long long gcdA = a;
    long long gcdB = b;

    while (gcdB != 0) {
        long long remainder =
            gcdA % gcdB;

        gcdA = gcdB;
        gcdB = remainder;
    }

    if (a == 0 || b == 0) {
        cout << 0 << '\n';
    } else {
        long long lcm =
            (a / gcdA) * b;

        cout << lcm << '\n';
    }

    return 0;
}
```

## Section XXXII. 各位數字總和

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    long long number;
    cin >> number;

    if (number < 0) {
        number = -number;
    }

    int digitSum = 0;

    while (number > 0) {
        int digit =
            static_cast<int>(number % 10);

        digitSum += digit;
        number /= 10;

```

# Part G：反轉與回文數

## Section XXXV. 反轉公式

每取得一個新數字：

```cpp
reversed =
    reversed * 10 + digit;
```

例如反轉 `123`：

```text
0 → 3 → 32 → 321
```

---

![圖：CPP_Lesson_11_img17_reverse_number_building](images/lesson_11/CPP_Lesson_11_img17_reverse_number_building.png)

## Section XXXVI. 完整反轉程式

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    long long number;
    cin >> number;

    bool negative =
        number < 0;

    if (negative) {
        number = -number;
    }

    long long reversed = 0;

    while (number > 0) {
        long long digit =
            number % 10;

        reversed =
            reversed * 10 + digit;

        number /= 10;
    }

    if (negative) {
        reversed = -reversed;
    }

    cout << reversed << '\n';

    return 0;
}
```

## Section XXXVIII. 回文數

若正整數正著讀與反著讀相同，就是回文數。

## Section XL. 完整回文判斷

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    long long number;
    cin >> number;

    if (number < 0) {
        cout << "Not palindrome\n";
        return 0;
    }

    long long original =
        number;

    long long reversed = 0;

    while (number > 0) {
        reversed =
            reversed * 10 +
            number % 10;

        number /= 10;
    }

    if (original == reversed) {
        cout << "Palindrome\n";
    } else {
        cout << "Not palindrome\n";
    }

    return 0;
}
```

`0` 會得到 `original == reversed == 0`，因此被判定為回文數。

## Section XLII. 完整計數程式

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    long long number;
    int targetDigit;

    cin >> number >> targetDigit;

    if (
        targetDigit < 0 ||
        targetDigit > 9
    ) {
        cout << "Invalid digit\n";
        return 0;
    }

    if (number < 0) {
        number = -number;
    }

    int count = 0;

    if (number == 0 && targetDigit == 0) {
        count = 1;
    }

    while (number > 0) {
        int digit =
            static_cast<int>(number % 10);

        if (digit == targetDigit) {
            ++count;
        }

        number /= 10;
    }

    cout << count << '\n';

    return 0;
}
```

# Part S：Mermaid 流程圖

## Section LXXII. 解題流程圖

### 1. 一般迴圈解題

```mermaid
flowchart TD
    A[閱讀題目] --> B[找出候選範圍]
    B --> C[找出判斷條件]
    C --> D[決定需要記錄的狀態]
    D --> E[選擇 for while 或巢狀迴圈]
    E --> F[處理特殊情況]
    F --> G[手動追蹤測試]
```

### 2. 因數搜尋

```mermaid
flowchart TD
    A[divisor 從 1 開始] --> B{divisor <= n}
    B -- 否 --> E[完成]
    B -- 是 --> C{n 可被 divisor 整除嗎}
    C -- 是 --> D[輸出或統計 divisor]
    C -- 否 --> F[跳過]
    D --> G[divisor 加 1]
    F --> G
    G --> B
```

### 3. 質數判斷

```mermaid
flowchart TD
    A{n >= 2 嗎} -- 否 --> B[不是質數]
    A -- 是 --> C[從 divisor=2 開始]
    C --> D{還需要檢查嗎}
    D -- 否 --> E[是質數]
    D -- 是 --> F{可以整除嗎}
    F -- 是 --> B
    F -- 否 --> G[下一個 divisor]
    G --> D
```

### 4. 輾轉相除法

```mermaid
flowchart TD
    A[取得 a 與 b] --> B{b 等於 0 嗎}
    B -- 是 --> C[a 是最大公因數]
    B -- 否 --> D[remainder = a mod b]
    D --> E[a = b]
    E --> F[b = remainder]
    F --> B
```

### 5. 位數處理

```mermaid
flowchart TD
    A[取得 number] --> B{number 還有位數嗎}
    B -- 否 --> E[完成]
    B -- 是 --> C[digit = number mod 10]
    C --> D[處理 digit]
    D --> F[number 除以 10]
    F --> B
```

### 6. 最大值

```mermaid
flowchart TD
    A[用第一筆資料初始化 maximum] --> B[讀取下一筆]
    B --> C{value 大於 maximum 嗎}
    C -- 是 --> D[更新 maximum]
    C -- 否 --> E[保持原值]
    D --> F{還有資料嗎}
    E --> F
    F -- 是 --> B
    F -- 否 --> G[輸出 maximum]
```

### 7. 找第一個答案

```mermaid
flowchart TD
    A[從下限開始] --> B{超過上限嗎}
    B -- 是 --> C[沒有答案]
    B -- 否 --> D{符合全部條件嗎}
    D -- 是 --> E[輸出答案並 break]
    D -- 否 --> F[候選值加 1]
    F --> B
```

### 8. 二元方程式搜尋

```mermaid
flowchart TD
    A[選擇 x] --> B[依序選擇所有 y]
    B --> C{方程式成立嗎}
    C -- 是 --> D[輸出解並計數]
    C -- 否 --> E[跳過]
    D --> F[下一個 y]
    E --> F
    F --> G{y 範圍結束嗎}
    G -- 否 --> B
    G -- 是 --> H[下一個 x]
```
