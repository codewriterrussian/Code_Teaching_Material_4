# Lesson 02：Your First C++ Program 第一個 C++ 程式

> 這堂課的重點：建立第一個 `.cpp` 程式，理解 `#include <iostream>`、`using namespace std;`、`int main()`、大括號、分號、`cout` 與 `return 0;` 的用途。接著使用 `cout` 輸出文字、數字與運算結果，並學會使用 `\n`、`endl` 和註解。

---

## Section I. 今天要做什麼？

1. 認識 C++ 原始程式檔。
2. 使用 `.cpp` 作為副檔名。
3. 建立 `main.cpp`。
4. 認識建立與執行程式的四個步驟。
5. 撰寫第一個 `Hello world` 程式。
6. 認識 `#include <iostream>`。
7. 認識 `using namespace std;`。
8. 認識 `int main()`。
9. 認識大括號 `{ }`。
10. 認識分號 `;`。
11. 認識 `return 0;`。
12. 使用 `cout` 輸出文字。
13. 使用 `cout` 輸出整數與小數。
14. 使用 `cout` 輸出運算結果。
15. 使用多個 `<<` 串接輸出。
16. 主動加入空格。
17. 使用 `\n` 換行。
18. 使用 `endl` 換行。
19. 比較 `\n` 與 `endl`。
20. 理解 C++ 程式需要先編譯。
21. 理解語法錯誤會造成編譯失敗。
22. 認識單行註解 `//`。
23. 認識多行註解 `/* */`。
24. 找出缺少雙引號的錯誤。
25. 找出缺少分號的錯誤。
26. 理解 `system("pause")` 不是標準 C++。
27. 完成概念檢查、程式閱讀與實作練習。

---

## Section II. 今天的學習方式

1. 閱讀程式時先找出：
   - 標頭檔
   - `main()`
   - 輸出敘述
   - `return`
2. 將大括號視為一段程式碼的範圍。
3. 每個完整敘述結尾檢查是否有分號。
4. 文字內容檢查是否放在雙引號中。
5. 閱讀 `cout` 時，由左向右追蹤每一個 `<<`。
6. 預測輸出時標出空格與換行。
7. 編譯錯誤題同時檢查錯誤行與上一行。
8. 註解應說明程式目的或原因。
9. 本章不提前加入 `cin` 與變數輸入。
10. 完整合法範例使用嚴格 C++17 選項檢查。

# Part C：編譯與執行

## Section XVI. 編譯流程

C++ 程式通常需要先經過編譯：

```text
原始程式碼
→ 編譯器
→ 可執行程式
→ 執行結果
```

若程式碼正確：

```text
編譯成功
→ 建立可執行程式
→ 可以執行
```

若程式碼有語法錯誤：

```text
編譯失敗
→ 顯示錯誤訊息
→ 無法正常建立程式
```

  <img src="images/CPP_Lesson_02_img05_compile_success_failure.png" alt="C++ 編譯成功與編譯失敗的差異" width="700">

## Section XVII. 缺少分號

錯誤：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello world"

    return 0;
}
```

`cout` 敘述後缺少：

```cpp
;
```

---

## Section XVIII. 缺少雙引號

錯誤：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << Hello << '\n';

    return 0;
}
```

C++ 會把：

```cpp
Hello
```

當成名稱，而不是文字。

正確：

```cpp
cout << "Hello" << '\n';
```

---

## Section XIX. 錯誤可能顯示在下一行

若上一行缺少分號：

```cpp
cout << "Hello"
return 0;
```

編譯器可能在 `return` 附近顯示錯誤。

因此檢查時要看：

```text
錯誤行
上一行
```

# Part D：使用 `cout` 輸出

## Section XXI. 基本語法

```cpp
cout << 輸出內容;
```

</p>

`cout` 會把內容顯示在終端機或執行畫面。

---

## Section XXII. 輸出文字

文字要放在雙引號中：

```cpp
cout << "Hello world";
cout << "早安";
```

雙引號表示：

```text
這是一段文字
不是名稱或指令
```

---

### 1. 完整範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    cout << "Welcome to C++!" << '\n';

    return 0;
}
```

輸出：

```text
Welcome to C++!
```

---

## Section XXIII. 輸出數字

數字不需要雙引號：

```cpp
cout << 123;
cout << 3.14;
```

---

### 2. 完整範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    cout << 123 << '\n';
    cout << 3.14 << '\n';

    return 0;
}
```

輸出：

```text
123
3.14
```

---

## Section XXIV. 輸出運算結果

```cpp
cout << 123 + 456;
cout << 10 * 5;
```

C++ 會先計算，再輸出。

若沒有空格或換行，結果會連在一起：

```text
57950
```

因為：

```text
123 + 456 → 579
10 × 5     → 50
```

---

### 3. 加入換行

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    cout << 123 + 456 << '\n';
    cout << 10 * 5 << '\n';

    return 0;
}
```

輸出：

```text
579
50
```

---

## Section XXV. 一次輸出多個內容

```cpp
cout << 123 << " " << "早安";
```

輸出：

```text
123 早安
```

由左向右閱讀：

```text
輸出 123
→ 輸出一個空格
→ 輸出早安
```

---

### 4. 完整範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    cout << "C++" << " " << "is" << " " << "fun" << '\n';

    return 0;
}
```

輸出：

```text
C++ is fun
```

---

## Section XXVI. `cout` 不會自動加空格

```cpp
cout << 10 << 20;
```

輸出：

```text
1020
```

需要空格時，要自己加入：

```cpp
cout << 10 << " " << 20;
```

---

## Section XXX. `'\n'` 與 `"\n"`

兩者都能輸出換行：

```cpp
cout << "Hello" << '\n';
cout << "Hello" << "\n";
```

其中：

```cpp
'\n'
```

是一個換行字元。

```cpp
"\n"
```

是一段只包含換行的文字。

本教材常用：

```cpp
'\n'
```

---

## Section XXXI. 使用 `endl`

```cpp
cout << "第一行" << endl;
cout << "第二行" << endl;
```

`endl` 會：

1. 換行。
2. 刷新輸出緩衝區。

---

## Section XXXII. `\n` 與 `endl`

| 寫法 | 換行 | 刷新輸出緩衝區 |
| --- | --- | --- |
| `'\n'` | 是 | 不一定立即刷新 |
| `endl` | 是 | 會刷新 |

<p align="center">
  <img src="images/CPP_Lesson_02_img09_newline_vs_endl.png" alt="換行字元與 endl 的差異" width="700">
</p>

一般輸出通常優先使用：

```cpp
'\n'
```

---

### 5. 完整比較範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    cout << "Line 1" << '\n';
    cout << "Line 2" << endl;
    cout << "Line 3\n";

    return 0;
}
```

輸出：

```text
Line 1
Line 2
Line 3
```

# Part F：註解 Comments

## Section XXXIII. 什麼是註解？

註解是在程式碼中加入的說明。

編譯器會忽略註解內容，因此註解不會成為輸出。

---

## Section XXXIV. 單行註解

單行註解使用：

```cpp
//
```

例如：

```cpp
// 輸出歡迎訊息
cout << "Welcome!" << '\n';
```

也可以放在一行程式末尾：

```cpp
cout << "Welcome!" << '\n';  // 顯示歡迎訊息
```

---

## Section XXXV. 多行註解

多行註解使用：

```cpp
/*
內容
*/
```

例如：

```cpp
/*
這個程式會輸出兩行文字。
第一行是 Hello，第二行是 C++。
*/
cout << "Hello\n";
cout << "C++\n";
```

<p align="center">
  <img src="images/CPP_Lesson_02_img10_comment_types.png" alt="C++ 單行註解與多行註解的差異" width="700">
</p>

---

## Section XXXVI. 註解的用途

註解適合說明：

- 程式目的
- 設計原因
- 特殊限制
- 不容易理解的部分

不需要把每一行程式重新翻譯一次。

---

### 6. 完整註解範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

/*
第一個 C++ 輸出練習：
依序輸出三種水果。
*/
int main() {
    // 每個水果各佔一行
    cout << "Apple\n";
    cout << "Banana\n";
    cout << "Watermelon\n";

    return 0;
}
```

# Part J：常見錯誤提醒

<p align="center">
  <img src="images/CPP_Lesson_02_img11_common_syntax_errors.png" alt="缺少分號、雙引號與輸出運算子的常見錯誤" width="700">
</p>

## Section XL. 常見錯誤

### 錯誤 1：檔案不是 `.cpp`

C++ 原始程式通常使用：

```text
.cpp
```

---

### 錯誤 2：忘記 `<iostream>`

使用 `cout` 前需要：

```cpp
#include <iostream>
```

---

### 錯誤 3：缺少 `main()`

可執行程式需要開始位置。

---

### 錯誤 4：大括號不成對

左大括號需要對應右大括號。

---

### 錯誤 5：忘記分號

```cpp
cout << "Hello"
```

---

### 錯誤 6：文字沒有雙引號

```cpp
cout << Hello;
```

---

### 錯誤 7：漏掉 `<<`

錯誤：

```cpp
cout "Hello";
```

正確：

```cpp
cout << "Hello";
```

---

### 錯誤 8：以為 `cout` 自動加空格

```cpp
cout << 10 << 20;
```

輸出：

```text
1020
```

---

### 錯誤 9：以為 `cout` 自動換行

需要主動加入 `'\n'` 或 `endl`。

---

### 錯誤 10：每一行都使用 `endl`

一般輸出通常使用 `'\n'` 即可。

---

### 錯誤 11：註解符號寫錯

單行使用 `//`，多行使用 `/* */`。

---

### 錯誤 12：多行註解沒有結束

必須使用：

```cpp
*/
```

結束。

---

### 錯誤 13：把要執行的程式註解掉

被註解的程式不會執行。

---

### 錯誤 14：只看錯誤行

上一行缺少分號時，錯誤可能顯示在下一行附近。

---

### 錯誤 15：使用 `system("pause")`

它不是標準 C++。

---

### 錯誤 16：忽略 `return 0;`

本教材保留它，讓正常結束位置清楚。

---

### 錯誤 17：在 `#include` 後加分號

正確：

```cpp
#include <iostream>
```

---

### 錯誤 18：混淆 `std::cout` 與 `cout`

沒有 `using namespace std;` 時，需要使用 `std::cout`。

---
