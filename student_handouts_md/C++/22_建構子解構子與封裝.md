## Section II. 今天的學習方式

1. 每個類別先回答：
   ```text
   物件代表什麼？
   哪些資料必須被保護？
   建立時哪些規則必須成立？
   外部真正需要哪些操作？
   ```
2. 建構子先確保物件一建立就是有效狀態。
3. 成員初始化列表依成員宣告順序分析。
4. 只讀成員函式應加：
   ```cpp
   const
   ```
5. Getter 回傳大型字串時可使用：
   ```cpp
   const std::string&
   ```
6. 不要回傳 private 成員的非 `const` 參考。
7. 優先設計表達行為的函式：
   ```text
   deposit
   withdraw
   complete
   rename
   restock
   ```
8. 解構順序由最後完成建立的物件開始追蹤。
9. Vector of objects 題要分辨：
   ```text
   push_back 既有物件
   emplace_back 直接呼叫建構子
   ```
10. 本章資源管理交給標準型別。
11. 所有合法完整程式使用嚴格 C++17 選項檢查。

## Section III. 核心語法對照

| 語法 | 用途 |
| --- | --- |
| `class Account { ... };` | 宣告類別 |
| `public:` | 公開介面 |
| `private:` | 內部資料與實作 |
| `Account();` | 預設建構子 |
| `Account(double value);` | 參數化建構子 |
| `Account() = default;` | 產生預設版本 |
| `Account() = delete;` | 禁止此建立方式 |
| `Account(...) : member(value) {}` | 成員初始化列表 |
| `explicit Account(int value);` | 禁止隱式單參數轉換 |
| `~Account();` | 解構子 |
| `double balance() const;` | const 成員函式 |
| `const string& name() const;` | 唯讀參考 getter |
| `ClassName::function()` | 類別外定義成員函式 |
| `return *this;` | 回傳目前物件參考 |
| `vector<Account>` | 保存多個物件 |
| `emplace_back(args...)` | 直接在容器內建構物件 |

## Section XX. Student 範例

```cpp
// VALIDATE
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    Student(
        int initialId,
        const string& initialName,
        double initialScore
    )
        : idValue(initialId),
          nameValue(
              initialName.empty()
                  ? "Unknown"
                  : initialName
          ),
          scoreValue(
              normalizeScore(
                  initialScore
              )
          ) {
    }

    int id() const {
        return idValue;
    }

    const string& name() const {
        return nameValue;
    }

    double score() const {
        return scoreValue;
    }

    bool rename(
        const string& newName
    ) {
        if (newName.empty()) {
            return false;
        }

        nameValue = newName;
        return true;
    }

    bool updateScore(
        double newScore
    ) {
        if (
            newScore < 0.0 ||
            newScore > 100.0
        ) {
            return false;
        }

        scoreValue = newScore;
        return true;
    }

private:
    static double normalizeScore(
        double score
    ) {
        if (score < 0.0) {
            return 0.0;
        }

        if (score > 100.0) {
            return 100.0;
        }

        return score;
    }

    int idValue;
    string nameValue;
    double scoreValue;
};

int main() {
    Student student(
        1,
        "Amy",
        92.5
    );

    student.updateScore(95.0);

    cout << student.id()
         << " "
         << student.name()
         << " "
         << student.score()
         << '\n';

    return 0;
}
```

# Part L：BankAccount 行為介面

## Section XXI. 完整帳戶類別

```cpp
// VALIDATE
#include <iostream>
#include <string>
using namespace std;

class BankAccount {
public:
    BankAccount(
        const string& initialOwner,
        double initialBalance
    )
        : ownerName(initialOwner),
          balanceValue(
              initialBalance >= 0.0
                  ? initialBalance
                  : 0.0
          ) {
    }

    const string& owner() const {
        return ownerName;
    }

    double balance() const {
        return balanceValue;
    }

    bool deposit(double amount) {
        if (amount <= 0.0) {
            return false;
        }

        balanceValue += amount;
        return true;
    }

    bool withdraw(double amount) {
        if (
            amount <= 0.0 ||
            amount > balanceValue
        ) {
            return false;
        }

        balanceValue -= amount;
        return true;
    }

private:
    string ownerName;
    double balanceValue;
};

int main() {
    BankAccount account(
        "Amy",
        100.0
    );

    account.deposit(50.0);
    account.withdraw(30.0);

    cout << account.owner()
         << " "
         << account.balance()
         << '\n';

    return 0;
}
```

# Part W：完整 Product 類別

## Section XL. 規則

- ID 建立後不改變。
- 名稱不可為空。
- 價格不可為負。
- 庫存不可為負。
- 補貨量必須為正。
- 出貨不可超過庫存。

```cpp
// VALIDATE
#include <iostream>
#include <string>
using namespace std;

class Product {
public:
    Product(
        int initialId,
        const string& initialName,
        double initialPrice,
        int initialStock
    )
        : idValue(initialId),
          nameValue(
              initialName.empty()
                  ? "Unnamed"
                  : initialName
          ),
          priceValue(
              initialPrice >= 0.0
                  ? initialPrice
                  : 0.0
          ),
          stockValue(
              initialStock >= 0
                  ? initialStock
                  : 0
          ) {
    }

    int id() const {
        return idValue;
    }

    const string& name() const {
        return nameValue;
    }

    double price() const {
        return priceValue;
    }

    int stock() const {
        return stockValue;
    }

    bool rename(
        const string& newName
    ) {
        if (newName.empty()) {
            return false;
        }

        nameValue = newName;
        return true;
    }

    bool changePrice(
        double newPrice
    ) {
        if (newPrice < 0.0) {
            return false;
        }

        priceValue = newPrice;
        return true;
    }

    bool restock(int amount) {
        if (amount <= 0) {
            return false;
        }

        stockValue += amount;
        return true;
    }

    bool ship(int amount) {
        if (
            amount <= 0 ||
            amount > stockValue
        ) {
            return false;
        }

        stockValue -= amount;
        return true;
    }

private:
    const int idValue;
    string nameValue;
    double priceValue;
    int stockValue;
};

int main() {
    Product product(
        101,
        "Keyboard",
        50.0,
        10
    );

    product.restock(5);
    product.ship(3);

    cout << product.id()
         << " "
         << product.name()
         << " "
         << product.price()
         << " "
         << product.stock()
         << '\n';

    return 0;
}
```

# Part AC：常見錯誤提醒

## Section XLIX. 常見錯誤

1. 忘記類別宣告結尾分號。
2. 將建構子寫上回傳型別。
3. 建構子名稱與類別名稱不同。

5. `= delete` 後仍使用被禁止的建立方式。
6. 在建構子主體內賦值代替必要初始化。
7. `const` 成員未在初始化列表初始化。
8. 參考成員未在初始化列表綁定。
9. 誤以為初始化列表書寫順序決定實際順序。
10. 成員依賴尚未初始化的另一成員。
11. 委派建構子形成循環。
12. 單一參數建構子忘記 `explicit`。
13. 解構子寫參數。
14. 解構子寫回傳型別。
15. 嘗試多載解構子。
16. 無理由自訂空解構子。
17. Getter 回傳 private 成員的非 const 參考。
18. 為每個欄位機械式建立 setter。
19. Setter 未驗證資料。
20. Const 查詢函式忘記加 `const`。
21. Const 物件呼叫修改型函式。
22. 在 const 成員函式修改一般成員。
23. 回傳區域物件參考。
24. 參考成員指向生命週期較短的物件。
25. `emplace_back()` 參數與建構子不匹配。
26. 演算法直接存取 private 成員。
27. 用公開 setter 允許非法狀態轉換。
28. 自行管理裸資源卻沒有正確複製與解構設計。
29. 把所有成員都設為 public 而沒有封裝。
30. 類別公開介面沒有表達實際行為。
