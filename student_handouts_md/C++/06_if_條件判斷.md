## Section II. 今天的學習方式

1. 先把程式分成：
   ```text
   一定執行
   → 檢查條件
   → 可能執行
   → 繼續往下
   ```
2. 每個 `if` 都先回答：
   ```text
   條件是什麼？
   條件何時為 true？
   條件為 false 時跳過什麼？
   ```
3. 將條件單獨寫成 `bool` 變數，先檢查結果。
4. 使用流程圖表示是否進入 `if` 區塊。
5. 範圍條件拆成兩個比較，再用 `&&` 組合。
6. 多個可接受選項拆成多個相等比較，再用 `||` 組合。
7. 使用三個獨立 `if` 時，逐一檢查每一個條件。
8. 巢狀 `if` 題先判斷外層，再判斷內層。
9. 程式閱讀題記錄每個 `if` 是否執行。
10. 不使用 `else` 解答本章題目。
11. 完整合法範例使用嚴格 C++17 選項檢查。
12. 錯誤範例只用於分析，不作為可執行範例。

## Section III. 核心語法對照

| 語法 | 用途 |
| --- | --- |
| `if (condition) { ... }` | 條件成立時執行區塊 |
| `if (value > 0) { ... }` | 判斷正數 |
| `if (value == 0) { ... }` | 判斷等於零 |
| `if (score >= 60) { ... }` | 判斷達到門檻 |
| `if (age >= 0 && age <= 120) { ... }` | 判斷範圍 |
| `if (answer == 'Y' || answer == 'y') { ... }` | 接受多個值 |
| `if (!ready) { ... }` | 條件反轉 |
| `bool valid = condition;` | 保存條件結果 |
| `if (valid) { ... }` | 使用布林變數 |
| `if (outer) { if (inner) { ... } }` | 巢狀條件 |

# Part A：程式流程與 `if`

## Section IV. 預設流程

沒有條件判斷時，程式通常由上往下執行：

```cpp
cout << "A\n";
cout << "B\n";
cout << "C\n";
```

輸出：

```text
A
B
C
```

每一行都會執行。

---

## Section V. 條件式執行

加入 `if` 後，某些程式碼只會在條件成立時執行：

```cpp
if (condition) {
    statement;
}
```

流程：

```text
檢查 condition
→ true：執行區塊
→ false：跳過區塊
→ 繼續執行後面的程式
```

# Part F：短路求值與安全條件

## Section XXXII. 先檢查除數

```cpp
divisor != 0 &&
number / divisor > 2
```

如果 `divisor == 0`：

```text
左側為 false
→ 右側不執行
→ 不會進行整數除以零
```

---

## Section XXXIII. 安全除法判斷

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    int number;
    int divisor;

    cout << "請輸入被除數與除數：";
    cin >> number >> divisor;

    if (
        divisor != 0 &&
        number / divisor > 2
    ) {
        cout << "Safe and quotient is greater than 2.\n";
    }

    return 0;
}
```

危險：



# Part G：巢狀 `if`

## Section XXXVII. 什麼是巢狀 `if`？

`if` 區塊內還可以再放另一個 `if`：

```cpp
if (outerCondition) {
    if (innerCondition) {
        statement;
    }
}
```

內層條件只有在外層成立時才會檢查。


![圖：巢狀 if 的閘門結構](images/CPP_Lesson_06_img21_nested_if_gate.png)

---

## Section XXXVIII. 分段驗證

```cpp
if (score >= 0) {
    if (score <= 100) {
        cout << "Valid score\n";
    }
}
```

流程：

1. 先確認不低於 `0`。
2. 外層成立後，才確認不高於 `100`。
3. 兩層都成立才輸出。

---

## Section XXXIX. 巢狀 `if` 與 `&&`

這兩種寫法在此例意義相近：

```cpp
if (score >= 0) {
    if (score <= 100) {
        cout << "Valid score\n";
    }
}
```

```cpp
if (score >= 0 && score <= 100) {
    cout << "Valid score\n";
}
```

簡單條件通常使用 `&&` 更直接。

巢狀 `if` 適合：

- 內層檢查只在外層成立後才有意義。
- 每一層有不同處理工作。
- 想明確分段驗證。


![圖：巢狀 if 與 && 的比較](images/CPP_Lesson_06_img22_nested_if_vs_and.png)

## Section XLIII. 完整三角形有效性

```cpp

using namespace std;

int main() {
    int a;
    int b;
    int c;

    cout << "請輸入三個邊長：";
    cin >> a >> b >> c;

    bool positiveSides =
        a > 0 && b > 0 && c > 0;

    bool satisfiesTriangleInequality =
        a + b > c &&
        a + c > b &&
        b + c > a;

    bool validTriangle =
        positiveSides &&
        satisfiesTriangleInequality;

    if (validTriangle) {
        cout << "Valid triangle\n";
    }

    return 0;
}
```

---

## Section XLIV. 正三角形

```cpp
a == b && b == c
```

三邊全部相等。

```cpp
if (
    validTriangle &&
    a == b &&
    b == c
) {
    cout << "Equilateral triangle\n";
}
```

---

## Section XLV. 等腰三角形

至少兩邊相等：

```cpp
a == b || a == c || b == c
```

```cpp
if (
    validTriangle &&
    (
        a == b ||
        a == c ||
        b == c
    )
) {
    cout << "Isosceles triangle\n";
}
```

正三角形也符合「至少兩邊相等」，因此使用獨立 `if` 時，正三角形可能同時輸出正三角形與等腰三角形。

這正好展示：

> 獨立 `if` 會各自判斷，不會自動互斥。

下一章會使用 `else if` 處理互斥分類。

## Section XLVI. 直角三角形

不先排序時，可以檢查三種可能：

```cpp
a * a + b * b == c * c ||
a * a + c * c == b * b ||
b * b + c * c == a * a
```

完整條件：

```cpp
bool rightTriangle =
    validTriangle &&
    (
        a * a + b * b == c * c ||
        a * a + c * c == b * b ||
        b * b + c * c == a * a
    );
```

## Section XLVIII. 縮排提升可讀性

建議：

```cpp
if (score >= 60) {
    cout << "Pass\n";
}
```

不建議：

```cpp
if (score >= 60) {
cout << "Pass\n";
}
```

縮排讓程式區塊更容易辨認。

---

## Section XLIX. 縮排不影響實際範圍

```cpp
if (score >= 60)
    cout << "Pass\n";
    cout << "Finished\n";
```

實際只有第一個 `cout` 受到 `if` 控制。

第二行永遠執行。

因此本教材建議永遠使用大括號：

```cpp
if (score >= 60) {
    cout << "Pass\n";
    cout << "Finished\n";
}
```

---

## Section L. 即使只有一行也使用大括號

可寫：

```cpp
if (score >= 60)
    cout << "Pass\n";
```

但建議：

```cpp
if (score >= 60) {
    cout << "Pass\n";
}
```

好處：

- 日後增加程式碼較安全。
- 不容易因縮排誤判。

# Part N：常見錯誤提醒

## Section LV. 常見錯誤

### 錯誤 1：條件後誤加分號

```cpp

```

---

### 錯誤 2：使用 `=` 代替 `==`

```cpp

```

這是賦值，不是比較。

---

### 錯誤 3：缺少括號

```cpp
if score >= 60
```

條件需要放在圓括號中。

---

### 錯誤 4：大括號不成對

每個 `{` 必須有對應的 `}`。

---

### 錯誤 5：只靠縮排判斷範圍

縮排不會改變語法結構。

---

### 錯誤 6：省略大括號後加入第二行

只有第一個敘述受到 `if` 控制。

---

### 錯誤 7：數學連鎖比較

```cpp
0 <= score <= 100
```

不具數學語意。

---

### 錯誤 8：錯誤 OR 寫法

```cpp
answer == 'Y' || 'y'
```

每個選項都要完整比較。

---

### 錯誤 9：將 `&&` 與 `||` 混淆

合法範圍通常需要兩端同時成立，因此使用 `&&`。

---

### 錯誤 10：短路安全條件順序錯誤

危險運算前要先放安全檢查。

---

### 錯誤 11：以為第一個 `if` 成立後其他 `if` 不再檢查

獨立 `if` 會各自執行。

---

### 錯誤 12：以為互斥情況一定只輸出一次

若條件設計重疊，可能輸出多個結果。

---

### 錯誤 13：正三角形同時符合等腰條件

使用獨立 `if` 時可能同時輸出。

---

### 錯誤 14：未先驗證三角形有效性

邊長分類前應先確認正值與三角形不等式。

---

### 錯誤 15：使用未初始化變數作為條件

### 錯誤 16：條件中加入過多副作用

例如同時修改多個變數，會降低可讀性。

---

### 錯誤 17：把 `if` 當成會重複執行

### 錯誤 18：期待條件不成立時自動顯示另一段內容
