## Section II. 今天的學習方式

1. 每個模板先問：
   ```text
   哪個部分會隨型別改變？
   哪些操作必須被型別支援？
   ```
2. 模板函式若只讀參數，通常使用：
   ```cpp
   const T&
   ```
3. 需要修改原物件時使用：
   ```cpp
   T&
   ```
4. 需要獨立副本時才使用：
   ```cpp
   T
   ```
5. 遇到錯誤時先檢查：
   ```text
   實際型別是否支援模板內使用的操作？
   ```
6. 類別模板在類別外定義成員時，必須再次寫：
   ```cpp
   template <typename T>
   ```
7. 使用相依型別時檢查是否需要：
   ```cpp
   typename
   ```
8. 非型別模板參數必須是編譯期可用值。
9. 模板定義通常放在 header。
10. 所有合法完整程式使用嚴格 C++17 選項檢查。

## Section III. 核心語法對照

| 語法 | 用途 |
| --- | --- |
| `template <typename T>` | 宣告型別模板參數 |
| `template <class T>` | 與 `typename T` 等價 |
| `T maximum(T first, T second)` | 函式模板 |
| `maximum<int>(3, 5)` | 顯式指定模板型別 |
| `template <typename T, typename U>` | 多個型別參數 |
| `template <typename T, size_t N>` | 型別與非型別參數 |
| `class Box<T>` | 類別模板實例 |
| `Box<int>` | `T = int` |
| `typename Container::value_type` | 相依型別 |
| `using StringBox = Box<string>;` | 模板別名 |
| `template <typename T = int>` | 預設模板參數 |
| `template <> class Printer<bool>` | 完整特化 |
| `const T& value` | 唯讀泛型參數 |
| `T& value` | 可修改泛型參數 |
| `auto` | 依運算式推導回傳型別 |
| `static_assert(...)` | 編譯期條件檢查 |

## Section XVIII. 完整交換模板

```cpp
// VALIDATE
#include <iostream>
#include <string>
using namespace std;

template <typename T>
void swapValues(
    T& first,
    T& second
) {
    T temporary =
        first;

    first =
        second;

    second =
        temporary;
}

int main() {
    int firstNumber = 10;
    int secondNumber = 20;

    swapValues(
        firstNumber,
        secondNumber
    );

    cout << firstNumber
         << " "
         << secondNumber
         << '\n';

    string firstText =
        "left";

    string secondText =
        "right";

    swapValues(
        firstText,
        secondText
    );

    cout << firstText
         << " "
         << secondText
         << '\n';

    return 0;
}
```

## Section XX. 完整模板多載

```cpp
// VALIDATE
#include <iostream>
#include <string>
using namespace std;

template <typename T>
void printValue(
    const T& value
) {
    cout << value
         << '\n';
}

template <typename T>
void printValue(
    const T& value,
    int repeatCount
) {
    for (
        int count = 0;
        count < repeatCount;
        ++count
    ) {
        cout << value
             << '\n';
    }
}

int main() {
    printValue(42);

    printValue(
        string("Hello"),
        2
    );

    return 0;
}
```

// VALIDATE
#include <iostream>
#include <string>
#include <vector>
using namespace std;

template <typename T>
bool findIndex(
    const vector<T>& values,
    const T& target,
    typename vector<T>::size_type&
        resultIndex
) {
    for (
        typename vector<T>::size_type
            index = 0;
        index < values.size();
        ++index
    ) {
        if (
            values[index] ==
            target
        ) {
            resultIndex =
                index;

            return true;
        }
    }

    return false;
}

int main() {
    vector<string> words{
        "apple",
        "banana",
        "orange"
    };

    vector<string>::size_type
        index = 0;

    if (
        findIndex(
            words,
            string("banana"),
            index
        )
    ) {
        cout << index
             << '\n';
    }

# Part AF：常見錯誤提醒

## Section LXXII. 常見錯誤

1. 忘記在函式前寫 `template <typename T>`。
2. 將 `typename` 拼錯。
3. 誤以為模板本身就是單一具體函式。
4. 期待不同參數型別自動推導成同一 T。
5. 沒有顯式指定型別解決推導衝突。
6. 使用模板型別不支援的運算子。
7. 泛型函式按值傳入大型物件造成不必要複製。
8. 需要修改原物件卻忘記 `&`。
9. 回傳參考指向區域物件。
10. 類別模板建立物件時忘記模板參數。
11. 類別外定義成員時忘記 template 宣告。
12. 類別外定義時漏寫 `ClassName<T>::`。
13. 相依型別前漏寫 `typename`。
14. 非型別模板參數使用執行期變數。
15. `std::array<T, N>` 的 N 不是編譯期常數。
16. 模板預設參數造成介面難懂。
17. 過度使用完整特化。
18. 期待函式模板可以像類別模板一樣任意偏特化。
19. 模板定義只放 `.cpp` 導致連結錯誤。
20. 模板錯誤訊息很長時沒有先縮小測試案例。
21. 泛型總和錯誤假設 `T{}` 一定是正確零值。
22. 泛型列印錯誤假設所有型別都支援 `operator<<`。
23. 泛型比較錯誤假設所有型別都支援 `<`。
24. 模板參數名稱過於模糊。
25. 模板介面沒有說明型別需求。
26. 只使用一種型別卻建立複雜模板。
27. 使用模板取代更合適的 virtual 介面。
28. 忽略模板可能增加編譯時間。
29. 使用特化造成不同型別行為不一致。
30. 在尚未理解基礎模板前直接使用複雜 SFINAE。

# Part AG：Mermaid 流程圖

## Section LXXIII. 模板基礎流程圖

### 1. 函式模板實例化

```mermaid
flowchart TD
    A[呼叫模板函式] --> B[推導或取得模板參數]
    B --> C{型別是否支援模板內操作}
    C -- 是 --> D[產生具體函式版本]
    D --> E[編譯並呼叫]
    C -- 否 --> F[編譯錯誤]
```

### 2. 型別推導

```mermaid
flowchart TD
    A[讀取每個函式參數] --> B[推導對應模板型別]
    B --> C{所有推導結果一致嗎}
    C -- 是 --> D[使用推導型別]
    C -- 否 --> E[推導失敗]
    E --> F[顯式指定或重新設計模板]
```

### 3. 類別模板

```mermaid
flowchart TD
    A[宣告 Box T] --> B[建立 Box int]
    A --> C[建立 Box string]
    B --> D[產生 int 版本類別]
    C --> E[產生 string 版本類別]
```

### 4. 相依型別

```mermaid
flowchart TD
    A[遇到 Container T 的巢狀名稱] --> B{編譯器能確定是型別嗎}
    B -- 否 --> C[加入 typename]
    B -- 是 --> D[直接使用]
    C --> E[解析為相依型別]
```

### 5. 非型別模板參數

```mermaid
flowchart TD
    A[提供 N] --> B{N 是編譯期常數嗎}
    B -- 是 --> C[建立對應固定大小型別]
    B -- 否 --> D[編譯錯誤]
```

### 6. 模板與 Virtual 選擇

```mermaid
flowchart TD
    A[需要共同行為] --> B{型別在編譯期已知嗎}
    B -- 是 --> C[考慮 template]
    B -- 否 --> D{需要執行期替換行為嗎}
    D -- 是 --> E[考慮 virtual interface]
    D -- 否 --> F[重新分析設計]
```

### 7. 模板檔案配置

```mermaid
flowchart TD
    A[宣告模板] --> B[使用處需要實例化]
    B --> C{完整定義可見嗎}
    C -- 是 --> D[成功產生具體版本]
    C -- 否 --> E[可能編譯或連結失敗]
    E --> F[將定義放 header 或 tpp]
```

### 8. 是否使用模板

```mermaid
flowchart TD
    A[發現重複程式碼] --> B{邏輯是否真的相同}
    B -- 否 --> C[使用不同函式或類別]
    B -- 是 --> D{多種型別支援相同操作嗎}
    D -- 是 --> E[建立模板]
    D -- 否 --> F[使用明確介面或多型]
```
