# Lesson 20：Structures, Enumerations, and Data Modeling 結構、列舉與資料建模

> 這堂課的重點：把彼此相關的資料整理成一個清楚的模型。你會使用 `struct` 表示一筆完整資料，使用 `enum` 與 `enum class` 表示有限狀態，並學習如何將資料驗證、函式介面、容器與演算法整合成可讀且可維護的程式。

> 本章仍以「公開資料成員」為主，不深入 `class`、private 成員、建構函式、多型與繼承。這些會在後續物件導向程式設計章節介紹。

## Section II. 今天的學習方式

1. 每個資料模型先回答：
   ```text
   這個模型代表什麼？
   它有哪些必要欄位？
   每個欄位型別是什麼？
   有哪些有效值規則？
   ```
2. 看到多個總是一起出現的變數時，思考是否應建立 `struct`。
3. 看到有限狀態時，優先考慮 `enum class`。
4. 每個結構成員名稱要能直接說明資料用途。
5. 初始化列表必須依成員宣告順序閱讀。
6. 唯讀函式參數通常使用：
   ```cpp
   const Struct&
   ```
7. 需要修改原物件時使用：
   ```cpp
   Struct&
   ```
8. 需要建立新結果時直接回傳：
   ```cpp
   Struct
   ```
9. 搜尋結構集合時，lambda 直接比較目標成員。
10. 排序比較器要回答：
   ```text
   first 是否應排在 second 前？
   ```
11. enum 轉字串函式應處理所有列舉值。
12. 所有合法完整程式使用嚴格 C++17 選項檢查。

#include <string>
using namespace std;

struct Student {
    string name;
    int age;
    double score;
};

void showStudent(
    const Student& student
) {
    cout << student.name
         << " "
         << student.age
         << " "
         << student.score
         << '\n';
}

bool updateScore(
    Student& student,
    double newScore
) {
    if (
        newScore < 0.0 ||
        newScore > 100.0
    ) {
        return false;
    }

    student.score =
        newScore;

    return true;
}

int main() {
    Student student{
        "Amy",
        16,
        90.0
    };

    updateScore(
        student,
        95.0
    );

    showStudent(student);

    return 0;
}

## Section XXXI. 完整統計結構

```cpp
// VALIDATE
#include <iostream>
#include <vector>
using namespace std;

struct Statistics {
    int minimum;
    int maximum;
    double average;
};

bool calculateStatistics(
    const vector<int>& values,
    Statistics& result
) {
    if (values.empty()) {
        return false;
    }

    result.minimum =
        values.front();

    result.maximum =
        values.front();

    long long total = 0;

    for (int value : values) {
        if (
            value <
            result.minimum
        ) {
            result.minimum =
                value;
        }

        if (
            value >
            result.maximum
        ) {
            result.maximum =
                value;
        }

        total += value;
    }

    result.average =
        static_cast<double>(
            total
        ) /
        static_cast<double>(
            values.size()
        );

    return true;
}

int main() {
    vector<int> values{
        5,
        10,
        15
    };

    Statistics statistics{};

    if (
        calculateStatistics(
            values,
            statistics
        )
    ) {
        cout << statistics.minimum
             << " "
             << statistics.maximum
             << " "
             << statistics.average
             << '\n';
    }

    return 0;
}
```

    vector<double> scores;
};

double calculateAverage(
    const Course& course
) {
    if (
        course.scores.empty()
    ) {
        return 0.0;
    }

    double total = 0.0;

    for (
        double score :
        course.scores
    ) {
        total += score;
    }

    return
        total /
        static_cast<double>(
            course.scores.size()
        );
}

int main() {
    Course course{
        "C++",
        {
            80.0,
            90.0,
            100.0
        }
    };

    cout << course.name
         << " "
         << calculateAverage(
                course
            )
         << '\n';

    return 0;
}

#include <string>
#include <vector>
using namespace std;

struct Student {
    int id = 0;
    string name;
    double score = 0.0;
};

struct StudentSearchResult {
    bool found = false;
    Student student{};
};

StudentSearchResult findStudent(
    const vector<Student>& students,
    int targetId
) {
    for (
        const Student& student :
        students
    ) {
        if (
            student.id ==
            targetId
        ) {
            return {
                true,
                student
            };
        }
    }

    return {};
}

int main() {
    vector<Student> students{
        {
            1,
            "Amy",
            90.0
        }
    };

    StudentSearchResult result =
        findStudent(
            students,
            1
        );

    if (result.found) {
        cout << result.student.name
             << '\n';
    }

    return 0;
}

# Part AJ：常見錯誤提醒

## Section CIV. 常見錯誤

1. 忘記 `struct` 宣告結尾分號。
2. 建立結構物件後讀取未初始化基本型別成員。
3. Aggregate initialization 順序與成員宣告順序不同。
4. 修改了錯誤結構物件的成員。
5. 唯讀函式參數使用傳值造成不必要複製。
6. 需要修改原物件卻忘記參考 `&`。
7. 回傳區域結構參考。
8. 將所有欄位都設成 public 後完全不做驗證。
9. 重複儲存可重新計算的衍生資料。
10. 欄位名稱使用 `value1`、`data2` 等模糊名稱。
11. 用字串保存應為數值的資料。
12. 用字串保存有限狀態並造成拼字錯誤。
13. 使用多個互斥 bool 表示單一狀態。
14. 傳統 enum 的列舉值名稱和其他名稱衝突。
15. 忘記 `enum class` 需要 `Type::value`。
16. 期待 `enum class` 自動轉成 int。
17. 使用 `static_cast` 後依賴不穩定底層編號。
18. `switch` 漏掉新增的列舉值。
19. 列舉轉字串函式沒有完整回傳路徑。
20. 文字轉列舉時未處理無效輸入。
21. Vector of structs 搜尋後沒有檢查 `.end()`。
22. 排序比較器使用 `<=`。
23. 排序比較器修改結構內容。
24. 在迭代器失效後繼續使用 `iterator->member`。
25. C++17 中直接比較沒有定義運算子的 struct。
26. 將顯示格式文字重複存入模型。
27. 建立一個包含所有概念的巨大 struct。
28. 巢狀結構層級過深且名稱不清楚。
29. 狀態轉換函式允許不合法轉換。
30. 沒有明確定義模型的有效值規則。
