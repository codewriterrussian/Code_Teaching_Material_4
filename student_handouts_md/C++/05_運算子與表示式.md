## Section II. 今天的學習方式

1. 每個表示式先標出：
   ```text
   運算元、運算子、結果
   ```
2. 遇到 `/` 時，先檢查左右兩側型別。
3. 遇到 `%` 時，確認兩側都是整數型別。
4. 遇到混合型別運算時，先判斷哪一側會被轉換。
5. 遇到賦值時，由右往左閱讀。
6. 遇到多個運算子時：

   - 再看優先順序
   - 最後看結合方向
7. 關係表示式先預測 `true` 或 `false`。
8. 邏輯表示式分段計算：
   ```text
   左條件 → 右條件 → 組合結果
   ```
9. 短路求值題要判斷右側是否真的執行。
10. `++` 與 `--` 題先分辨前置或後置。
11. 不在同一個複雜表示式中多次修改同一變數。
12. 完整合法範例使用嚴格 C++17 選項檢查。

# Part A：運算子、運算元與表示式

## Section IV. 什麼是運算子？

運算子是告訴程式要進行哪一種操作的符號。

例如：

```cpp
3 + 5
```

其中：

```text
3、5 → 運算元
+    → 運算子
3+5  → 表示式
8    → 表示式結果
```

![運算子、運算元、表示式與結果的關係](images/CPP_Lesson_05_img01_operator_operand_expression.png)

---

## Section V. 表示式會產生值

```cpp
10 + 20
```

產生：

```text
30
```

```cpp
5 > 3
```

產生：

```text
true
```

```cpp
number = 10
```

會把 `10` 存入 `number`，同時整個賦值表示式也具有值。

---

## Section VI. 表示式可以組合

```cpp
(3 + 5) * 2
```

內層：

```text
3 + 5 → 8
```

外層：

```text
8 * 2 → 16
```

較小的表示式可以成為較大表示式的運算元。

# Part C：整數除法與浮點除法

## Section X. 整數除法

```cpp
7 / 2
```

左右兩邊都是整數，因此執行整數除法：

```text
7 ÷ 2 = 3 餘 1
```

表示式結果：

```text
3
```

小數部分不會保留。

---

## Section XI. 浮點數除法

```cpp
7.0 / 2
```

其中一側是 `double`，另一側會轉成相容浮點型別。

結果：

```text
3.5
```

---

## Section XII. 比較兩種除法

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    cout << 7 / 2 << '\n';
    cout << 7.0 / 2 << '\n';
    cout << 7 / 2.0 << '\n';

    return 0;
}
```

輸出：

```text
3
3.5
3.5
```

---

## Section XIII. 使用 `static_cast<double>()`

```cpp
int total = 7;
int count = 2;

double average =
    static_cast<double>(total) / count;
```

結果：

```text
3.5
```

只要在除法前先把其中一側轉成浮點數，就會執行浮點除法。

---

## Section XIV. 錯誤的轉換位置

```cpp
double average =
    static_cast<double>(total / count);
```

若：

```text
total = 7
count = 2
```

執行順序：

```text
total / count → 3
static_cast<double>(3) → 3.0
```

![除法前轉型與除法後轉型的結果差異](images/CPP_Lesson_05_img03_cast_before_division.png)

已經遺失的小數不會恢復。

```cpp
17 % 5
```

# Part E：優先順序與括號

## Section XXIII. 為什麼需要優先順序？

```cpp
2 + 3 * 4
```

若全部由左到右：

```text
(2 + 3) × 4 = 20
```

但 C++ 會先做乘法：

```text
2 + (3 × 4) = 14
```

---

## Section XXIV. 基本優先順序

本章常用運算子的簡化順序：

1. `( )`
2. 一元運算：`!`、一元 `+`、一元 `-`、前置 `++`、前置 `--`
3. `*`、`/`、`%`
4. `+`、`-`
5. `<`、`<=`、`>`、`>=`
6. `==`、`!=`
7. `&&`
8. `||`
9. `?:`
10. `=`、`+=`、`-=` 等賦值

> 不需要一次背完全部 C++ 運算子表。遇到不確定或可讀性不佳時，使用括號。

![C++ 常用運算子的簡化優先順序](images/CPP_Lesson_05_img06_operator_precedence.png)

---

## Section XXV. 括號改變順序

```cpp
(2 + 3) * 4
```

先計算：

```text
2 + 3 → 5
```

再計算：

```text
5 * 4 → 20
```

![括號如何改變算術表示式的計算順序](images/CPP_Lesson_05_img07_parentheses_order.png)

---

## Section XXVI. 同優先順序的結合方向

```cpp
20 / 5 * 2
```

`/` 與 `*` 優先順序相同，通常由左向右：

```text
20 / 5 → 4
4 * 2  → 8
```

不是：

```text
20 / (5 * 2) → 2
```

---

## Section XXVII. 減法也由左向右

```cpp
10 - 3 - 2
```

等價於：

```cpp
(10 - 3) - 2
```

結果：

```text
5
```

---

## Section XXVIII. 使用括號增加可讀性

即使沒有括號也能得到正確結果：

```cpp
price * quantity + shippingFee
```

若加入分組：

```cpp
(price * quantity) + shippingFee
```

讀者更容易看懂。

括號不只用來改變結果，也可用來表達意圖。

---

## Section XXIX. 優先順序完整範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    cout << 2 + 3 * 4 << '\n';
    cout << (2 + 3) * 4 << '\n';
    cout << 20 / 5 * 2 << '\n';
    cout << 20 / (5 * 2) << '\n';

    return 0;
}
```

輸出：

```text
14
20
8
2
```

# Part F：賦值運算

## Section XXX. 基本賦值

```cpp
number = 10;
```

表示：

```text
將右側的 10

```

## Section XXXI. 賦值方向

合法：

```cpp
number = 10;
```

不合法：

```cpp
/* 10 = number; */
```

左側必須是可以接收新值的物件。

```cpp
sum = first + second;
```

```cpp
area = width * height;
```

```cpp
average =

```

先算右側，再存入左側。

---

## Section XXXIII. 賦值表示式也有值

```cpp
int first;
int second;

first = second = 10;
```

賦值通常由右向左結合：

```text
second = 10
→ 整個表示式的值為 10
→ first = 10
```

結果：

```text
first = 10
second = 10
```

---

## Section XXXIV. 鏈式賦值的限制

```cpp
first = second = 10;
```

雖然合法，但不應把複雜運算塞進鏈式賦值。

清楚寫法：

```cpp
second = 10;
first = second;
```

更容易逐行追蹤。

# Part G：複合賦值

## Section XXXV. `+=`

```cpp
score += 5;
```

等價於基本概念：

```cpp
score = score + 5;
```

---

## Section XXXVI. 常見複合賦值

| 寫法 | 基本概念 |
| --- | --- |
| `value += amount;` | `value = value + amount;` |
| `value -= amount;` | `value = value - amount;` |
| `value *= amount;` | `value = value * amount;` |
| `value /= amount;` | `value = value / amount;` |
| `value %= amount;` | `value = value % amount;` |

## Section XXXVII. 完整複合賦值範例

```cpp
// VALIDATE

int main() {
    int value = 20;

    value += 5;

    value -= 3;
    cout << value << '\n';

    value *= 2;
    cout << value << '\n';

    value /= 4;
    cout << value << '\n';

    value %= 5;
    cout << value << '\n';

    return 0;
}
```

追蹤：

| 步驟 | `value` |
| --- | ---: |
| 初始 | 20 |
| `+= 5` | 25 |
| `-= 3` | 22 |
| `*= 2` | 44 |
| `/= 4` | 11 |
| `%= 5` | 1 |

# Part H：遞增與遞減

## Section XXXIX. 增加或減少 1

```cpp
++number;
number++;
--number;
number--;
```

都會修改 `number`。

---

## Section XL. 單獨成行時

```cpp
int number = 5;

number++;
++number;
```

執行後：

```text
number = 7
```

若 `++` 單獨成為一個敘述，前置與後置最後都增加 1。

---

## Section XLI. 前置遞增

```cpp
int number = 5;
int result = ++number;
```

順序：

```text
先將 number 增加到 6
→ 表示式結果為 6
→ result = 6
```

結果：

```text
number = 6
result = 6
```

---

## Section XLII. 後置遞增

```cpp
int number = 5;
int result = number++;
```

順序：

```text
先使用舊值 5 作為表示式結果
→ result = 5
→ 再將 number 增加到 6
```

結果：

```text
number = 6
result = 5
```

---

## Section XLIII. 完整前置與後置比較

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    int first = 5;
    int firstResult = ++first;

    int second = 5;
    int secondResult = second++;

    cout << first << " "
         << firstResult << '\n';

    cout << second << " "
         << secondResult << '\n';

    return 0;
}
```

輸出：

```text
6 6
6 5
```

## Section XLIV. 遞減同樣適用

```cpp
int first = 5;
int result1 = --first;
```

```text
first = 4
result1 = 4
```

```cpp
int second = 5;
int result2 = second--;
```

```text
second = 4
result2 = 5
```

## Section XLV. 初學建議

若只想增加 1：

```cpp
++number;
```

若只想減少 1：

```cpp
--number;
```

不要在同一行加入太多副作用：

```cpp
// 不建議作為初學風格
result = number++ + ++number;
```

即使某些寫法在特定標準中有明確規則，也很難閱讀與維護。

## Section XLVII. 六個關係運算子

| 運算子 | 意義 |
| --- | --- |
| `==` | 等於 |
| `!=` | 不等於 |

| `>` | 大於 |

```cpp
// VALIDATE
```

```text
true
false
true

```

## Section XLIX. `=` 與 `==`

```cpp
number = 10;
```

用途：

```text
賦值
```

```cpp
number == 10
```

用途：

```text
比較是否相等
```

# Part J：邏輯運算

## Section LIII. 邏輯 AND `&&`

```cpp
condition1 && condition2
```

只有兩邊都為 `true`，結果才是 `true`。

| 左側 | 右側 | 結果 |
| --- | --- | --- |
| `false` | `false` | `false` |
| `false` | `true` | `false` |
| `true` | `false` | `false` |
| `true` | `true` | `true` |

---

## Section LIV. 邏輯 OR `||`

```cpp
condition1 || condition2
```

只要至少一邊為 `true`，結果就是 `true`。

| 左側 | 右側 | 結果 |
| --- | --- | --- |
| `false` | `false` | `false` |
| `false` | `true` | `true` |
| `true` | `false` | `true` |
| `true` | `true` | `true` |

---

## Section LV. 邏輯 NOT `!`

```cpp
!condition
```

反轉真假：

```text
!true  → false
!false → true
```

![邏輯 AND、OR 與 NOT 的作用](images/CPP_Lesson_05_img12_logical_operators.png)

必須同時成立。

# Part K：短路求值

## Section LX. `&&` 的短路

```cpp
left && right
```

若 `left` 已經是 `false`，整體一定是 `false`。

因此 `right` 不會執行。

---

## Section LXI. `||` 的短路

```cpp
left || right
```

若 `left` 已經是 `true`，整體一定是 `true`。

因此 `right` 不會執行。

---

## Section LXII. 避免除以零

```cpp
divisor != 0 &&
number / divisor > 2
```

若 `divisor == 0`：

```text
左側為 false
→ 右側不執行
→ 避免整數除以零
```

順序不能任意交換。

危險：

```cpp
number / divisor > 2 &&
divisor != 0
```

![使用短路求值避免除以零](images/CPP_Lesson_05_img13_short_circuit_safety.png)

除法會先發生。

---

## Section LXIII. 完整短路範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    int number = 20;
    int divisor = 0;

    bool safeAndLarge =
        divisor != 0 &&
        number / divisor > 2;

    cout << boolalpha
         << safeAndLarge
         << '\n';

    return 0;
}
```

輸出：

```text
false
```

右側除法不會執行。

---

## Section LXIV. 使用副作用觀察短路

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    int count = 0;

    bool first =
        false && (++count > 0);

    cout << first << " "
         << count << '\n';

    bool second =
        true || (++count > 0);

    cout << second << " "
         << count << '\n';

    return 0;
}
```

輸出：

```text
0 0
1 0
```

兩次右側都沒有執行，所以 `count` 維持 `0`。

# Part M：條件運算子 `?:`

## Section LXVII. 基本語法


# Part S：常見錯誤提醒

## Section LXXIX. 常見錯誤

### 錯誤 1：以為整數除法會保留小數

```cpp
7 / 2
```

結果是 `3`。

---

### 錯誤 2：除法完成後才轉型

```cpp
static_cast<double>(total / count)
```

無法恢復已遺失的小數。

---

### 錯誤 3：除以零

整數除以零不能使用。

---

### 錯誤 4：對浮點數使用 `%`

`%` 只適用於整數型別。

---

### 錯誤 5：忽略負數餘數的符號

負數 `%` 的結果需要依 C++ 的整數除法規則理解，不應直接套用只適合非負數的位數拆解方法。

---

### 錯誤 6：誤判優先順序

```cpp
2 + 3 * 4
```

乘法先執行。

---

### 錯誤 7：只依賴記憶，不使用括號

若表達式難讀，加入括號。

---

### 錯誤 8：混淆 `=` 與 `==`

- `=` 賦值。
- `==` 比較。

---

### 錯誤 9：左側不是可賦值物件

```cpp
10 = number;
```

不合法。

---

### 錯誤 10：忘記複合賦值受型別影響

```cpp
int value = 7;
value /= 2;
```

結果是 `3`。

---

### 錯誤 11：混淆前置與後置遞增

前置使用新值，後置表示式使用舊值。

---

### 錯誤 12：在複雜表示式中多次修改同一變數

即使能編譯，也可能難以理解或產生未定義／非預期行為。

---

### 錯誤 13：使用數學連鎖比較

```cpp
0 <= score <= 100
```

不是正確範圍條件。

---

### 錯誤 14：將 `&&` 與 `||` 混淆

範圍通常需要 `&&`；多個可接受選項通常使用 `||`。

### 錯誤 15：忽略短路順序
