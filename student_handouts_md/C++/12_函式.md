# Lesson 12：Functions 函式

> 這堂課的重點：把一段具有明確工作的程式碼整理成「函式」，讓程式可以重複使用、分工、測試與閱讀。你會學習函式的定義與呼叫、參數、回傳值、`void`、函式宣告、區域變數、作用域、傳值呼叫、提前 `return`，並把前面學過的條件判斷與迴圈整理成可重複使用的函式。

## Section II. 今天的學習方式

1. 看到一個函式時，先標出：
   ```text
   回傳型態
   函式名稱
   參數
   函式主體
   ```
2. 呼叫函式前先問：
   ```text
   我需要提供什麼資料？
   ```
3. 呼叫函式後再問：
   ```text
   它會回傳什麼？
   ```
4. 若函式只負責「做一件事」而不需要提供結果，可以考慮 `void`。
5. 若函式需要回答一個問題，例如「是不是偶數」，優先考慮 `bool`。
6. 若函式要計算數字，回傳型態要符合結果可能的資料型態。
7. 寫函式前先用一句話描述工作：
   ```text
   這個函式負責 ______。
   ```
8. 一個函式最好有清楚、單一的主要責任。
9. 能用回傳值表達結果時，不要依賴不必要的全域變數。
10. 函式內的變數先視為只在函式內有效。
11. `return` 題要確認：
    ```text
    回傳什麼？
    何時離開函式？
    ```
12. 完整合法範例使用嚴格 C++17 選項檢查。

# Part A：什麼是函式？

## Section IV. 函式的基本概念

函式可以想成一個小型工具：

```text
輸入資料
↓
執行特定工作
↓
產生結果
```

例如：

```text
輸入兩個整數
↓
相加
↓
回傳總和
```

可以寫成：

```cpp
int add(int first, int second) {
    return first + second;
}
```

---

![圖 1：函式是一台小工具](images/lesson_12/lesson12_functions_01_input_process_return.png)

## Section V. 為什麼需要函式？

沒有函式時，大量程式可能都放在：

```cpp
int main() {
    // 很多很多程式碼
}
```

問題會逐漸變成：

```text
main() 太長
重複程式碼很多
難以閱讀
難以測試
難以修改
```

使用函式後，可以拆成：

```text
讀取資料
計算
驗證
輸出
搜尋
```

每一項由不同函式負責。

---

![圖 2：把大型程式拆成函式](images/lesson_12/lesson12_functions_02_break_down_program.png)

## Section VI. 第一個自訂函式

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void sayHello() {
    cout << "Hello\n";
}

int main() {
    sayHello();

    return 0;
}
```

執行順序：

```text
進入 main()
↓
呼叫 sayHello()
↓
進入 sayHello()
↓
輸出 Hello
↓
sayHello() 結束
↓
回到 main()
```

---

![圖 3：函式呼叫後會回來](images/lesson_12/lesson12_functions_03_call_and_return.png)

## Section VII. 定義與呼叫

函式定義：

```cpp
void sayHello() {
    cout << "Hello\n";
}
```

函式呼叫：

```cpp
sayHello();
```

不要把兩者混在一起。

# Part C：沒有參數的函式

## Section XIII. 重複呼叫

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void printSeparator() {
    cout << "----------\n";
}

int main() {
    printSeparator();
    cout << "Section A\n";
    printSeparator();
    cout << "Section B\n";
    printSeparator();

    return 0;
}
```

同一個函式可以呼叫很多次。

正確：

```cpp
printSeparator();
```

不是：

```cpp
printSeparator;
```

括號代表：

```text
執行這個函式
```

---

## Section XV. `void` 的意思

```cpp
void printSeparator()
```

`void` 表示：

```text
這個函式不提供一個資料值給呼叫端
```

它仍然可以：

```text
輸出
判斷
迴圈
呼叫其他函式
```

只是沒有像 `int` 函式那樣回傳一個整數結果。

```cpp

```

函式呼叫：

```cpp

```

這裡的：

```cpp
25
```

稱為引數 argument。

## Section XIX. 多個參數

```cpp

    cout << "("

         << ", "
```

# Part G：函式宣告與定義順序

## Section XXX. 為什麼順序會有問題？

這樣：

```cpp
int main() {
    cout << square(5);
}

int square(int number) {
    return number * number;
}
```

若前面沒有宣告，編譯器在看到：

```cpp
square(5)
```

時還不知道 `square` 是什麼。

---

## Section XXXI. 方法一：先定義函式

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int square(int number) {
    return number * number;
}

int main() {
    cout << square(5)
         << '\n';

    return 0;
}
```

---

## Section XXXII. 方法二：使用函式原型

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int square(int number);

int main() {
    cout << square(5)
         << '\n';

    return 0;
}

int square(int number) {
    return number * number;
}
```

---

![圖 8：函式原型讓編譯器先認識函式](images/lesson_12/lesson12_functions_08_prototype_and_definition.png)

## Section XXXIII. 函式原型

```cpp
int square(int number);
```

最後有：

```text
;
```

它只是在告訴編譯器：

```text
之後會有一個叫 square 的函式
接收一個 int
回傳一個 int
```

---

## Section XXXIV. 宣告與定義必須一致

宣告：

```cpp
int add(int first, int second);
```

定義也應相符：

```cpp
int add(int first, int second) {
    return first + second;
}
```

不能宣告成：

```cpp
double add(int first, int second);
```

卻定義為：

```cpp
int add(int first, int second)
```

# Part H：區域變數與作用域

## Section XXXV. 函式內的變數

```cpp
int square(int number) {
    int result =
        number * number;

    return result;
}
```

`result` 是區域變數。

它主要只存在於：

```text
square() 的大括號範圍內
```

---

## Section XXXVI. 不同函式可以有同名區域變數

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void firstFunction() {
    int value = 10;
    cout << value << '\n';
}

void secondFunction() {
    int value = 20;
    cout << value << '\n';
}

int main() {
    firstFunction();
    secondFunction();

    return 0;
}
```

兩個 `value` 是不同變數。

---

## Section XXXVII. `main()` 看不到其他函式的區域變數

錯誤概念：

```cpp
void createNumber() {
    int number = 10;
}

int main() {
    cout << number;
}
```

`number` 不在 `main()` 的作用域內。

# Part I：傳值呼叫 Pass by Value

```cpp
#include <iostream>

void changeNumber(int number) {

int main() {
    int value = 5;
```

不是直接修改 `main()` 中的：

```cpp

```

```text

```

# Part J：Early Return 提前結束函式

## Section XLII. `return` 不只負責提供結果

一旦執行：

```cpp
return value;
```

函式就會立即結束。

後面的程式不會再執行。

---

## Section XLIII. 使用 early return 驗證資料

```cpp
// VALIDATE
#include <iostream>
using namespace std;

bool isValidScore(int score) {
    if (score < 0) {
        return false;
    }

    if (score > 100) {
        return false;
    }

    return true;
}

int main() {
    int score;
    cin >> score;

    if (isValidScore(score)) {
        cout << "Valid\n";
    } else {
        cout << "Invalid\n";
    }

    return 0;
}
```

---

![圖 11：Early Return 像出口閘門](images/lesson_12/lesson12_functions_11_early_return.png)

## Section XLIV. 為什麼 early return 很清楚？

不需要把所有條件塞成：

```cpp
return score >= 0 && score <= 100;
```

簡單條件時兩種都可以。

但複雜驗證時：

```text
發現錯誤
→ 立刻 return
```

通常比較容易追蹤。

---

## Section XLV. `void` 也可以提前 `return`

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void printPositive(int number) {
    if (number <= 0) {
        return;
    }

    cout << number
         << '\n';
}

int main() {
    printPositive(-3);
    printPositive(8);

    return 0;
}
```

`return;` 沒有資料值，只表示：

```text
立即離開這個 void 函式
```

## Section XLVII. `isInRange()`

```cpp
// VALIDATE
#include <iostream>
using namespace std;

bool isInRange(
    int number,
    int minimum,
    int maximum
) {
    return
        number >= minimum &&
        number <= maximum;
```

# Part T：常見錯誤提醒

## Section LXIX. 常見錯誤

1. 定義函式後忘記在 `main()` 呼叫。
2. 呼叫函式時忘記括號。
3. 函式原型忘記分號。
4. 函式在使用後才定義，又沒有先宣告。
5. 宣告與定義的回傳型態不一致。
6. 宣告與定義的參數型態不一致。
7. 呼叫時引數數量錯誤。
8. 呼叫時引數順序錯誤。
9. 把 parameter 與 argument 混為同一個位置概念。
10. `int` 函式忘記回傳值。
11. `double` 計算卻不小心使用不適合的整數運算。
12. `void` 函式使用 `return value;`。
13. 在 `return` 後面放重要程式，卻期待它執行。
14. 忽略函式的回傳值。
15. 誤以為傳值參數修改後會改變呼叫端變數。
16. 嘗試在其他函式直接使用區域變數。
17. 建立過多不必要的全域變數。
18. 函式名稱過短，無法表示用途。
19. 一個函式同時處理太多不相關工作。
20. 只為了「用了函式」而把一行簡單程式拆得過度零碎。
21. `bool` 函式中回傳 `1`、`0` 雖可轉換，但降低可讀性。
22. `isEven()` 內又輸出結果，使「判斷」與「顯示」責任混在一起。
23. 搜尋函式找到答案後只 `break` 內層，卻忘記可直接 `return`。
24. `return` 的值與函式名稱代表的意義不一致。
25. 看到重複程式碼卻只複製貼上，不考慮抽成函式。
