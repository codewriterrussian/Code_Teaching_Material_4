# Lesson 10：Nested Loops 巢狀迴圈

> 這堂課的重點：在一個迴圈中再放入另一個迴圈，處理「列與欄」、「每一組要重複多次」、「所有可能組合」等問題。你會學習外層與內層迴圈的執行關係，並用巢狀迴圈完成九九乘法表、文字矩形、空心矩形、三角形與簡易整數方程式搜尋。

> 本章主要使用傳統 `for` 迴圈。`while` 與 `do-while` 也可以形成巢狀迴圈，但圖形與固定範圍問題使用 `for` 通常較清楚。陣列與二維陣列會在後續章節完整介紹。

## Section II. 今天的學習方式

1. 每個巢狀迴圈先標出：
   ```text
   外層變數
   內層變數
   外層範圍
   內層範圍
   ```
2. 將外層想成：
   ```text
   第幾列
   第幾組
   第一個選項
   ```
3. 將內層想成：
   ```text
   第幾欄
   組內第幾次
   第二個選項
   ```
4. 每次外層進入新一輪時，確認內層是否重新從起點開始。
5. 圖形題先建立表格：
   ```text
   row
   column
   應輸出什麼
   ```
6. 靠右圖形先拆成：
   ```text
   空白
   符號
   ```
7. 座標法先寫出條件，再放入迴圈。
8. 搜尋所有組合時，先決定每個變數的合法範圍。
9. `break` 題要標記它位於哪一層迴圈。
10. 計算總次數時，先判斷內層是否每輪固定。
11. 完整合法範例使用嚴格 C++17 選項檢查。
12. 錯誤範例只供分析，不作為合法完整程式。

## Section III. 核心語法對照

| 語法 | 用途 |
| --- | --- |
| `for (...) { for (...) { ... } }` | 建立雙層迴圈 |
| `row` | 常用來表示列 |
| `column` | 常用來表示欄 |
| `cout << '\n';` | 一列結束後換行 |
| `row == 1` | 上邊界 |
| `row == height` | 下邊界 |
| `column == 1` | 左邊界 |
| `column == width` | 右邊界 |
| `column <= row` | 左下直角三角形 |
| `column <= size - row + 1` | 倒立三角形 |
| `column < size - row + 1` | 靠右圖形的空白區 |
| `column == row` | 主對角線 |
| `row + column == size + 1` | 反對角線 |
| `break;` | 離開目前最內層迴圈 |
| `continue;` | 跳過目前迴圈本輪剩餘程式 |
| `setw(width)` | 設定下一個輸出欄位寬度 |

# Part A：什麼是巢狀迴圈？

## Section IV. 基本結構

```cpp
for (外層初始化; 外層條件; 外層更新) {
    for (內層初始化; 內層條件; 內層更新) {
        程式主體;
    }
}
```

## Section V. 外層與內層

```cpp
for (int row = 1; row <= 3; ++row) {
    for (int column = 1; column <= 4; ++column) {
        cout << row << " " << column << '\n';
    }
}
```

- `row` 控制外層。
- `column` 控制內層。
- 每一個 `row` 都會搭配所有 `column`。

---

## Section VI. 執行順序

當：

```text
row = 1
```

內層會執行：

```text
column = 1, 2, 3, 4
```

接著外層更新：

```text
row = 2
```

內層重新從：

```text
column = 1
```

開始。


![圖：外層與內層的真正執行順序](images/lesson_10/CPP_Lesson_10_img02_nested_execution_order.png)

## Section VII. 完整座標範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    for (int row = 1; row <= 2; ++row) {
        for (int column = 1; column <= 3; ++column) {
            cout << "("
                 << row
                 << ", "
                 << column
                 << ")\n";
        }
    }

    return 0;
}
```

輸出：

```text
(1, 1)
(1, 2)
(1, 3)
(2, 1)
(2, 2)
(2, 3)
```

# Part B：計算總執行次數

## Section IX. 固定內層次數

```cpp
for (int row = 0; row < 3; ++row) {
    for (int column = 0; column < 4; ++column) {
        ++count;
    }
}
```

外層：

```text
3 次
```

每一輪內層：

```text
4 次
```

總次數：

```text
3 × 4 = 12
```

## Section X. 三層迴圈

```cpp
for (int a = 0; a < 2; ++a) {
    for (int b = 0; b < 3; ++b) {
        for (int c = 0; c < 4; ++c) {
            ++count;
        }
    }
}
```

總次數：

```text
2 × 3 × 4 = 24
```

## Section XI. 內層次數不固定

```cpp
for (int row = 1; row <= 4; ++row) {
    for (int column = 1; column <= row; ++column) {
        ++count;
    }
}
```

內層次數：

```text
1 + 2 + 3 + 4 = 10
```

不能直接用：

```text
4 × 4
```

## Section XXIII. 傳統排列方式

## Section XXVII. 完整空心矩形

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int main() {
    int height = 5;
    int width = 8;

    for (int row = 1; row <= height; ++row) {
        for (int column = 1; column <= width; ++column) {
            bool isBorder =
                row == 1 ||
                row == height ||
                column == 1 ||
                column == width;

            if (isBorder) {
                cout << '*';
            } else {
                cout << ' ';
            }
        }

        cout << '\n';
    }

    return 0;
}
```

輸出：

```text

*      *
*      *
********
```

---

## Section XXVIII. 高度或寬度為 1

若：

```text
height = 1
```

所有位置都符合：

```cpp
row == 1
```

因此整列都是邊界。

若：

```text
width = 1
```

所有位置都符合左邊界與右邊界。

## Section LXVIII. 三角形迴圈

```cpp

    for (int column = 1; column <= row; ++column) {
        // ...
    }
}
```

```text

```

大約也是與：

```text
n²
```

## Section LXIX. 為什麼要注意？

若：

```text
n = 10
```

`n² = 100`。

若：

```text
n = 10000
```

`n² = 100000000`。

巢狀迴圈可能很快產生大量工作或輸出。

```mermaid
flowchart TD

    C --> D{內層條件成立嗎}
    D -- 是 --> E[執行內層主體]
    E --> F[更新內層]
    F --> D
    D -- 否 --> G[更新外層]
    G --> B
```

```mermaid
flowchart TD

    B --> C{還有欄位嗎}

    E --> C
    C -- 否 --> F[換行]
    F --> G{還有下一列嗎}
    G -- 是 --> A
    G -- 否 --> H[完成]
```

```mermaid
    D --> E
```
