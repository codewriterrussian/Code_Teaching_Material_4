## Section II. 今天的學習方式

1. 每次看到繼承，先問：
   ```text
   Derived 真的是一種 Base 嗎？
   ```
2. 只為了重用程式碼時，先考慮 composition。
3. 覆寫函式一律加：
   ```cpp
   override
   ```
4. 多型基底類別通常加入：
   ```cpp
   virtual ~Base() = default;
   ```
5. 需要多型時使用：
   ```cpp
   Base&
   Base*
   ```
6. 避免：
   ```cpp
   Base object = derived;
   ```
7. 抽象基底介面應小而清楚。
8. 建構順序：
   ```text
   base → members → derived body
   ```
9. 解構順序：
   ```text
   derived body → members reverse → base
   ```
10. Downcast 前先思考是否能改用虛擬函式。
11. 本章所有合法完整程式使用嚴格 C++17 選項檢查。

## Section III. 核心語法對照

| 語法 | 用途 |
| --- | --- |
| `class Dog : public Animal` | Public inheritance |
| `protected:` | 基底與衍生類別可存取 |
| `Derived(...) : Base(...) {}` | 呼叫基底建構子 |
| `virtual void speak() const;` | 虛擬函式 |
| `void speak() const override;` | 覆寫並要求編譯器檢查 |
| `void function() final;` | 禁止繼續覆寫 |
| `class Type final` | 禁止繼承 |
| `virtual double area() const = 0;` | 純虛擬函式 |
| `virtual ~Base() = default;` | 虛擬解構子 |
| `const Base& reference = derived;` | Upcasting reference |
| `Base* pointer = &derived;` | Upcasting pointer |
| `dynamic_cast<Derived*>(basePointer)` | 安全 downcast |
| `using Base::Base;` | 繼承基底建構子 |
| `Base& parameter` | 保留動態多型 |
| `Base parameter` | 可能造成 object slicing |

## Section VIII. 為什麼不建議大量 protected data？

因為所有衍生類別都可任意修改，基底類別較難維持 invariant。

通常較好：

- private data
- protected helper function
- public 或 protected getter

---

## Section IX. 完整 Protected Helper

```cpp
// VALIDATE
#include <iostream>
using namespace std;

class Counter {
public:
    int value() const {
        return valueCount;
    }

protected:
    void changeBy(int amount) {
        valueCount += amount;
    }

private:
    int valueCount = 0;
};

class StepCounter : public Counter {
public:
    explicit StepCounter(
        int initialStep
    )
        : stepValue(initialStep) {
    }

    void increment() {
        changeBy(stepValue);
    }

private:
    int stepValue;
};

int main() {
    StepCounter counter(5);

    counter.increment();
    counter.increment();

    cout << counter.value()
         << '\n';

    return 0;
}
```

# Part H：非虛擬函式

## Section XIX. Static Binding

非虛擬函式依表達式的靜態型別決定。

```cpp
// VALIDATE
#include <iostream>
using namespace std;

class Base {
public:
    void show() const {
        cout << "Base\n";
    }
};

class Derived : public Base {
public:
    void show() const {
        cout << "Derived\n";
    }
};

int main() {
    Derived derived;
    const Base& baseReference =
        derived;

    derived.show();
    baseReference.show();

    return 0;
}
```

輸出：

```text
Derived
Base
```

這是遮蔽，不是動態多型。

```cpp
// VALIDATE
#include <iostream>
using namespace std;

class Shape {
public:
    virtual ~Shape() = default;

    virtual double area() const = 0;
};

class Circle : public Shape {
public:
    explicit Circle(
        double initialRadius
    )
        : radiusValue(initialRadius) {
    }

    double area() const override {
        constexpr double pi =
            3.14159265358979323846;

        return
            pi *
            radiusValue *
            radiusValue;
    }

private:
    double radiusValue;
};

class Rectangle : public Shape {
public:
    Rectangle(
        double initialWidth,
        double initialHeight
    )
        : widthValue(initialWidth),
          heightValue(initialHeight) {
    }

    double area() const override {
        return
            widthValue *
            heightValue;
    }

private:
    double widthValue;
    double heightValue;
};

void showArea(
    const Shape& shape
) {
    cout << shape.area()
         << '\n';
}

int main() {
    Circle circle(2.0);
    Rectangle rectangle(
        4.0,
        3.0
    );

    showArea(circle);
    showArea(rectangle);

    return 0;
}
```

```cpp
class Animal {
public:
    virtual ~Animal() = default;
};

class Dog : public Animal {
public:
```

```cpp
        cout << "Dog fetches.\n";
    }

};

    Animal* animal

        dynamic_cast<Dog*>(
```

# Part Q：建構子中的 Virtual 呼叫

## Section LIV. 本章安全非擁有示範

```cpp
// VALIDATE
#include <iostream>
#include <vector>
using namespace std;

class Shape {
public:
    virtual ~Shape() = default;

    virtual double area() const = 0;
};

class Square : public Shape {
public:
    explicit Square(
        double initialSide
    )
        : sideValue(initialSide) {
    }

    double area() const override {
        return
            sideValue *
            sideValue;
    }

private:
    double sideValue;
};

class Rectangle : public Shape {
public:
    Rectangle(
        double initialWidth,
        double initialHeight
    )
        : widthValue(initialWidth),
          heightValue(initialHeight) {
    }

    double area() const override {
        return
            widthValue *
            heightValue;
    }

private:
    double widthValue;
    double heightValue;
};

int main() {
    Square square(3.0);
    Rectangle rectangle(
        4.0,
        5.0
    );

    vector<const Shape*> shapes{
        &square,
        &rectangle
    };

    for (
        const Shape* shape :
        shapes
    ) {
        cout << shape->area()
             << '\n';
    }

    return 0;
}
```

這些指標不擁有物件；`square` 與 `rectangle` 必須比 vector 活得久。

# Part AB：常見錯誤提醒

## Section LXIV. 常見錯誤

1. 只為重用程式碼而濫用繼承。
2. Derived 並不是真正的 Base。
3. 忘記使用 public inheritance。
4. 誤以為衍生類別可存取 base private 成員。
5. 將大量資料設為 protected。
6. 忘記在衍生建構子呼叫必要的基底建構子。
7. 誤判建構與解構順序。
8. 將 name hiding 誤認為 overriding。
9. 基底函式忘記 `virtual`。
10. 覆寫函式忘記 `override`。
11. 覆寫時漏掉 `const`。
12. 覆寫參數型別不同。
13. 比較器或函式名稱相同就誤以為是覆寫。
14. 抽象類別仍嘗試直接建立物件。
15. 衍生類別未實作全部純虛擬函式。
16. 多型基底缺少 virtual destructor。
17. 按值傳遞多型物件造成 slicing。
18. 使用 `vector<Base>` 保存衍生物件。
19. Downcast 未檢查失敗。
20. 過度依賴 `dynamic_cast`。
21. 在建構子依賴衍生虛擬覆寫。
22. 在解構子依賴衍生虛擬覆寫。
23. 對非 polymorphic base 使用 `dynamic_cast`。
24. 忘記 `final` 禁止後續覆寫。
25. 使用 inheritance 表達 has-a。
26. 衍生類別破壞基底契約。
27. 建立過深繼承階層。
28. 建立過大的抽象基底介面。
29. 非擁有型基底指標指向已銷毀物件。
30. 使用裸擁有指標卻沒有清楚所有權設計。

# Part AC：Mermaid 流程圖

## Section LXV. 繼承與多型流程圖

### 1. 判斷是否使用繼承

```mermaid
flowchart TD
    A[想重用或擴充類別] --> B{Derived 真的是 Base 嗎}
    B -- 是 --> C[考慮 public inheritance]
    B -- 否 --> D{只是擁有或使用 Base 嗎}
    D -- 是 --> E[使用 composition]
    D -- 否 --> F[重新設計介面]
```

### 2. 建構與解構順序

```mermaid
flowchart TD
    A[建立 Derived] --> B[建立 Base 部分]
    B --> C[建立 Derived 成員]
    C --> D[執行 Derived 建構子主體]
    D --> E[使用物件]
    E --> F[執行 Derived 解構子主體]
    F --> G[銷毀 Derived 成員]
    G --> H[銷毀 Base 部分]
```

### 3. 虛擬函式呼叫

```mermaid
flowchart TD
    A[透過 Base 參考或指標呼叫] --> B{函式是 virtual 嗎}
    B -- 否 --> C[依靜態型別選擇 Base 版本]
    B -- 是 --> D[查看實際物件型別]
    D --> E[呼叫最終 override 版本]
```

### 4. 抽象類別

```mermaid
flowchart TD
    A[類別包含純虛擬函式] --> B[類別成為 abstract]
    B --> C{衍生類別實作全部純虛擬函式嗎}
    C -- 是 --> D[可建立衍生物件]
    C -- 否 --> E[衍生類別仍為 abstract]
```

### 5. Object Slicing

```mermaid
flowchart TD
    A[將 Derived 傳入 Base 值] --> B[只複製 Base 部分]
    B --> C[Derived 額外資料消失]
    C --> D[虛擬呼叫失去原衍生物件]
    A --> E[改用 Base 參考或指標]
    E --> F[保留完整物件與動態多型]
```

### 6. Downcast

```mermaid
flowchart TD
    A[取得 Base 指標] --> B[dynamic_cast 到 Derived 指標]
    B --> C{結果為 nullptr 嗎}
    C -- 是 --> D[實際物件不是 Derived]
    C -- 否 --> E[安全使用 Derived 介面]
```

### 7. 虛擬解構子

```mermaid
flowchart TD
    A[透過 Base 指標銷毀物件] --> B{Base destructor 是 virtual 嗎}
    B -- 是 --> C[先呼叫 Derived destructor]
    C --> D[再呼叫 Base destructor]
    B -- 否 --> E[衍生清理可能不完整]
```

### 8. 多型介面設計

```mermaid
flowchart TD
    A[多個型別有共同操作] --> B[建立精簡抽象 Base]
    B --> C[宣告 virtual 或 pure virtual]
    C --> D[各 Derived 使用 override]
    D --> E[外部只依賴 Base 介面]
```
