# Lesson 01：C++ Basics, Input, Output & Data Types C++ 初識、輸入輸出與資料型別

> 這堂課的重點：理解 C++ 程式的基本結構，學會使用 `cout` 輸出、使用 `cin` 輸入，並建立變數、常數及常見資料型別。完成本章後，你應該可以獨立撰寫簡單的互動式 C++ 程式。

> 輸入資料 → 執行規則 → 輸出結果

## Section II. 今天的學習方式

1. 先把每個程式分成：
   ```text
   Input → Process → Output
   ```
2. 每次看到新的程式，先找：
   - 標頭檔
   - `main()`
   - 變數
   - 輸入
   - 處理
   - 輸出
3. 文字使用雙引號：
   ```cpp
   "Hello"
   ```
4. 單一字元使用單引號：
   ```cpp
   'A'
   ```
5. 變數建立時標出：
   ```text
   型別、名稱、初始值
   ```
6. 輸入題先確認變數型別是否符合輸入資料。
7. 每次使用 `cin >>` 時，思考輸入中是否可能包含空格。
8. 每次使用整數型別時，確認資料是否包含小數。
9. 不硬背型別實際大小，使用 `sizeof` 在目前環境確認。
10. 完整範例使用：
    ```text
    clang++ -std=c++17 -Wall -Wextra -Werror
    ```
    檢查。

## Section VIII. 程式結構說明

| 程式碼 | 用途 |
| --- | --- |

## Section XI. 輸出文字

文字使用雙引號：



```cpp
cout << 123 + 456;
cout << 10 * 5;
```

```text

```

## Section XV. 使用 `\n`

```cpp
cout << "第一行\n";
```

## Section XVI. 使用 `endl`

```cpp
cout << "第一行" << endl;
cout << "第二行" << endl;
```

`endl` 會：

1. 換行。
2. 刷新輸出緩衝區。

一般輸出通常優先使用：

```cpp
'\n'
```

---

## Section XVII. `cout` 常見錯誤

### 錯誤 1：文字沒有雙引號

```cpp
cout << Hello;
```

C++ 會把 `Hello` 當成名稱。

正確：

```cpp
cout << "Hello";
```

### 錯誤 2：忘記分號

```cpp
cout << "Hello"
```

正確：

```cpp
cout << "Hello";
```

## Section XXII. `cin` 與資料型別




因為 `cin >>` 遇到空白會停止。

# Part F：常數 Constants

## Section XXXIV. 使用 `const`

```cpp
const int MONTHS_PER_YEAR = 12;
```

完整範例：

```cpp
#include <iostream>

int main() {
    const int MONTHS_PER_YEAR = 12;

```

## Section XXXV. 常數不能重新指定

```cpp
const int MONTHS_PER_YEAR = 12;

/* MONTHS_PER_YEAR = 24; */
```

建立後不能修改。

## Section XXXVI. 使用 `constexpr`

```cpp
constexpr int DAYS_PER_WEEK = 7;
```

初學時可理解成：

```text
明確表示可在編譯期間確定的固定常數
```

## Section XXXVII. `#define`

```cpp
#define DAYS_PER_WEEK 7
```

現代 C++ 通常較建議：

```cpp
constexpr int DAYS_PER_WEEK = 7;
```

因為 `const` 與 `constexpr`：

- 有明確型別
- 編譯器較容易檢查
- 較符合 C++ 型別系統

# Part G：關鍵字與識別字

## Section XXXVIII. 關鍵字 Keywords

C++ 保留單字，例如：

```cpp
int
double
if
else
for
while
return
class
const
```

不能作為自訂變數名稱。

錯誤：

```cpp
int return = 10;
```

---

## Section XXXIX. 識別字 Identifiers

識別字是程式設計者建立的名稱，可用於：

- 變數
- 常數
- 函式
- 類別

---

## Section XL. 命名規則

1. 不能使用 C++ 關鍵字。
2. 只能使用英文字母、數字與底線 `_`。
3. 第一個字元不能是數字。
4. 名稱區分大小寫。

合法：

```cpp
age
studentScore
student_score
_score
score2
```

不合法：

```cpp
2score
student-score
class
```

---

## Section XLI. 大小寫不同

```cpp
int score = 90;
int Score = 80;
int SCORE = 70;
```

三者是不同變數。

---

## Section XLII. 命名建議

不建議：

```cpp
int x = 30;
```

較清楚：

```cpp
int studentCount = 30;
```

常見命名方式：

```cpp
int studentCount;   // camelCase
int student_count;  // snake_case
```

同一專案應盡量一致。

## Section XLIV. 整數型別

```cpp
short smallNumber = 100;
int studentCount = 30;
long population = 23000000;
long long worldPopulation = 8000000000LL;
```

| 型別 | 常見大小 | 說明 |
| --- | ---: | --- |
| `short` | 2 位元組 | 較小範圍整數 |
| `int` | 4 位元組 | 最常使用的整數型別 |
| `long` | 4 或 8 位元組 | 大小依平台而定 |
| `long long` | 8 位元組 | 較大範圍整數 |

實際大小依：

- 作業系統
- 處理器架構
- 編譯器

而不同。

---

## Section XLV. 浮點數型別

```cpp
float temperature = 36.5f;
double height = 168.75;
```

| 型別 | 常見大小 | 約略有效位數 |
| --- | ---: | ---: |
| `float` | 4 位元組 | 約 6～7 位十進位有效數字 |
| `double` | 8 位元組 | 約 15～16 位十進位有效數字 |

小數常值預設為 `double`。

```cpp
float value1 = 3.14f;
double value2 = 3.14;
```

## Section XLVIII. 字元編碼

```cpp
char ch = 'a';
```


傳統 ASCII：

| 字元 | 編碼 |
| --- | ---: |
| `'A'` | 65 |
| `'a'` | 97 |
| `'0'` | 48 |

> 中文字在 UTF-8 中通常需要多個位元組，不能假設一個中文字只使用一個 `char`。

# Part N：常見錯誤提醒

## Section LXII. 常見錯誤

### 錯誤 1：忘記分號

```cpp
int age = 15
```

---

### 錯誤 2：文字沒有雙引號

```cpp
cout << Hello;
```

---

### 錯誤 3：字元使用雙引號

```cpp
char grade = "A";
```

---

### 錯誤 4：使用未定義變數

```cpp
cout << score;
```

---

### 錯誤 5：重複定義同名變數

```cpp
int age = 15;
int age = 16;
```

---

### 錯誤 6：輸入資料型別不符

```cpp
int age;
cin >> age;
```

輸入：

```text
fifteen
```

無法正常轉成整數。

---

### 錯誤 7：忘記載入 `<string>`

使用：

```cpp
string name;
```

前應加入：

```cpp
#include <string>
```

---

### 錯誤 8：使用 `cin >>` 讀取完整姓名

遇到空格會停止。

---

### 錯誤 9：直接輸出未初始化區域變數

```cpp
int score;
cout << score;
```

內容不確定。

---

### 錯誤 10：修改 `const`

```cpp
const int DAYS = 7;
DAYS = 8;
```

---

### 錯誤 11：使用關鍵字命名

```cpp
int return = 10;
```

---

### 錯誤 12：名稱以數字開頭

```cpp
int 2score = 90;
```

---

### 錯誤 13：混淆 `=` 與數學等號概念

```cpp
score = 95;
```

表示將右側資料指定給左側變數。

---

### 錯誤 14：假設所有電腦的型別大小相同

應使用：

```cpp
sizeof(...)
```

確認。

---

### 錯誤 15：假設一個中文字只使用一個 `char`

UTF-8 中文字通常需要多個位元組。

---

### 錯誤 16：所有換行都使用 `endl`

一般情況使用 `\n` 即可。

---

### 錯誤 17：在跨平台教材使用 `system("pause")`

它不是標準 C++。

---

### 錯誤 18：`cout` 串接時漏掉 `<<`

```cpp
cout << "Age: " age;
```

應寫：

```cpp
cout << "Age: " << age;
```
