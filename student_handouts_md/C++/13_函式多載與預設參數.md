# Lesson 13：Function Overloading and Default Arguments 函式多載與預設參數

> 這堂課的重點：深入理解 C++ 如何讓多個函式共用同一個名稱，以及呼叫函式時，編譯器如何根據引數數量與型別選擇最適合的版本。你也會學習預設引數的宣告規則、使用時機，以及多載與預設引數同時存在時可能產生的歧義。

> 第 12 章已介紹函式多載與預設引數的基本語法。本章會進一步分析多載集合、函式簽章、型別轉換優先順序、參考多載、歧義呼叫、`static_cast` 消除歧義，以及良好的介面設計方式。

## Section III. 核心語法對照

| 語法 | 用途 |
| --- | --- |
| `void show(int value);` | `int` 版本 |
| `void show(double value);` | `double` 版本 |
| `void show(int a, int b);` | 不同參數數量 |
| `void process(int& value);` | 可修改左值參考版本 |
| `void process(const int& value);` | 唯讀參考版本 |
| `void draw(int length, char symbol = '*');` | 使用預設引數 |
| `void configure(int level = 1, bool enabled = true);` | 多個右側預設值 |
| `static_cast<double>(value)` | 明確指定型別 |
| `static_cast<void (*)(int)>(show)` | 指定多載函式指標版本 |
| `int function(int);` | 回傳型別不參與多載選擇 |
| `void example(int);` | 與 `void example(const int);` 相同簽章 |
| `void test(int);` + `void test(int, int = 0);` | 呼叫 `test(5)` 時會歧義 |

# Part A：什麼是函式多載？

## Section IV. 相同名稱，不同參數列表

```cpp
void show(int value) {
    cout << "Integer: "
         << value
         << '\n';
}

void show(double value) {
    cout << "Double: "
         << value
         << '\n';
}
```

兩個函式都叫：

```text
show
```

但參數型別不同。

## Section V. 完整基本多載範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void show(int value) {
    cout << "Integer: "
         << value
         << '\n';
}

void show(double value) {
    cout << "Double: "
         << value
         << '\n';
}

int main() {
    show(10);
    show(3.5);

    return 0;
}
```

輸出：

```text
Integer: 10
Double: 3.5
```

---

## Section VI. 呼叫時選擇版本

```cpp
show(10);
```

引數 `10` 是 `int`，因此選擇：

```cpp
show(int)
```

```cpp
show(3.5);
```

引數 `3.5` 是 `double`，因此選擇：

```cpp
show(double)
```

---

## Section VII. 多載集合

同一作用域中的同名函式形成多載集合：

```cpp
show(int)
show(double)
show(char)
```

呼叫：

```cpp
show(argument);
```

編譯器會從集合中選擇最佳版本。

# Part B：哪些差異可以形成多載？

## Section VIII. 不同參數數量

```cpp
int maximum(int first, int second);

int maximum(
    int first,
    int second,
    int third
);
```

這是合法多載。

---

## Section IX. 完整不同數量範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int maximum(int first, int second) {
    return
        first > second
            ? first
            : second;
}

int maximum(
    int first,
    int second,
    int third
) {
    return
        maximum(
            maximum(first, second),
            third
        );
}

int main() {
    cout << maximum(3, 8)
         << '\n';

    cout << maximum(3, 8, 5)
         << '\n';

    return 0;
}
```

---

## Section X. 不同參數型別

```cpp
int absoluteValue(int value);
double absoluteValue(double value);
```

合法，因為參數型別不同。

---

## Section XI. 不同參數順序

```cpp
void describe(int count, double value);
void describe(double value, int count);
```

這也是合法多載。

但若參數意義不清楚，呼叫可能難以閱讀。

---

## Section XII. 完整順序多載範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void repeat(int count, char symbol) {
    for (int index = 0; index < count; ++index) {
        cout << symbol;
    }

    cout << '\n';
}

void repeat(char symbol, int count) {
    repeat(count, symbol);
}

int main() {
    repeat(5, '*');
    repeat('#', 3);

    return 0;
}
```

# Part C：哪些差異不能形成多載？

## Section XIII. 參數名稱不影響簽章

以下兩個宣告代表同一種函式：

```cpp
int add(int first, int second);
int add(int a, int b);
```

參數名稱只是函式內部使用的名稱。

---

## Section XIV. 只改回傳型別不可以

不合法：

```cpp
int convert(int value);
double convert(int value);
```

呼叫：

```cpp
convert(10);
```

引數只能告訴編譯器參數是 `int`，無法根據使用者期待的回傳型別選擇版本。

---

![圖：CPP_Lesson_13_img05_return_type_not_overload](images/lesson_13/CPP_Lesson_13_img05_return_type_not_overload.png)

## Section XV. 頂層 `const` 不形成傳值多載

以下兩個宣告視為相同：

```cpp
void process(int value);
void process(const int value);
```

因為傳值時，呼叫者的資料會被複製。

`const` 只限制函式內是否能修改這份副本。

---

## Section XVI. 錯誤概念

```cpp
/* 不可同時定義：

void process(int value) {
}

void process(const int value) {
}

*/
```

這不是兩個不同多載，而是重複定義相同函式。

# Part D：參考與 `const` 參考多載

## Section XVII. 合法參考多載

```cpp
void process(int& value);
void process(const int& value);
```

兩者不同：

- `int&`：可修改的一般左值。
- `const int&`：唯讀，可接收常數或暫時值。

---

## Section XVIII. 完整參考多載範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void inspect(int& value) {
    cout << "Mutable lvalue: "
         << value
         << '\n';
}

void inspect(const int& value) {
    cout << "Const or temporary: "
         << value
         << '\n';
}

int main() {
    int number = 10;
    const int constantNumber = 20;

    inspect(number);
    inspect(constantNumber);
    inspect(30);

    return 0;
}
```

---

## Section XIX. 呼叫選擇

```cpp
int number = 10;
inspect(number);
```

一般可修改變數最適合：

```cpp
inspect(int&)
```

```cpp
const int number = 10;
inspect(number);
```

只能選：

```cpp
inspect(const int&)
```

暫時值：

```cpp
inspect(30);
```

也會選：

```cpp
inspect(const int&)
```

---

## Section XX. 左值初步概念

一般具名變數：

```cpp
int number = 10;
```

表達式：

```cpp
number
```

通常是左值，代表一個有持續身分與儲存位置的物件。

字面常數：

```cpp
10
```

是暫時值，不能綁定到一般非 `const` 左值參考。

# Part E：多載解析的基本流程

## Section XXI. 第一步：候選函式

編譯器先找出目前可見的同名函式：

```cpp

show(double)

```

## Section XXII. 第二步：可行函式

函式必須：

- 引數數量可對應。
- 每個引數能轉換成參數型別。
- 參考綁定規則合法。
- 缺少的引數有預設值。

若多個函式都可行，編譯器比較每個引數所需的轉換品質。

本章使用簡化順序：

```text

優於
型別提升
優於
一般標準轉換
```

## Section XXIV. 精確符合

```cpp

void show(double);
```

```cpp
show(10);
```

`10` 是 `int`，因此 `show(int)` 是精確符合。

## Section XXV. 型別提升

常見提升：

```text

short → int
float → double
```

提升通常比一般轉換更優先。

## Section XXVI. 一般標準轉換

例如：

```text

double → int
int → char
```

這些通常比精確符合或提升排名低。


# Part G：型別提升

## Section XXXII. `short` 通常提升為 `int`

假設：

```cpp
void display(int value);
void display(double value);
```

```cpp
short number = 5;
display(number);
```

`short → int` 是整數提升。

`short → double` 是一般轉換。

所以通常選：

```cpp
display(int)
```

---

## Section XXXIII. 完整提升範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void display(int value) {
    cout << "int: "
         << value
         << '\n';
}

void display(double value) {
    cout << "double: "
         << value
         << '\n';
}

int main() {
    short number = 5;
    display(number);

    return 0;
}
```

---

## Section XXXIV. `float` 提升為 `double`

若只有：

```cpp
void display(double);
void display(int);
```

`float` 引數通常會優先提升為 `double`，而不是轉成 `int`。

# Part H：歧義呼叫

## Section XXXV. 什麼是歧義？

當兩個或更多可行函式同樣合適，編譯器無法選擇唯一最佳版本。

結果：

```text
編譯錯誤
```

---

## Section XXXVI. 常見歧義例子

```cpp
void process(long value);
void process(double value);
```

呼叫：

```cpp
process(10);
```

`int → long` 與 `int → double` 都屬一般標準轉換。

編譯器可能無法選出更好的版本。

---

## Section XXXVII. 使用明確型別消除歧義

```cpp
process(static_cast<long>(10));
```

或：

```cpp
process(static_cast<double>(10));
```

---

![圖：CPP_Lesson_13_img14_static_cast_resolves_overload](images/lesson_13/CPP_Lesson_13_img14_static_cast_resolves_overload.png)

## Section XXXVIII. 完整明確轉型範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void process(long value) {
    cout << "long: "
         << value
         << '\n';
}

void process(double value) {
    cout << "double: "
         << value
         << '\n';
}

int main() {
    process(
        static_cast<long>(10)
    );

    process(
        static_cast<double>(10)
    );

    return 0;
}
```

## Section XXXIX. 最佳做法

若呼叫者經常需要 `static_cast` 才能選擇版本，可能表示：

- 多載集合太複雜。
- 參數型別太相近。
- 函式名稱應拆開。
- 介面設計不夠清楚。

# Part I：預設引數

## Section XL. 基本宣告

```cpp
void drawLine(
    int length,
    char symbol = '*'
);
```

呼叫：

```cpp
drawLine(5);
```

編譯器會視為：

```cpp
drawLine(5, '*');
```

---

![圖：CPP_Lesson_13_img15_default_argument_filling](images/lesson_13/CPP_Lesson_13_img15_default_argument_filling.png)

## Section XLI. 完整預設引數範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void drawLine(
    int length,
    char symbol = '*'
);

int main() {
    drawLine(5);
    drawLine(3, '#');

    return 0;
}

void drawLine(
    int length,
    char symbol
) {
    for (int count = 0; count < length; ++count) {
        cout << symbol;
    }

    cout << '\n';
}
```

---

## Section XLII. 預設值通常放在宣告

宣告：

```cpp
void drawLine(
    int length,
    char symbol = '*'
);
```

定義：

```cpp
void drawLine(
    int length,
    char symbol
) {
    // ...
}
```

不要在兩處重複預設值。

---

![圖：CPP_Lesson_13_img18_default_argument_declaration](images/lesson_13/CPP_Lesson_13_img18_default_argument_declaration.png)

## Section XLIII. 預設值不是新的多載

```cpp
void drawLine(
    int length,
    char symbol = '*'
);
```

仍然只有一個函式：

```cpp
drawLine(int, char)
```

它只是允許呼叫者省略第二個引數。

# Part J：多個預設引數

## Section XLIV. 合法排列

```cpp
void configure(
    int level,
    bool enabled = true,
    char mode = 'A'
);
```

可以呼叫：

```cpp
configure(2);
configure(2, false);
configure(2, false, 'B');
```

---

![圖：CPP_Lesson_13_img17_default_arguments_right_to_left](images/lesson_13/CPP_Lesson_13_img17_default_arguments_right_to_left.png)

## Section XLV. 不可省略中間引數

不能直接表示：

```text
使用 level
省略 enabled
但指定 mode
```

一般位置引數必須依順序提供。

若要指定 `mode`，也必須先提供 `enabled`。

---

## Section XLVI. 完整多個預設值範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void configure(
    int level,
    bool enabled = true,
    char mode = 'A'
);

int main() {
    cout << boolalpha;

    configure(1);
    configure(2, false);
    configure(3, true, 'B');

    return 0;
}

void configure(
    int level,
    bool enabled,
    char mode
) {
    cout << "level="
         << level
         << ", enabled="
         << enabled
         << ", mode="
         << mode
         << '\n';
}
```

---

## Section XLVII. 預設參數必須位於右側

合法：

```cpp
void example(
    int first,
    int second = 10,
    int third = 20
);
```

不合法：

```cpp
/* void example(
    int first = 1,
    int second,
    int third = 3
); */
```

一旦某個參數有預設值，右側參數也必須有預設值。

---

# Part K：預設引數的求值

## Section XLVIII. 每次呼叫時使用

預設引數不是在函式定義時只計算一次。

每次省略該引數時，都會使用預設表示式。

---

## Section XLIX. 函式呼叫作為預設值

```cpp
int nextId();

void createItem(
    int id = nextId()
);
```

每次呼叫：

```cpp
createItem();
```

都會呼叫 `nextId()` 取得預設值。

---

## Section L. 完整動態預設值範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

int nextId() {
    static int id = 0;

    ++id;
    return id;
}

void createItem(
    int id = nextId()
) {
    cout << "Item "
         << id
         << '\n';
}

int main() {
    createItem();
    createItem();
    createItem(100);

    return 0;
}
```

輸出：

```text
Item 1
Item 2
Item 100
```

> `static` 區域變數會保留前一次呼叫後的值。它的完整生命週期與用途會在後續章節進一步說明。

# Part L：多載與預設引數的衝突

## Section LI. 危險組合

```cpp
void show(int value);

void show(
    int value,
    int width = 0
);
```

呼叫：

```cpp
show(10);
```

兩個版本都可行：

```text
show(int)
show(int, int = 0)
```

因此呼叫歧義。

---

## Section LII. 不要設計成可重疊

不建議：

```cpp
void print(int value);
void print(int value, bool newline = true);
```

建議選擇其中一種：

```cpp
void print(int value, bool newline = true);
```

或使用清楚不同名稱：

```cpp
void print(int value);
void printWithOptions(int value, bool newline);
```

---

## Section LIII. 另一種重疊

```cpp
void calculate(double value);

void calculate(
    int value,
    int scale = 1
);
```

不同呼叫可能涉及：

- 精確符合
- 隱性轉換
- 預設引數
- 多個可行版本

雖然某些呼叫仍可解析，但介面理解成本提高。

---

## Section LIV. 設計原則

多載與預設引數同時使用時：

1. 列出每個可能的實際呼叫參數數量。
2. 確保每一種常見呼叫只有一個明顯版本。
3. 避免依賴細微型別轉換排名。
4. 避免一個引數數量對應多個版本。
5. 必要時改用不同函式名稱。

# Part M：多載與預設引數的選擇

## Section LV. 使用多載

適合：

```text
相同概念
但輸入型別或輸入形狀不同
```

例如：

```cpp
maximum(int, int)
maximum(double, double)
```

---

## Section LVI. 使用預設引數

適合：

```text
同一個函式
其中部分選項有常見預設值
```

例如：

```cpp
drawLine(length, symbol = '*')
```

---

## Section LVII. 使用不同名稱

適合：

```text
行為本質不同
或多載版本容易產生歧義
```

例如：

```cpp
parseInteger(...)
parseFloatingPoint(...)
```

可能比全部叫：

```cpp
parse(...)
```

更清楚。

---

## Section LVIII. 比較表

| 問題 | 建議 |
| --- | --- |
| 相同概念，不同型別 | 多載 |
| 相同概念，不同參數數量 | 多載 |
| 選項有常用預設值 | 預設引數 |
| 行為不同 | 不同函式名稱 |
| 多載與預設值造成重疊 | 重新設計 |
| 呼叫經常需要轉型 | 簡化介面 |

# Part N：面積函式多載

## Section LIX. 正方形與長方形

```cpp
double area(double side);

double area(
    double width,
    double height
);
```

相同概念：

```text
計算面積
```

輸入數量不同。

---

## Section LX. 完整面積多載範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

double area(double side) {
    return side * side;
}

double area(
    double width,
    double height
) {
    return width * height;
}

int main() {
    cout << area(5.0)
         << '\n';

    cout << area(5.0, 3.0)
         << '\n';

    return 0;
}
```

---

## Section LXI. 多載語意應一致

兩個 `area()` 都應：

```text
接收尺寸
回傳面積
```

不應讓其中一個版本突然：

- 輸出文字
- 修改全域狀態
- 回傳周長
- 讀取鍵盤輸入

# Part O：字串與數值多載

## Section LXII. 不同資料表示

可以建立：

```cpp
void printValue(int value);
void printValue(double value);
void printValue(const string& value);
```

它們都表示：

```text
顯示一個值
```

---

## Section LXIII. 完整多型別顯示範例

```cpp
// VALIDATE
#include <iostream>
#include <string>
using namespace std;

void printValue(int value) {
    cout << "int: "
         << value
         << '\n';
}

void printValue(double value) {
    cout << "double: "
         << value
         << '\n';
}

void printValue(
    const string& value
) {
    cout << "string: "
         << value
         << '\n';
}

int main() {
    printValue(10);
    printValue(2.5);

    string text =
        "C++";

    printValue(text);

    return 0;
}
```

---

## Section LXIV. 字串字面常數注意事項

呼叫：

```cpp
printValue("C++");
```

`"C++"` 的型別不是 `string`，而是字元陣列。

它可以轉換成 `string`，但若多載集合中還有：

```cpp
printValue(const char*)
```

編譯器通常會優先選更直接符合的 `const char*` 版本。

初學時避免加入過多非常接近的字串多載。

---

# Part P：函式指標與多載

## Section LXV. 多載名稱本身不一定唯一

假設：

```cpp
void show(int);
void show(double);
```

單獨寫：

```cpp
show
```

代表一個多載集合，不一定能直接決定是哪個函式。

---

## Section LXVI. 由函式指標型別決定

```cpp
void (*functionPointer)(int) =
    show;
```

指標型別要求：

```cpp
void(int)
```

因此選擇 `show(int)`。

---

## Section LXVII. 完整函式指標範例

```cpp
// VALIDATE
#include <iostream>
using namespace std;

void show(int value) {
    cout << "int: "
         << value
         << '\n';
}

void show(double value) {
    cout << "double: "
         << value
         << '\n';
}

int main() {
    void (*showInteger)(int) =
        static_cast<void (*)(int)>(
            show
        );

    void (*showDouble)(double) =
        static_cast<void (*)(double)>(
            show
        );

    showInteger(10);
    showDouble(2.5);

    return 0;
}
```

> 函式指標的完整語法與應用會在進階章節說明。本例只展示多載名稱需要目標型別才能確定版本。

# Part Q：避免過度多載

## Section LXVIII. 太多數值版本

例如同時建立：

```cpp
process(bool)
process(char)
process(short)
process(int)
process(long)
process(float)
process(double)
```

可能造成：

- 字面常數選擇不直覺。
- 隱性轉換規則難以判斷。
- 呼叫容易歧義。
- 維護成本增加。

---

## Section LXIX. 保留真正需要的版本

只建立實際有不同處理需求的版本。

若所有版本程式碼幾乎相同，之後可以考慮：

- 統一使用一個型別。
- 明確轉型。
- 使用函式模板。
- 使用不同資料模型。

---

## Section LXX. `bool` 特別容易造成意外轉換

許多數值可以轉換成 `bool`：

```text
0 → false
非 0 → true
```

因此：

```cpp
process(bool)
```

與數值多載一起存在時，可能增加理解成本。

不要只為了方便而建立沒有必要的 `bool` 多載。

# Part V：常見錯誤提醒

## Section LXXV. 常見錯誤

1. 以為參數名稱不同就能多載。
2. 只改回傳型別。
3. 將傳值參數的頂層 `const` 當成不同簽章。
4. 函式宣告與定義的參數列表不一致。
5. 多載版本的語意完全不同。
6. 建立太多相近的整數型別版本。
7. 建立太多相近的浮點型別版本。
8. 沒有判斷字面常數的實際型別。
9. 忘記 `2.5` 是 `double`。
10. 忘記 `2.5f` 才是 `float`。
11. 忘記字元字面常數是 `char`。
12. 不了解 `short` 通常提升成 `int`。
13. 認為編譯器會隨意挑選歧義版本。
14. 依賴危險或不清楚的隱性轉換。
15. 使用過多 `static_cast` 才能正常呼叫。
16. 暫時值傳給非 `const` 左值參考。
17. 以為 `const T&` 可以修改原資料。
18. 預設引數沒有從右側開始。
19. 想省略中間引數。
20. 在宣告與定義重複指定預設值。
21. 以為預設引數會建立另一個函式。
22. 以為預設值只在程式啟動時計算一次。
23. 多載和預設引數提供相同有效引數數量。
24. 建立 `f(int)` 與 `f(int, int = 0)`。
25. `bool` 多載吸收非零數值造成意外。
26. 多載集合中加入過多可隱性轉換的版本。
27. 函式指標沒有提供目標型別。
28. 字串字面常數在 `string` 與 `const char*` 多載間選擇不如預期。
29. 為了展示語法而建立難以維護的介面。
30. 沒有測試邊界型別與省略引數的呼叫。

# Part W：Mermaid 流程圖

## Section LXXVI. 多載與預設引數流程圖

### 1. 多載解析

```mermaid
flowchart TD
    A[遇到函式呼叫] --> B[收集同名候選函式]
    B --> C[排除引數數量或型別不合法版本]
    C --> D{剩下幾個可行函式}
    D -- 0 個 --> E[找不到相符函式]
    D -- 1 個 --> F[選擇該版本]
    D -- 多個 --> G[比較轉換品質]
    G --> H{有唯一最佳版本嗎}
    H -- 是 --> F
    H -- 否 --> I[歧義編譯錯誤]
```

### 2. 轉換優先順序

```mermaid
flowchart TD
    A[比較可行版本] --> B{有精確符合嗎}
    B -- 是 --> C[優先精確符合]
    B -- 否 --> D{有型別提升嗎}
    D -- 是 --> E[優先提升]
    D -- 否 --> F[比較一般標準轉換]
    F --> G{仍然同樣合適嗎}
    G -- 是 --> H[歧義]
    G -- 否 --> I[選擇較佳版本]
```

### 3. 預設引數

```mermaid
flowchart TD
    A[呼叫函式] --> B{是否省略右側引數}
    B -- 否 --> C[使用呼叫者提供值]
    B -- 是 --> D[從宣告取得預設表示式]
    D --> E[求值並補上引數]
    C --> F[執行同一個函式]
    E --> F
```

### 4. 參考多載

```mermaid
flowchart TD
    A[取得引數] --> B{是可修改左值嗎}
    B -- 是 --> C[可選 T& 與 const T&]
    C --> D[通常選 T&]
    B -- 否 --> E{可綁定 const T& 嗎}
    E -- 是 --> F[選 const T&]
    E -- 否 --> G[沒有可行版本]
```

### 5. 多載與預設值衝突

```mermaid
flowchart TD
    A[呼叫 f 一個引數] --> B[f 一參數版本可行]
    A --> C[f 兩參數版本有預設值也可行]
    B --> D[兩者參數符合程度相同]
    C --> D
    D --> E[歧義]
```

### 6. 選擇介面方式

```mermaid
flowchart TD
    A[需要設計函式介面] --> B{操作概念相同嗎}
    B -- 否 --> C[使用不同名稱]
    B -- 是 --> D{輸入型別或數量不同嗎}
    D -- 是 --> E[考慮多載]
    D -- 否 --> F{只是部分選項有常用值嗎}
    F -- 是 --> G[考慮預設引數]
    F -- 否 --> H[使用單一函式]
```

### 7. 消除歧義

```mermaid
flowchart TD
    A[呼叫發生歧義] --> B{可以移除重疊版本嗎}
    B -- 是 --> C[簡化多載集合]
    B -- 否 --> D{行為可改用不同名稱嗎}
    D -- 是 --> E[重新命名]
    D -- 否 --> F[使用明確型別或 static_cast]
```

### 8. 預設引數排列

```mermaid
flowchart TD
    A[某參數開始有預設值] --> B[檢查右側所有參數]
    B --> C{右側都有預設值嗎}
    C -- 是 --> D[宣告合法]
    C -- 否 --> E[宣告不合法]
```
