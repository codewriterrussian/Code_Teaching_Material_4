# Student Handouts

This directory contains Markdown handouts for students.

## File Naming

Use the following naming pattern:

- Lesson_01_Topic_Name.md
- Lesson_02_Topic_Name.md

## Images

Place images inside a lesson-specific directory.

Example structure:

- images/Lesson_01_Topic_Name/Lesson_01_Topic_Name_img1.png
- images/Lesson_01_Topic_Name/Lesson_01_Topic_Name_img2.png

Reference an image in a Markdown handout with:

![Description](images/Lesson_01_Topic_Name/Lesson_01_Topic_Name_img1.png)
