## Section IV. 寫題目前的提醒

### 1. 資料型態不是裝飾

下面兩個變數雖然都能保存數字，但用途不同：

```c
int student_count = 30;
double temperature = 26.5;
```

- `student_count` 表示人數，不需要小數。
- `temperature` 可能包含小數部分。

型態會影響：

```text
可以保存什麼資料
可以表示多大的範圍
運算時如何處理
printf() 與 scanf() 要使用什麼格式
```

---

### 2. 不要假設所有電腦的型態大小完全相同

常見電腦上，`int` 經常占用 4 bytes，但 C 語言不要求所有環境都使用完全相同的大小。

請使用：

```c
sizeof(int)
```

實際確認目前環境的結果。

---

### 3. `sizeof` 的結果使用 `%zu` 輸出

```c
printf("%zu\n", sizeof(int));
```

`sizeof` 的結果型態是 `size_t`，適合使用 `%zu`。

---

### 4. 格式指定符必須與資料型態相符

例如：

```c
int count = 10;
double price = 25.5;
char grade = 'A';
```

對應輸出：

```c
printf("%d\n", count);
printf("%f\n", price);
printf("%c\n", grade);
```

使用錯誤的格式指定符，可能得到錯誤結果，甚至造成未定義行為。

---

### 5. `printf()` 與 `scanf()` 的浮點格式不完全一樣

![printf 與 scanf 格式指定符對照](images/C_Lesson_04_img06_format_specifiers.png)

輸出時：

```c
float f = 1.5f;
double d = 2.5;

printf("%f\n", f);
printf("%f\n", d);
```

輸入時：

```c
scanf("%f", &f);   // float
scanf("%lf", &d);  // double
```

本章最重要的對照：

| 型態 | `printf()` | `scanf()` |
| --- | --- | --- |
| `int` | `%d` | `%d` |
| `float` | `%f` | `%f` |
| `double` | `%f` | `%lf` |
| `char` | `%c` | `%c` |

---

### 6. 單引號與雙引號不一樣

單一字元使用單引號：

```c
char letter = 'A';
```

字串使用雙引號：

```c
printf("A\n");
```

請分辨：

```text
'A'  → 一個字元常數
"A"  → 一個字串
```

---

### 7. 整數除法會捨去小數部分

```c
int result = 5 / 2;
```

`result` 會得到：

```text
2
```

不是 `2.5`，因為左右兩邊都是整數。

---

### 8. 浮點數不一定能精確保存每一個小數

```c
double value = 0.1;
```

電腦通常會保存一個非常接近 `0.1` 的值，但不一定是數學上完全精確的 `0.1`。

因此，不要因為浮點計算出現很小的誤差，就立刻認為程式一定寫錯。

---

### 9. 超過型態範圍不是安全的做法

若數值可能很大，就要選擇能容納它的型態。

例如計算大型人口數、檔案大小或長時間累積結果時，可能需要：

```c
long long total;
```

不要依賴有號整數超過範圍後會產生某個固定結果。

## Section V. 核心概念說明

### 1. 什麼是資料型態？

資料型態可以理解成資料的「使用說明」。

例如：

```c
int age = 18;
double height = 172.5;
char grade = 'A';
```

程式看到不同型態後，會知道：

```text
age    要當成整數處理
height 要當成浮點數處理
grade  要當成一個字元編碼處理
```

同一組位元若使用不同方式解讀，可能代表完全不同的資料。

---

### 2. bit 與 byte

![bit byte 與可表示狀態數量](images/C_Lesson_04_img02_bits_and_bytes.png)

一個 bit 可以表示：

```text
0 或 1
```

多個 bit 組合後，可以表示更多狀態。

例如兩個 bit：

```text
00
01
10
11
```

共有四種組合。

一般關係：

```text
n 個 bit 可以形成 2^n 種組合
```

C 語言使用 byte 作為計算物件大小的單位。

在目前常見的個人電腦上：

```text
1 byte 通常是 8 bits
```

---

### 3. 使用 `sizeof` 查看占用空間

![不同平台的資料型態大小](images/C_Lesson_04_img03_sizeof_platforms.png)

```c
#include <stdio.h>

int main(void) {
    printf("short: %zu byte(s)\n", sizeof(short));
    printf("int: %zu byte(s)\n", sizeof(int));
    printf("long: %zu byte(s)\n", sizeof(long));
    printf("long long: %zu byte(s)\n", sizeof(long long));
    printf("float: %zu byte(s)\n", sizeof(float));
    printf("double: %zu byte(s)\n", sizeof(double));
    printf("char: %zu byte(s)\n", sizeof(char));
    return 0;
}
```

不同電腦或編譯器的結果可能不同。

一定可以知道的是：

```c
sizeof(char)
```

結果必定是 `1`，因為 C 語言把一個 `char` 的大小定義為一個 byte。

---

### 4. 常見的內建資料型態

| 類別 | 常見型態 | 主要用途 |
| --- | --- | --- |
| 整數 | `short`、`int`、`long`、`long long` | 保存沒有小數部分的數值 |
| 無號整數 | `unsigned short`、`unsigned int` 等 | 保存零與正整數 |
| 浮點數 | `float`、`double`、`long double` | 保存帶有小數部分或很大、很小的數值 |
| 字元 | `char` | 保存一個小型整數編碼，常用來表示字元 |
| 無值 | `void` | 表示沒有資料值，之後學習函式時會使用 |

本章以這三種最常用型態為主：

```c
int
double
char
```

---

### 5. 整數型態

![C 語言常見整數型態](images/C_Lesson_04_img04_integer_types.png)

整數型態用來保存：

```text
-10
0
25
1000
```

不能保存小數部分。

最常用的整數型態：

```c
int number = 100;
```

其他整數型態：

```c
short small_number = 100;
long large_number = 100000L;
long long very_large_number = 10000000000LL;
```

不同型態提供不同的最低可表示範圍，實際大小仍要以目前環境為準。

---

### 6. `signed` 與 `unsigned`

![signed 與 unsigned 整數的差異](images/C_Lesson_04_img05_signed_vs_unsigned.png)

一般的：

```c
int number;
```

通常等同於：

```c
signed int number;
```

可以表示：

```text
負數、零、正數
```

無號整數：

```c
unsigned int count;
```

只表示：

```text
零、正數
```

無號整數不需要保留負數範圍，因此能把可用組合用在較大的非負數上。

---

### 7. 輸出不同整數型態

```c
#include <stdio.h>

int main(void) {
    int a = -20;
    unsigned int b = 300U;
    long c = 100000L;
    long long d = 9000000000LL;

    printf("int: %d\n", a);
    printf("unsigned int: %u\n", b);
    printf("long: %ld\n", c);
    printf("long long: %lld\n", d);
    return 0;
}
```

常見對照：

| 型態 | `printf()` 格式 |
| --- | --- |
| `int` | `%d` |
| `unsigned int` | `%u` |
| `long` | `%ld` |
| `unsigned long` | `%lu` |
| `long long` | `%lld` |
| `unsigned long long` | `%llu` |

---

### 8. 整數範圍與溢位

每個整數型態只能表示有限範圍。

可以把它想成一個有容量限制的盒子：

```text
盒子容量足夠 → 可以正確保存
超過盒子容量 → 發生溢位問題
```

有號整數超過範圍時，不應依賴它產生特定結果。

避免方式：

1. 先估計可能的最大值與最小值。
2. 選擇更大的整數型態。
3. 計算前思考中間結果是否也可能超過範圍。

---

### 9. 浮點數型態

浮點數用來近似表示實數，例如：

```text
3.14
-0.25
10000000000.0
0.000001
```

常見型態：

```c
float
double
long double
```

一般入門程式若需要小數，優先考慮：

```c
double value;
```

因為 `double` 通常比 `float` 提供較高精確度。

---

### 10. 有效數字與精確度

![float 與 double 的精確度](images/C_Lesson_04_img07_float_precision.png)

觀察圓周率：

```text
3.141592653589793...
```

若只保留四個有效數字：

```text
3.142
```

若保留更多有效數字：

```text
3.14159265
```

浮點型態能保存的有效數字有限。

通常：

```text
float  的精確度較低
double 的精確度較高
```

這不代表 `double` 能精確保存所有小數，只代表它通常能保留更多有效資訊。

---

### 11. 科學記號與浮點表示

大型數字：

```text
12345000000
```

可以寫成：

```text
1.2345 × 10^10
```

小型數字：

```text
0.0078901
```

可以寫成：

```text
7.8901 × 10^-3
```

C 程式中的科學記號：

```c
double large = 1.2345e10;
double small = 7.8901e-3;
```

其中 `e10` 表示乘以 `10^10`，`e-3` 表示乘以 `10^-3`。

### 12. 輸出浮點數

```c
#include <stdio.h>

int main(void) {
    float temperature = 23.45f;
    double pi = 3.141592653589793;

    printf("temperature: %f\n", temperature);
    printf("pi: %f\n", pi);
    printf("pi to 3 decimal places: %.3f\n", pi);
    printf("scientific notation: %e\n", pi);
    return 0;
}
```

格式：

| 格式 | 用途 |
| --- | --- |
| `%f` | 一般小數形式 |
| `%.2f` | 顯示到小數點後 2 位 |
| `%e` | 科學記號形式 |
| `%g` | 依數值選擇較精簡的形式 |

注意：

```text
顯示到小數點後幾位，不等於變數只保存那些位數。
```

`printf()` 的顯示格式只控制畫面呈現方式。

### 13. 輸入不同型態的資料

```c
#include <stdio.h>

int main(void) {
    int age;
    float temperature;
    double height;
    char grade;

    printf("Age: ");
    scanf("%d", &age);

    printf("Temperature: ");
    scanf("%f", &temperature);

    printf("Height: ");
    scanf("%lf", &height);

    printf("Grade: ");
    scanf(" %c", &grade);

    printf("age = %d\n", age);
    printf("temperature = %.1f\n", temperature);
    printf("height = %.1f\n", height);
    printf("grade = %c\n", grade);
    return 0;
}
```

注意字元輸入使用：

```c
scanf(" %c", &grade);
```

`%c` 前面的空白可以略過前一次輸入留下的空白字元或換行字元。

### 14. 字面常數是什麼？

直接寫在程式中的固定值稱為字面常數。

```c
int count = 10;
double price = 29.5;
char level = 'B';
```

其中：

```text
10    是整數字面常數
29.5  是浮點字面常數
'B'   是字元常數
```

---

### 15. 整數字面常數的後綴

```c
10       // 通常是 int
10U      // unsigned int
10L      // long
10UL     // unsigned long
10LL     // long long
10ULL    // unsigned long long
```

後綴可使用大寫或小寫，但大寫通常較容易閱讀。

例如小寫 `l` 容易與數字 `1` 混淆，因此：

```c
1000L
```

通常比：

```c
1000l
```

更清楚。

---

### 16. 浮點字面常數的後綴

沒有後綴的小數字面常數通常是 `double`：

```c
double a = 3.14;
```

加入 `f` 或 `F` 表示 `float`：

```c
float b = 3.14f;
```

加入 `L` 表示 `long double`：

```c
long double c = 3.14L;
```

### 17. 整數除法與浮點除法

![整數除法與浮點除法的差異](images/C_Lesson_04_img08_integer_vs_float_division.png)

```c
#include <stdio.h>

int main(void) {
    printf("5 / 2 = %d\n", 5 / 2);
    printf("5.0 / 2 = %f\n", 5.0 / 2);
    printf("5 / 2.0 = %f\n", 5 / 2.0);
    return 0;
}
```

Result:

```text
5 / 2 = 2
5.0 / 2 = 2.500000
5 / 2.0 = 2.500000
```

規則先簡化成：

```text
整數 ÷ 整數 → 整數除法
只要其中一邊是浮點數 → 浮點運算
```

---

### 18. 隱性型態轉換

```c
int count = 3;
double average = count / 2.0;
```

運算時，`count` 會被轉換成適合與 `2.0` 一起運算的浮點形式。

結果：

```text
1.5
```

這種由編譯器自動完成的轉換稱為隱性型態轉換。

---

### 19. 賦值時的型態轉換

```c
double price = 19.95;
int whole = price;
```

將 `double` 指派給 `int` 時，小數部分會被捨去：

```text
whole 取得 19
```

這不是四捨五入。

反方向：

```c
int score = 90;
double value = score;
```

`value` 會得到浮點形式的 `90.0`。

---

### 20. 強制型態轉換

語法：

```c
(目標型態)值或運算式
```

例如：

```c
int total = 5;
int count = 2;
double average = (double)total / count;
```

`total` 先轉成 `double`，因此執行浮點除法。

結果：

```text
2.5
```

完整程式：

```c
#include <stdio.h>

int main(void) {
    int total = 5;
    int count = 2;
    double average = (double)total / count;

    printf("average = %.2f\n", average);
    return 0;
}
```

---

### 21. 強制轉換的位置很重要

![強制型態轉換的位置比較](images/C_Lesson_04_img09_cast_position.png)

錯誤目標：想得到 `2.5`。

```c
double result = (double)(5 / 2);
```

執行順序：

```text
5 / 2 先做整數除法得到 2
再把 2 轉成 double
```

結果仍然是：

```text
2.0
```

正確寫法：

```c
double result = (double)5 / 2;
```

先將其中一個運算元轉成浮點數，再執行除法。

### 22. `char` 字元型態

```c
char letter = 'A';
```

`char` 主要保存一個小型整數值，常用來表示一個字元的編碼。

可以把它理解成兩個角度：

```text
畫面角度：字元 A
儲存角度：A 對應的數字編碼
```

C 語言不會直接把字元形狀存入變數，而是保存對應的數字編碼。

---

### 23. 字元編碼

字元編碼建立以下對應：

```text
字元 ↔ 數字
```

在常見 ASCII 編碼中：

```text
'A' 對應 65
'B' 對應 66
'a' 對應 97
'0' 對應 48
```

ASCII 包含：

- 英文字母。
- 數字字元。
- 常用符號。
- 控制字元。

本章的字元運算以 ASCII 或相容編碼的常見環境為基礎。

---

### 24. 使用 `%c` 與 `%d` 觀察同一個 `char`

![同一個 char 的字元與編碼顯示方式](images/C_Lesson_04_img11_char_two_views.png)

```c
#include <stdio.h>

int main(void) {
    char letter = 'A';

    printf("as a character: %c\n", letter);
    printf("as a number: %d\n", letter);
    return 0;
}
```

可能輸出：

```text
as a character: A
as a number: 65
```

同一份資料可以用不同格式解讀：

```text
%c → 顯示成字元
```

### 27. 大寫轉小寫練習

![ASCII 大寫字母轉小寫字母](images/C_Lesson_04_img12_ascii_case_conversion.png)

```c
    return 0;
}
```


### 28. 如何選擇資料型態？

![依照資料用途選擇基本資料型態](images/C_Lesson_04_img01_type_selection.png)

| 資料用途 | 建議型態 | 原因 | `printf()` | `scanf()` |
| --- | --- | --- | --- | --- |
| 一般整數 | `int` | 不需要小數部分 | `%d` | `%d` |
| 非常大的整數 | `long long` | 通常提供較大的整數範圍 | `%lld` | `%lld` |
| 一般小數 | `double` | 通常比 `float` 有更高精確度 | `%f` | `%lf` |
| 單一英文字元 | `char` | 保存一個字元編碼 | `%c` | `%c` |

選擇時依序思考：

```text
資料有沒有小數？
是否需要負數？
可能有多大或多小？
需要多少精確度？
是數值還是單一字元？
```

## Section V-A. 容易搞混的重點

### 1. 型態大小、數值範圍與精確度不是同一件事

| 概念 | 問題 |
| --- | --- |
| 大小 | 占用多少 byte？ |
| 範圍 | 最小與最大可以表示多少？ |
| 精確度 | 能保留多少有效資訊？ |

`sizeof` 只能直接回答大小，不能單獨告訴你完整的範圍與精確度。

---

### 2. `printf()` 的 `%f` 與 `scanf()` 的 `%f` 不要混淆

```c
float f;
double d;
```

輸出：

```c
printf("%f", f);
printf("%f", d);
```

輸入：

```c
scanf("%f", &f);
scanf("%lf", &d);
```

記憶方式：

```text
scanf 需要精確知道要寫入 float 還是 double
```

---

### 3. `'A'`、`"A"` 與 `65` 是不同寫法

![字元字串與整數常數的差異](images/C_Lesson_04_img10_char_string_integer.png)

```text
'A'  → 字元常數
"A"  → 字串
65   → 整數常數
```

在 ASCII 環境中，`'A'` 的編碼值通常是 `65`，但寫程式時應依用途選擇最清楚的表示方式。

例如要表示字母 A：

```c
char letter = 'A';
```

比下面更容易理解：

```c
char letter = 65;
```

---

### 4. `5 / 2` 與 `5.0 / 2` 不同

```c
5 / 2
```

兩邊都是整數，得到：

```text
2
```

```c
5.0 / 2
```

至少一邊是浮點數，得到：

```text
2.5
```

---

### 5. 先除法再轉型，無法找回已經消失的小數

```c
(double)(5 / 2)
```

得到 `2.0`，因為小數在整數除法時已經消失。

要改成：

```c
(double)5 / 2
```

---

### 6. `%c` 與 `%d` 可以用不同方式顯示同一個 `char`

```c
char value = 'A';
```

```c
printf("%c\n", value);  // A
printf("%d\n", value);  // 常見 ASCII 環境為 65
```

資料沒有改變，改變的是輸出時的解讀方式。


小數部分被捨去。

---

### 10. 使用 `float` 卻期待非常高的精確度

若需要一般較高精確度的小數計算，優先考慮：

```c
double
```

---

### 11. 直接比較或顯示浮點數後，誤以為所有位數都應完全準確

浮點數是有限近似，某些小數會出現極小誤差。

---

### 12. 讓整數結果超過可表示範圍

計算大型結果前，先評估型態容量，必要時使用：

```c
long long
```

---

### 13. 用數字編碼代替清楚的字元常數

較難閱讀：

```c
char letter = 65;
```

較清楚：

```c
char letter = 'A';
```

---

### 14. 認為 `char` 只能當文字，不能參與運算

`char` 保存的是小型整數值，因此能參與整數運算。

但運算結果是否對應想要的字元，仍取決於字元編碼與輸入範圍。

---

### 15. 只因為型態更大，就認為它一定更適合

選擇型態應考慮：

```text
用途
範圍
精確度
可讀性
輸入輸出格式
```

不是永遠選最大的型態。

## Section XIII. Mermaid 流程圖

### 1. 選擇基本資料型態

```mermaid
flowchart TD
    A[要保存什麼資料？] --> B{單一字元？}
    B -- 是 --> C[使用 char]
    B -- 否 --> D{需要小數？}
    D -- 是 --> E[一般使用 double]
    D -- 否 --> F{數值可能非常大？}
    F -- 是 --> G[考慮 long long]
    F -- 否 --> H[一般使用 int]
```

---

### 2. 平均數運算判斷

```mermaid
flowchart TD
    A[準備執行除法] --> B{兩個運算元都是整數？}
    B -- 否 --> C[執行浮點運算]
    B -- 是 --> D{需要保留小數？}
    D -- 否 --> E[執行整數除法]
    D -- 是 --> F[先將其中一個運算元轉成 double]
    F --> C
```

---

### 3. `scanf()` 格式選擇

```mermaid
flowchart TD
    A[確認變數型態] --> B{int?}

    D -- 是 --> E[使用 %f]
    D -- 否 --> F{double?}
    F -- 是 --> G[使用 %lf]
    F -- 否 --> H{char?}
    H -- 是 --> I[使用空白加 %c]
```
