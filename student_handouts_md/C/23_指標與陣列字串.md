## Section II. 今天的學習方式

1. 函式呼叫題先畫兩組變數：

   - 被呼叫函式參數
2. 傳值時畫出「複製值」的箭頭。
3. 傳位址時畫出「複製位址」的箭頭。
4. 每一次看到 `*pointer`，都追蹤它指向哪一個呼叫端物件。
5. `swap()` 題先使用值參數觀察失敗，再改成指標參數。
6. `sort()` 題分辨：
   - 比較的是指標值
   - 還是指標所指的整數值
7. 決定傳值或傳位址時，先問：
   - 函式需要修改呼叫端嗎？
   - 資料能否直接複製？
   - 複製成本是否合理？
8. 指標算術題一律配合陣列記憶體圖。
9. 不將指標加一理解成一般整數位址加一個位元組。
10. 對 `pointer + n` 寫出它對應的陣列元素。
11. 指標相減時，先確認兩個指標來自同一個陣列。
12. 陣列與指標題同時寫出：
    - 完整陣列物件
    - 第一個元素位址
13. 使用 `v + length` 時，只把它當成終點位置，不讀取該位置。
14. 下標題將：
    ```c
    a[b]
    ```
    改寫成：
    ```c
    *(a + b)
    ```
15. 函式陣列參數題將所有寫法先改讀成指標參數。
16. `*p++` 題先根據優先順序加括號：
    ```c
    *(p++)
    ```
17. 字串題要分別畫出：
    - 可修改的字元陣列
    - 指標變數
    - 字串字面常數所在的字元序列
18. `const` 題先確認限制的是：
    - 指標所指物件
    - 還是指標本身
19. 本章來源主要涵蓋 `const Type *`；其他 `const` 指標形式不作為主要內容。
20. 字串複製題始終檢查目的地容量與 `'\0'`。
21. 來源投影片中的程式逐步推導會保留，但完整範例使用現代 C17 可通過嚴格編譯的寫法。

# Part A：指標與函式

## Section IV. 函式呼叫時複製值

### 1. 普通參數不會改變呼叫端

```c
#include <stdio.h>

void add_one(int number);

int main(void) {
    int number = 3;

    add_one(number);
    printf("%d\n", number);

    return 0;
}

void add_one(int number) {
    number = number + 1;
}
```

輸出：

```text
3
```

呼叫：

```c
add_one(number);
```

會將 `number` 的整數值複製到函式參數。

函式只知道參數副本的值，不知道呼叫端原變數位於哪裡。

---

### 2. 函式內的參數是另一個物件

概念：

```text
main 的 number
    │ 複製值
    ▼
add_one 的 number
```

兩個變數名稱雖然可以相同，但代表不同物件。

---

## Section V. 函式呼叫時複製位址

### 3. 將變數位址傳入函式

```c
#include <stdio.h>

void add_one(int *number);

int main(void) {
    int number = 3;

    add_one(&number);
    printf("%d\n", number);

    return 0;
}

void add_one(int *number) {
    *number = *number + 1;
}
```

輸出：

```text
4
```

---

### 4. 參數保存的是位址副本

呼叫：

```c
add_one(&number);
```

會將：

```c
&number
```

這個位址值複製到指標參數。

函式使用：

```c
*number
```

找到呼叫端原本的整數。

---

### 5. 傳值與傳位址比較

| 寫法 | 函式取得 | 函式內修改的對象 |
| --- | --- | --- |
| `add_one(number)` | 整數值副本 | 函式參數副本 |
| `add_one(&number)` | 位址值副本 | 位址所指的呼叫端整數 |

更精確地說，C 的引數仍然全部是**以值傳遞**：

- 普通參數複製資料值。
- 指標參數複製位址值。

## Section VI. 使用函式交換兩個整數

### 6. 交換的基本步驟

```c
int temporary = a;
a = b;
b = temporary;
```

暫存變數保存第一個值，避免它被覆蓋後遺失。

---

### 7. 錯誤方向：只把整數值交給 `swap()`

```c
void swap(int a, int b) {
    int temporary = a;
    a = b;
    b = temporary;
}
```

即使函式內的 `a`、`b` 成功交換，呼叫端仍然不變。

---

### 8. 正確交換函式

```c
#include <stdio.h>

void swap(int *a, int *b);

int main(void) {
    int a = 3;
    int b = 5;

    swap(&a, &b);

    printf("a = %d\n", a);
    printf("b = %d\n", b);

    return 0;
}

void swap(int *a, int *b) {
    int temporary = *a;

    *a = *b;
    *b = temporary;
}
```

輸出：

```text
a = 5
b = 3
```

## Section VII. 使用函式排序兩個整數

### 10. 直接排序

```c
if (a > b) {
    int temporary = a;
    a = b;
    b = temporary;
}
```

---

### 11. 使用交換函式

```c
if (a > b) {
    swap(&a, &b);
}
```

---

### 12. `sort()` 也必須接收位址

錯誤概念：

```c
void sort(int a, int b) {
    if (a > b) {
        swap(&a, &b);
    }
}
```

這只會排序 `sort()` 內的兩個參數副本。

---

### 13. 正確排序函式

```c
#include <stdio.h>

void swap(int *a, int *b);
void sort_two(int *a, int *b);

int main(void) {
    int a = 5;
    int b = 3;

    sort_two(&a, &b);

    printf("a = %d\n", a);
    printf("b = %d\n", b);

    return 0;
}

void sort_two(int *a, int *b) {
    if (*a > *b) {
        swap(a, b);
    }
}

void swap(int *a, int *b) {
    int temporary = *a;

    *a = *b;
    *b = temporary;
}
```

輸出：

```text
a = 3
b = 5
```

---

### 14. 為什麼呼叫 `swap(a, b)` 不再加 `&`？

在 `sort_two()` 中：

```c
a
b
```

本來就已經是 `int *`。

`swap()` 也需要 `int *`，因此直接傳入：

```c
swap(a, b);
```

如果寫：

```c
swap(&a, &b);
```

型別會變成 `int **`，不是本題需要的型別。

## Section VIII. 該傳變數值還是位址？

### 15. 來源提出的基本原則

> 可以傳值時，優先傳值。

來源列出的理由：

- 複製一份資料較不怕被函式修改。
- 可以維持函式間較乾淨的關係。
- 使用較方便，可以直接傳入一般常數。

---

### 16. 求兩數最大值適合傳值

```c
#include <stdio.h>

int max_two(int a, int b);

int main(void) {
    int a = 3;
    int b = 5;

    printf("%d\n", max_two(a, b));
    printf("%d\n", max_two(3, 5));

    return 0;
}

int max_two(int a, int b) {
    if (a > b) {
        return a;
    }

    return b;
}
```

這個函式只需要讀取兩個值，不需要修改呼叫端。

---

### 17. 指標版本較不方便

若函式介面是：

```c
int max_two_pointer(
    const int *a,
    const int *b
);
```

呼叫變數時需要：

```c
max_two_pointer(&a, &b);
```

而不能直接寫：

```c
max_two_pointer(&3, &5);
```

因為一般整數常數不是可取址的物件。

---

### 18. 來源列出的例外規則

應傳位址的典型情況：

1. 作為引數的變數在呼叫函式後必須改變。
   - 例如數值交換。
2. 資料無法直接整體複製。
   - 例如陣列與字串。
3. 複製成本太高。
   - 例如較複雜或較大的結構。

---

### 19. 教材補充：只讀指標參數

若資料很大但函式只需要讀取，可以結合位址與 `const`：

```c
int sum_values(
    const int values[],
    int length
);
```

這表示函式透過位址讀取資料，但不應修改陣列元素。

# Part B：指標與陣列

## Section IX. 指標對整數的加減運算

### 20. 陣列元素有連續位置

```c
int values[5];
```

可以畫成：

```text
values[0] values[1] values[2] values[3] values[4]
```

每一個元素都有各自的 `int *` 位址：

```text
&values[0]
&values[1]
&values[2]
&values[3]
&values[4]
```

---

### 21. 指標加一移動到下一個元素

## Section XIV. 在函式間傳遞陣列

### 45. 固定三個元素的最大值函式


```c
int values[3] = {3, 9, 7};

```

---

### 46. 參數中的陣列寫法會調整成指標

在函式參數中：

```c
int maxv(int values[3]);
```

```c
int maxv(int values[]);
```

```c
int maxv(int *values);
```

三者的參數都以 `int *` 處理。

參數中的 `[3]` 不會讓函式取得一份三元素陣列副本。

---

### 47. 呼叫時傳入第一個元素位址

```c
maxv(values);
```

在這個運算式中，`values` 轉成：

```c
&values[0]
```

因此也可以概念上寫成：

```c
maxv(&values[0]);
```

---

### 48. 函式中可用兩種寫法

```c
values[i]
```

或：

```c
*(values + i)
```

兩者等價。

---

### 49. 同一函式處理不同長度

```c
#include <stdio.h>

int maxv(const int *values, int length);

int main(void) {
    int first[3] = {3, 9, 7};
    int second[5] = {3, 9, 1, 2, 7};

    printf("%d\n", maxv(first, 3));
    printf("%d\n", maxv(second, 5));

    return 0;
}

int maxv(const int *values, int length) {
    int i;
    int maximum = values[0];

    for (i = 1; i < length; i++) {
        if (values[i] > maximum) {
            maximum = values[i];
        }
    }

    return maximum;
}
```

前提：

```text
length >= 1
```

---

### 50. 為什麼仍要傳 `length`？

第一個元素位址只告訴函式：

```text
陣列從哪裡開始
```

不會告訴函式：

```text
後面有多少個合法元素
```

### 51. 使用下標將陣列歸零

```c

}
```

### 52. 使用指標下標

```c
int *pointer = values;

    pointer[i] = 0;
}
```

---

### 53. 使用指標移動

```c
int *pointer;

for (
    pointer = values;
    pointer != values + 5;
    pointer++

    *pointer = 0;
```

### 54. 使用 `while`

```c

    *pointer = 0;
```

### 55. 合併成 `*pointer++`

來源最後化簡：

```c
*pointer++ = 0;
```

由運算子優先順序判讀：

```c
*(pointer++) = 0;
```

步驟：

1. 使用目前 `pointer` 指向的元素。
2. 將該元素設為 `0`。
3. 指標再移到下一個元素。

---

### 56. 完整歸零程式

```c
#include <stdio.h>

int main(void) {
    int values[5] = {1, 2, 3, 4, 5};
    int *pointer = values;
    int i;

    while (pointer != values + 5) {
        *pointer++ = 0;
    }

    for (i = 0; i < 5; i++) {
        printf("%d ", values[i]);
    }

    printf("\n");

    return 0;
}
```

輸出：

```text
0 0 0 0 0
```

---

### 57. 教材補充：三種容易混淆的寫法

來源主要推導：

```c
*pointer++
```

以下為優先順序補充：

| 寫法 | 加括號後 | 效果 |
| --- | --- | --- |
| `*pointer++` | `*(pointer++)` | 使用目前元素，再移動指標 |
| `(*pointer)++` | `(*pointer)++` | 增加目前元素的值，指標不動 |
| `*++pointer` | `*(++pointer)` | 先移動指標，再存取新元素 |

### 61. 可修改的字元陣列

輸出：

字串字面常數的內容在初始化時被複製到 `text` 陣列中。

### 62. 指向字串字面常數

來源示範：


## Section XXII. 指標與 `const` 的轉型方向

### 76. 可修改指標可轉成唯讀指標

```c
char array[] = "test";

const char *readonly = writable;
```

合法。

`readonly` 可以讀取同一批字元，但不能透過它修改。

### 77. 陣列也可轉成 `const char *`

```c

const char *readonly = "test";
```

```c
#include <stdio.h>

int main(void) {

}
```

輸出：

```text
Test
```


```c
char source[5] = "test";
```

## Section XXIV. 自行使用指標複製字串

### 84. 基本函式

```c
void string_copy(
    char *destination,
    const char *source
) {
    while (*source != '\0') {
        *destination = *source;
        destination++;
        source++;
    }

    *destination = '\0';
}
```

---

### 85. 為什麼來源是 `const char *`？

函式只需要讀取來源，不應修改來源文字。

---

### 86. 為什麼目的地是 `char *`？

函式必須將字元寫入目的地，因此目的地不能是唯讀字元指標。

---

### 87. 最後一定要補 `'\0'`

迴圈在來源的 `'\0'` 前停止。

因此結束後要：

```c
*destination = '\0';
```

否則目的地不是完整 C 字串。

---

### 88. 完整自行複製範例

```c
#include <stdio.h>

void string_copy(
    char *destination,
    const char *source
);

int main(void) {
    const char source[] = "test";
    char destination[5];

    string_copy(destination, source);

    printf("%s\n", destination);

    return 0;
}

void string_copy(
    char *destination,
    const char *source
) {
    while (*source != '\0') {
        *destination = *source;
        destination++;
        source++;
    }

    *destination = '\0';
}
```

---

### 89. 更精簡的寫法

```c
while ((*destination++ = *source++) != '\0') {
}
```

這會連 `'\0'` 一起複製。

但運算子較密集，初學階段應先熟悉清楚版本。

## Section XXV. 使用標準函式 `strcpy()`

### 90. 函式介面

```c
char *strcpy(
    char *destination,
    const char *source
);
```

需要：

```c
#include <string.h>
```

---

### 91. 基本使用

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    const char source[] = "test";
    char destination[5];

    strcpy(destination, source);

    printf("%s\n", destination);

    return 0;
}
```

---

### 92. `strcpy()` 的兩個參數

| 參數 | 型別 | 需要 |
| --- | --- | --- |
| `destination` | `char *` | 指向可寫且容量足夠的字元空間 |
| `source` | `const char *` | 指向有效且以 `'\0'` 結束的字串 |

---

### 93. 目的地必須有足夠容量

來源：

```text
"test"
```

需要：

```text
't' 'e' 's' 't' '\0'
```

共五格。

因此：

```c
char destination[5];
```

剛好足夠。

若容量不足，`strcpy()` 會寫到陣列外部。

---

### 94. 未初始化指標不能當作目的地

錯誤：

```c
char *destination;

strcpy(destination, source);
```

`destination` 尚未指向任何已配置、可寫且足夠大的空間。

---

### 95. `const` 陣列不能作為目的地

錯誤：

```c
const char destination[5] = {0};

/* strcpy(destination, source); */
```

`strcpy()` 需要：

```c
char *
```

不能寫入 `const char` 元素。

---

### 96. `const char *` 也不能作為目的地

錯誤：

```c
const char *destination;

/* strcpy(destination, source); */
```

即使它稍後指向某處，`const char *` 介面也不允許透過該指標寫入字元。

---

### 97. `strcpy()` 不知道目的地容量

它只依來源的 `'\0'` 決定何時停止。

呼叫者必須自行保證：

```text
目的地容量 >= 來源長度 + 1
```

## Section XXVI. 教材安全補充

> 以下內容用來補足來源範例在現代 C 程式中容易遇到的安全問題。

### 98. 不要將一般輸入直接當成 `printf()` 格式字串

不建議：

```c
printf(text);
```

建議：

```c
printf("%s", text);
```

---

### 99. 不要修改字串字面常數

即使宣告成：

```c
char *text = "test";
```

也不能安全修改。

優先使用：

```c
const char *text = "test";
```

---

### 100. `strcpy()` 沒有容量參數

只有在呼叫端能確定目的地容量時使用。

若來源長度不可信，應先驗證長度或使用具有明確容量設計的自訂函式。

---

### 101. 有容量限制的自訂版本

```c
#include <stddef.h>

int string_copy_sized(
    char *destination,
    size_t capacity,
    const char *source
) {
    size_t i = 0;

    if (
        destination == NULL ||
        source == NULL ||
        capacity == 0
    ) {
        return 0;
    }

    while (
        source[i] != '\0' &&
        i + 1 < capacity
    ) {
        destination[i] = source[i];
        i++;
    }

    destination[i] = '\0';

    return source[i] == '\0';
}
```

回傳：

- `1`：完整複製。
- `0`：參數無效或來源被截短。

這是教材補充，不是來源投影片的主要實作。

## Section XXVII. 容易搞混的重點

### 102. 傳位址仍然是傳值

C 沒有把參數變成同一個指標變數。

它複製的是位址值。

---

### 103. `sort_two()` 中比較的是 `*a` 與 `*b`

```c
a > b
```

比較的是兩個位址，不能用來判斷整數大小。

應寫：

```c
*a > *b
```

---

### 104. 指標加一與整數加一的單位不同

```c
number + 1
```

整數值增加一。

```c
pointer + 1
```

移動到下一個所指型態元素。

---

### 105. 指標相減不是位元組數

同一陣列中：

```c
second - first
```

得到相隔的元素數量。

---

### 106. 陣列名稱與指標變數不相同

陣列名稱不能被重新賦值；指標變數可以。

---

### 107. 尾端位置不是元素

```c
values + length
```

可用來比較，但不能解參照。

---

### 108. `pointer[i]` 不代表 `pointer` 是陣列

下標是由指標加法與間接存取定義的。

---

### 109. 函式參數中的 `[3]` 不會保存陣列長度

```c
void function(int values[3]);
```

仍然是指標參數。

---

### 110. `*pointer++` 修改的是指標，不是元素值

它等價於：

```c
*(pointer++)
```

若要增加元素值：

```c
(*pointer)++;
```

---

### 111. 字元陣列初始化與指標指向字面常數不同

```c
char array[] = "test";
```

會建立可修改副本。

```c
const char *pointer = "test";
```

只保存字串字面常數的位址。

---

### 112. 指標改指向不是複製字串

```c
pointer = "Test";
```

只改變位址。

---

### 113. `const char *` 的指標本身仍可改變

`const` 限制的是透過該指標修改字元，不是指標變數本身。

---

### 114. 增加 `const` 與移除 `const` 的方向不同

```c
char * → const char *
```

安全且允許。

```c
const char * → char *
```

可能讓程式修改唯讀資料，不是安全的隱性轉型。

---

### 115. 字串複製需要目的地儲存空間

僅宣告：

```c
char *destination;
```

不會自動配置字元陣列。

## Section XXXIII. 重點複習

1. C 函式引數全部以值傳遞。
2. 普通參數複製資料值。
3. 指標參數複製位址值。
4. 透過指標參數可以修改呼叫端物件。
5. `swap()` 必須取得兩個整數位址。
6. `swap(&a, &b)` 將呼叫端位址傳入。
7. `*a` 與 `*b` 是實際要交換的整數。
8. `sort_two()` 也必須取得位址才能改變呼叫端。
9. 指標參數傳給另一個相同指標參數時不需再取址。
10. 可以傳值時，來源建議優先傳值。
11. 傳值較不容易讓函式修改原資料。
12. 傳值可以直接傳入一般常數。
13. 必須修改呼叫端時傳位址。
14. 無法直接整體複製的陣列與字串通常傳位址。
15. 複製成本很高的資料也可能傳位址。
16. 指標加一移動到下一個同型態陣列元素。
17. 指標減一移動到前一個元素。
18. 指標加法只能與整數組合。
19. 兩個指標不能相加。

## Section XXXIV. 常見錯誤提醒

### 錯誤 1：交換函式只接收普通整數

只會交換參數副本。

---

### 錯誤 2：呼叫指標參數時忘記取址

```c
swap(a, b);
```

在 `main()` 中的 `a`、`b` 是普通整數時應傳：

```c
swap(&a, &b);
```

---

### 錯誤 3：在指標參數函式中比較位址

```c
if (a > b)
```

應比較：

```c
if (*a > *b)
```

---

### 錯誤 4：指標已經是位址卻再次取址

```c
swap(&a, &b);
```

若 `a`、`b` 已經是 `int *`，這會得到 `int **`。

---

### 錯誤 5：所有資料都不必要地傳位址

只讀取小型值時，傳值更簡單。

---

### 錯誤 6：把 `pointer + 1` 當成增加一個位元組

它移動一個所指型態元素。

---

### 錯誤 7：將兩個指標相加

沒有本章所需的合法意義。

---

### 錯誤 8：對不同陣列的指標做減法

指標相減必須建立在同一陣列範圍中。

---

### 錯誤 9：把陣列當成可重新賦值的指標變數

```c
values = values + 1;
```

不合法。

---

### 錯誤 10：解參照尾端之後的位置

```c
*(values + length)
```

越界。

---

### 錯誤 11：以為參數中的 `[10]` 會傳入十個元素副本

實際仍是指標參數。

---

### 錯誤 12：函式只取得指標卻沒有取得長度

無法知道合法範圍。

---

### 錯誤 13：將 `*pointer++` 誤讀成增加元素值

它增加的是指標。

---

### 錯誤 14：修改字串字面常數

```c
char *text = "test";
text[0] = 'T';
```

未定義行為。

---

### 錯誤 15：將字元陣列與指標視為完全相同

它們在配置、賦值與 `sizeof` 上不同。

---

### 錯誤 16：以為指標改指向就是複製字串

只改變位址，沒有建立獨立內容。

---

### 錯誤 17：透過 `const char *` 修改字元

會造成編譯診斷。

---

### 錯誤 18：將 `const char *` 指派給 `char *`

會移除保護，嚴格 C 編譯器必須診斷。

---

### 錯誤 19：自行複製時忘記 `'\0'`

目的地不會形成完整字串。

---

### 錯誤 20：`strcpy()` 目的地容量不足

會寫出陣列範圍。

---

### 錯誤 21：只宣告目的地指標，沒有配置字元空間

```c
char *destination;
```

不能直接交給 `strcpy()`。

---

### 錯誤 22：將 `const` 陣列作為 `strcpy()` 目的地

目的地必須可寫。
