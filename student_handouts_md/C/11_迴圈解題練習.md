## Section IV. 寫題目前的提醒

### 1. 整除表示餘數為 `0`

<p align="center">
  <img
    src="images/lesson_11/C_Lesson_11_img03_modulo_divisibility.png"
    alt="餘數與整除判斷"
    width="700">
</p>


```c
n % divisor == 0
```

代表：

```text
divisor 可以整除 n
```

不是使用除法結果判斷：

```c
n / divisor == 0
```

---

### 2. 正因數候選從 `1` 開始

題目要求正因數，因此：

```c
for (number = 1; number <= n; number++)
```

不要從 `0` 開始，因為不能用 `0` 當除數。

---

### 3. `N` 本身永遠是 `N` 的正因數

```c
n % n == 0
```

因此搜尋到：

```c
number <= n
```

才能包含 `N` 本身。

---

### 4. 質數不包括 `1`

質數是：

> 除了 `1` 與本身以外，沒有其他正因數的正整數。

`1` 只有一個正因數，不符合質數定義。

---

### 5. 質數判斷不需要檢查 `1` 與 `N`

因為任何正整數都能被 `1` 與自己整除。

真正需要檢查的是：

```c
2
```

到：

```c
N - 1
```

是否存在因數。

---

### 6. 韓信點兵三個條件要同時成立

來源題目：

```text
三三數之賸二
五五數之賸三
七七數之賸二
```

翻譯成：

```c
number % 3 == 2 &&
number % 5 == 3 &&
number % 7 == 2
```

需要使用 `&&`，不是 `||`。

---

### 7. 沒有上限的韓信點兵答案不只一個

滿足條件的數字包括：

```text
23
128
233
338
443
...
```

如果題目只問「第一個」，由 `1` 向上搜尋即可。

如果題目要求「所有答案」，必須提供有限搜尋範圍。

---

### 8. 搜尋方向決定答案順序

<p align="center">
  <img
    src="images/lesson_11/C_Lesson_11_img04_search_direction.png"
    alt="搜尋方向與答案順序"
    width="700">
</p>


由小到大：

```c
for (number = min; number <= max; number++)
```

輸出由小到大。

由大到小：

```c
for (number = max; number >= min; number--)
```

輸出由大到小。

---

### 9. 最大值可以由大到小搜尋

由上限開始向下找時，第一個合格值就是最大答案。

但必須處理：

```text
範圍內可能沒有答案
```

否則程式可能一直往負數搜尋。

---

### 10. `answer = 0` 可以表示「尚未找到」

韓信點兵的正整數答案不會是 `0`，因此可以使用：

```c
int answer = 0;
```

找到時：

```c
answer = number;
```

離開後：

```c
if (answer != 0)
```

表示確實找到。

---

### 11. `count` 增加的位置要正確

只有候選值符合條件時才增加：

```c
if (qualified) {
    count++;
}
```

如果每一輪都增加，記錄的是檢查次數，不是答案數量。

---

### 12. 「找前三個」要在找到三個後停止

可將停止條件寫進 `for`：

```c
for (number = 1; number <= 1000 && count < 3; number++)
```

當 `count == 3` 時，不再檢查後面的候選值。

---

### 13. 「第三小」不能把前三個都輸出

找到答案時先增加：

```c
count++;
```

只有：

```c
count == 3
```

時才輸出。

---

### 14. `isPrime` 的初始假設通常是「先視為質數」

```c
int isPrime = 1;
```

如果找到非平凡因數：

```c
isPrime = 0;
```

---

### 15. 找到一個非平凡因數就足以判定不是質數

不需要繼續找出所有因數。

因此可把：

```c
isPrime
```

加入迴圈條件：

```c
for (number = 2; number < n && isPrime; number++)
```

---

### 16. 不使用旗標時，可以觀察迴圈控制變數

```c
for (number = 2;
     number < n && n % number != 0;
     number++) {
}
```

如果最後：

```c
number == n
```

表示從 `2` 到 `n - 1` 都沒有整除。

---

### 17. 空的 `for` 本體要特別小心分號

來源中有一種寫法：

```c
for (number = 2;
     number < n && n % number != 0;
     number++) {
}
```

也可以寫成空述句：

```c
for (...);
```

但初學階段使用大括號較清楚，不容易誤讀。

---

### 18. `N <= 1` 要直接判定不是質數

如果不特別處理，某些迴圈版本可能把 `1` 錯判成質數。

先檢查：

```c
if (n <= 1) {
    printf("No\n");
}
```

## Section V. 核心概念說明

## Section V-A. 找出所有正因數

### 1. 什麼是因數？

如果整數 `a` 能整除整數 `N`：

```text
N ÷ a 的餘數為 0
```

則 `a` 是 `N` 的因數。

C 語言：

```c
n % number == 0
```

---

### 2. 正因數的例子

`8` 的正因數：

```text
1, 2, 4, 8
```

`9` 的正因數：

```text
1, 3, 9
```

`10` 的正因數：

```text
1, 2, 5, 10
```

`11` 的正因數：

```text
1, 11
```

`11` 除了 `1` 與本身外沒有其他正因數，因此是質數。

---

### 3. 如何找出候選值？

`N` 的正因數必須：

1. 是正整數。
2. 不大於 `N`。
3. 能整除 `N`。

因此候選範圍是：

```text
1 到 N
```

---

### 4. 正因數程式

```c
#include <stdio.h>

int main(void) {
    int n;
    int number;

    printf("N = ");
    scanf("%d", &n);

    for (number = 1; number <= n; number++) {
        if (n % number == 0) {
            printf("%d ", number);
        }
    }

    printf("\n");

    return 0;
}
```

輸入：

```text
N = 21
```

輸出：

```text
1 3 7 21
```

---

### 5. 搜尋架構

<p align="center">
  <img
    src="images/lesson_11/C_Lesson_11_img02_factor_search_flow.png"
    alt="因數搜尋流程"
    width="700">
</p>


```c

    if (候選值符合條件) {
        處理答案;
    }
}
```

在因數問題中：

| 部分 | 內容 |
| --- | --- |
| 候選值 | `1` 到 `N` |
| 合格條件 | `N % number == 0` |
| 處理答案 | 輸出 `number` |

---

### 6. 追蹤 `N = 8`

| 候選 `number` | `8 % number` | 是因數嗎？ |
| ---: | ---: | --- |
| 1 | 0 | 是 |
| 2 | 0 | 是 |
| 3 | 2 | 否 |
| 4 | 0 | 是 |
| 5 | 3 | 否 |
| 6 | 2 | 否 |
| 7 | 1 | 否 |
| 8 | 0 | 是 |

結果：

```text
1 2 4 8
```

---

### 7. 延伸：計算正因數數量

```c
#include <stdio.h>

int main(void) {
    int n;
    int number;
    int count = 0;

    printf("N = ");
    scanf("%d", &n);

    for (number = 1; number <= n; number++) {
        if (n % number == 0) {
            count++;
        }
    }

    printf("Number of positive divisors: %d\n", count);

    return 0;
}
```

質數的正因數數量恰好是 `2`。

### 8. 題目條件

```c

number % 5 == 3
number % 7 == 2
```

---

### 9. 合格條件

```c
number % 3 == 2 &&
number % 5 == 3 &&
number % 7 == 2
```

把它包在否定中：

```c
!(number % 3 == 2 &&
  number % 5 == 3 &&
  number % 7 == 2)
```

代表：

> 目前還不是答案。

---

### 10. 使用 `while` 找第一個答案

```c
#include <stdio.h>

int main(void) {
    int number = 1;

    while (!(number % 3 == 2 &&
             number % 5 == 3 &&
             number % 7 == 2)) {
        number++;
    }

    printf("%d\n", number);

    return 0;
}
```

輸出：

```text
23
```

---

### 11. 為什麼起點是 `1`？

題目詢問正整數數量，因此從最小正整數開始。

由小到大搜尋時，第一個符合條件的值就是最小正整數答案。

---

### 12. 為什麼這個題目需要小心？

沒有搜尋上限時：

- 程式假設一定找得到答案。
- 若條件根本沒有答案，迴圈可能永遠不停止。
- 即使有答案，也只能找到第一個。

後續來源教材因此加入搜尋範圍。

## Section V-D. 找出最大答案

### 17. 由上限向下搜尋

因為題目只要最大值，可以從 `max` 開始向下檢查。

最直接的想法：

```c
int number = max;

while (!(number % 3 == 2 &&
         number % 5 == 3 &&
         number % 7 == 2)) {
    number--;
}

printf("%d\n", number);
```

如果上限內有答案，這能找到最大值。

---

### 18. 沒有答案時的危險

<p align="center">
  <img
    src="images/lesson_11/C_Lesson_11_img11_safe_search_boundary.png"
    alt="安全搜尋與搜尋邊界"
    width="700">
</p>


若上限小於第一個答案 `23`，例如：

```text
MAX = 10
```

前面的程式會繼續檢查：

```text
9, 8, ..., 0, -1, -2, ...
```

可能一直找不到適合的正整數，造成無窮搜尋。

因此要限制：

```c
number > 0
```

---

### 19. 安全的 `while` 版本

```c
#include <stdio.h>

int main(void) {
    int max;
    int number;

    printf("MAX = ");
    scanf("%d", &max);

    number = max;

    while (number > 0 &&
           !(number % 3 == 2 &&
             number % 5 == 3 &&
             number % 7 == 2)) {
        number--;
    }

    if (number > 0) {
        printf("%d\n", number);
    } else {
        printf("Not found\n");
    }

    return 0;
}
```

---

### 20. 使用 `answer` 保存最大值

另一種來源中的做法是由小到大走完整範圍，每次找到答案就覆蓋：

```c
#include <stdio.h>

int main(void) {
    int max;
    int number;
    int answer = 0;

    printf("MAX = ");
    scanf("%d", &max);

    for (number = 1; number <= max; number++) {
        if (number % 3 == 2 &&
            number % 5 == 3 &&
            number % 7 == 2) {
            answer = number;
        }
    }

    if (answer != 0) {
        printf("%d\n", answer);
    } else {
        printf("Not found\n");
    }

    return 0;
}
```

因為由小到大搜尋，最後一次保存的答案就是最大答案。

---

### 21. 由大到小，只保存第一個答案

```c
#include <stdio.h>

int main(void) {
    int max;
    int number;
    int answer = 0;

    printf("MAX = ");
    scanf("%d", &max);

    for (number = max;
         number >= 1 && answer == 0;
         number--) {
        if (number % 3 == 2 &&
            number % 5 == 3 &&
            number % 7 == 2) {
            answer = number;
        }
    }

    if (answer != 0) {
        printf("%d\n", answer);
    } else {
        printf("Not found\n");
    }

    return 0;
}
```

将：

```c
answer == 0
```

放進迴圈條件，找到答案後就停止。

## Section V-F. 質數判斷

<p align="center">

### 27. 什麼是質數？

質數是：

> 除了 `1` 與本身以外，沒有其他正因數的正整數。

例子：

```text
2, 3, 5, 7, 11, 13, 17, 19, 23, ...
```

不包括：

```text
1
```

質數有無窮多個，也是現代密碼系統的重要基礎之一。

---

### 28. 直接尋找非平凡因數

如果 `N` 是質數，則：

```text
2 到 N - 1
```

之間不會有任何數能整除 `N`。

```c
for (number = 2; number < n; number++) {
    if (n % number == 0) {
        /* 找到非平凡因數 */
    }
}
```

---

### 29. 方法一：計算非平凡因數數量

```c
#include <stdio.h>

int main(void) {
    int n;
    int number;
    int numberOfDivisors = 0;

    printf("N = ");
    scanf("%d", &n);

    if (n <= 1) {
        printf("No\n");
        return 0;
    }

    for (number = 2; number < n; number++) {
        if (n % number == 0) {
            numberOfDivisors++;
        }
    }

    if (numberOfDivisors == 0) {
        printf("Yes\n");
    } else {
        printf("No\n");
    }

    return 0;
}
```

若沒有任何非平凡因數，就是質數。

---

### 30. 方法二：使用 `isPrime`

<p align="center">
  <img
    src="images/lesson_11/C_Lesson_11_img10_isprime_state.png"
    alt="isPrime 狀態轉換"
    width="700">
</p>


```c
#include <stdio.h>

int main(void) {
    int n;
    int number;
    int isPrime = 1;

    printf("N = ");
    scanf("%d", &n);

    if (n <= 1) {
        isPrime = 0;
    }

    for (number = 2; number < n; number++) {
        if (n % number == 0) {
            isPrime = 0;
        }
    }

    if (isPrime) {
        printf("Yes\n");
    } else {
        printf("No\n");
    }

    return 0;
}
```

`isPrime` 的意義：

| 值 | 意義 |
| ---: | --- |
| 1 | 目前仍視為質數 |
| 0 | 已確定不是質數 |

---

### 31. 找到因數後停止檢查

```c
for (number = 2;
     number < n && isPrime;
     number++) {
    if (n % number == 0) {
        isPrime = 0;
    }
}
```

只要 `isPrime` 變成 `0`，下一次條件檢查時就離開迴圈。

---

### 32. 方法三：利用控制變數判斷

不使用 `isPrime`：

```c
#include <stdio.h>

int main(void) {
    int n;
    int number;

    printf("N = ");
    scanf("%d", &n);

    if (n <= 1) {
        printf("No\n");
        return 0;
    }

    for (number = 2;
         number < n && n % number != 0;
         number++) {
    }

    if (number == n) {
        printf("Yes\n");
    } else {
        printf("No\n");
    }

    return 0;
}
```

---

### 33. 為什麼 `number == n` 代表質數？

如果每個：

```text
2, 3, ..., N - 1
```

都不能整除 `N`，迴圈會一直正常更新，最後 `number` 變成 `N`。

若中途找到因數，條件：

```c
n % number != 0
```

會變成假，迴圈提早結束，此時：

```c
number < n
```

---

### 34. 相同概念的 `while` 版本

```c
#include <stdio.h>

int main(void) {
    int n;
    int number = 2;

    printf("N = ");
    scanf("%d", &n);

    if (n <= 1) {
        printf("No\n");
        return 0;
    }

    while (number < n && n % number != 0) {
        number++;
    }

    if (number == n) {
        printf("Yes\n");
    } else {
        printf("No\n");
    }

    return 0;
}
```

這顯示同一個搜尋邏輯可以使用 `for` 或 `while` 表達。

## Section V-G. 容易搞混的重點

### 1. 因數與倍數方向相反

若：

```text
3 可以整除 12
```

則：

- `3` 是 `12` 的因數。
- `12` 是 `3` 的倍數。

---

### 2. `N % number == 0` 的被除數是 `N`

錯誤：

```c
number % n == 0
```

這是在檢查 `N` 是否為 `number` 的因數，方向不同。

---

### 3. 韓信點兵不是三個條件任選一個

必須同時符合，因此使用：

```c
&&
```

---

### 4. 無上限搜尋不適合「列出所有答案」

答案無窮多，不可能讓程式自然列完。

要列出所有答案，必須提供上限或範圍。

---

### 5. 最大值不一定要保存每個答案

若由大到小搜尋，第一個答案就是最大值。

由小到大搜尋時，則可以每次覆蓋 `answer`。

---

### 6. `answer == 0` 是狀態，也是數值

在本題中：

- `0` 不是合法正整數答案。
- 因此可安全用來代表「未找到」。

其他題目若 `0` 可能是答案，就要改用獨立狀態變數。

---

### 7. `count` 的用途不是保存答案

```c
count
```

表示找到幾個。

```c
number
```

才是目前找到的數值。

---

### 8. 「第三小」的 `count` 是順位

找到第一個時：

```text
count = 1
```

找到第三個時：

```text
count = 3
```

因此可在 `count == 3` 時輸出。

---

### 9. 質數判斷只需要找到一個反例

只要找到一個：

```c
n % number == 0
```

且 `number` 介於 `2` 與 `n - 1`，就已確定不是質數。

---

### 10. `isPrime = 1` 不是「已證明是質數」

它代表：

> 到目前為止，尚未找到能推翻質數假設的因數。

---

### 11. `number == n` 的方法依賴迴圈停止原因

必須同時理解：

- 正常走到 `n`
- 中途因整除而停止

不能只看到最後一行就死背。

---

### 12. `2` 是質數

檢查 `2` 時：

```c
number = 2
number < n
```

一開始就是假。

控制變數等於 `n`，因此判定為質數。

## Section XI. 重點複習

1. 搜尋題需要候選範圍、合格條件與答案處理。
2. `N % number == 0` 表示 `number` 是 `N` 的因數。
3. 正因數候選可以從 `1` 搜尋到 `N`。
4. 質數只有 `1` 與本身兩個正因數。
5. `1` 不是質數。
6. 韓信點兵需要三個餘數條件同時成立。
7. 無上限搜尋只能合理地找第一個答案，不能列完無窮多答案。
8. 加入上限後可以列出範圍內所有答案。
9. 加入下限後可以限制完整搜尋區間。
10. 搜尋方向決定輸出順序。
11. 由大到小搜尋時，第一個合格值就是最大值。
12. 沒有答案時要避免搜尋進入無限負數。
13. `answer = 0` 可在本題中表示尚未找到。
14. 由小到大每次覆蓋 `answer`，最後保存最大答案。
15. `count` 記錄找到幾個答案。
16. 找固定數量時，可將 `count < target` 加入迴圈條件。
17. 找第 `K` 個答案時，在 `count == K` 時輸出。
18. 質數判斷只需搜尋非平凡因數。
19. 找到一個非平凡因數即可確定不是質數。
20. `isPrime` 是狀態變數，不是因數數量。
21. 控制變數殘值可以反映迴圈停止原因。
22. `N <= 1` 必須判定為非質數。
23. `2` 是最小的質數。
24. 先完成正確的線性搜尋，再改善停止條件。
25. 同一個搜尋邏輯可以使用 `for` 或 `while` 表達。

## Section XII. 常見錯誤提醒

### 錯誤 1：因數條件方向顛倒

錯誤：

```c
number % n == 0
```

正確：

```c
n % number == 0
```

---

### 錯誤 2：從 `0` 開始測試因數

錯誤：

```c
for (number = 0; number <= n; number++)
```

執行：

```c
n % 0
```

是無效操作。

---

### 錯誤 3：漏掉 `N` 本身

錯誤：

```c
number < n
```

若題目要求所有正因數，應使用：

```c
number <= n
```

---

### 錯誤 4：韓信點兵使用 `||`

這會把符合任一條件的數字也視為答案。

---

### 錯誤 5：沒有範圍卻想輸出所有韓信點兵答案

答案無窮多，程式不會自然結束。

---

### 錯誤 6：最大值搜尋沒有下界

```c
while (!qualified) {
    number--;
}
```

若範圍內沒有答案，可能一直搜尋負數。

---

### 錯誤 7：沒有檢查 `answer`

若 `answer` 仍是 `0`，代表沒有找到，不應直接當成答案輸出。

---

### 錯誤 8：每輪都增加 `count`

錯誤：

```c
for (...) {
    count++;

    if (qualified) {
        ...
    }
}
```

這是在計算候選值數量。

---

### 錯誤 9：先判斷 `count == 3` 再增加

若順序錯誤，第三個答案可能在 `count == 2` 時出現，造成漏印。

---

### 錯誤 10：把 `1` 判斷為質數

必須特別處理：

```c
n <= 1
```

---

### 錯誤 11：質數檢查包含 `N` 本身

如果檢查：

```c
number <= n
```

則任何 `N` 都會被自己整除，全部被判定為非質數。

應使用：

```c
number < n
```

---

### 錯誤 12：找到因數後把 `isPrime` 設成 `1`

找到非平凡因數時應：

```c
isPrime = 0;
```

---

### 錯誤 13：控制變數版本沒有理解停止原因

中途找到因數時：

```c
number < n
```

不能只檢查 `number` 是否大於某個固定值。

---

### 錯誤 14：把空本體的分號放錯位置

若使用：

```c
for (...);
```

分號就是本體。

之後的大括號不會被迴圈控制。初學時建議使用明確的空大括號。

## Section XIII. Mermaid 流程圖

### 1. 通用線性搜尋

```mermaid
flowchart TD
    A[設定第一個候選值] --> B{仍在搜尋範圍嗎}
    B -- 否 --> F[搜尋結束]
    B -- 是 --> C{候選值合格嗎}
    C -- 是 --> D[處理答案]
    C -- 否 --> E[更新候選值]
    D --> E
    E --> B
```

---

### 2. 找出所有正因數

```mermaid
flowchart TD
    A[number 設為 1] --> B{number 小於等於 N}
    B -- 否 --> F[結束]
    B -- 是 --> C{N 除以 number 的餘數為 0}
    C -- 是 --> D[輸出 number]
    C -- 否 --> E[number 加 1]
    D --> E
    E --> B
```

---

### 3. 第一個韓信點兵答案

```mermaid
flowchart TD
    A[number 設為 1] --> B{同時符合三個餘數條件}
    B -- 是 --> D[輸出 number]
    B -- 否 --> C[number 加 1]
    C --> B
```

---

### 4. 有範圍的韓信點兵

```mermaid
flowchart TD
    A[number 設為 MIN] --> B{number 小於等於 MAX}
    B -- 否 --> F[結束]
    B -- 是 --> C{符合三個餘數條件}
    C -- 是 --> D[輸出 number]
    C -- 否 --> E[number 加 1]
    D --> E
    E --> B
```

---

### 5. 最大答案

```mermaid
flowchart TD
    A[number 設為 MAX] --> B{number 大於 0}
    B -- 否 --> F[輸出 Not found]
    B -- 是 --> C{符合條件}
    C -- 是 --> D[保存並輸出答案]
    C -- 否 --> E[number 減 1]
    E --> B
```

---

### 6. 找前三小

```mermaid
flowchart TD
    A[count 設為 0 且 number 設為 1] --> B{number 不超過上限且 count 小於 3}
    B -- 否 --> F[結束]
    B -- 是 --> C{符合條件}
    C -- 是 --> D[count 加 1 並輸出 number]
    C -- 否 --> E[number 加 1]
    D --> E
    E --> B
```

---

### 7. 旗標法判斷質數

```mermaid
flowchart TD
    A[先假設 isPrime 為 1] --> B{N 小於等於 1}
    B -- 是 --> G[isPrime 設為 0]
    B -- 否 --> C[number 從 2 開始]
    C --> D{number 小於 N 且 isPrime 為真}
    D -- 否 --> H{isPrime 為真嗎}
    D -- 是 --> E{N 可被 number 整除嗎}
    E -- 是 --> G
    E -- 否 --> F[number 加 1]
    G --> H
    F --> D
    H -- 是 --> I[輸出 Yes]
    H -- 否 --> J[輸出 No]
```

---

### 8. 控制變數殘值法

```mermaid
flowchart TD
    A[number 設為 2] --> B{number 小於 N 且不能整除 N}
    B -- 是 --> C[number 加 1]
    C --> B
    B -- 否 --> D{number 等於 N}
    D -- 是 --> E[是質數]
    D -- 否 --> F[不是質數]
```
