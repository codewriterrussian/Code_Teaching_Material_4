# Lesson 02：Pointer Arrays and Pointers to Arrays 指標陣列與陣列指標

> 這堂課的重點：分辨「指標組成的陣列」與「指向完整陣列的指標」，並把這兩種型態應用到函式參數及二維資料。你會學會判讀 `int *p[3]` 與 `int (*p)[3]`、理解陣列長度如何成為型態的一部分，以及為什麼真正的二維陣列不能直接當成 `int **`。

> 本章依照 `28-01` 到 `28-06` 的投影片編排。多個字串、字串指標及緊密字串儲存不放在本章，會留給後續章節。

## Section II. 今天的學習方式

1. 由變數名稱開始，按照括號與運算子優先順序向外閱讀宣告。
2. 對以下兩個宣告分別畫圖：
   ```c
   int *p[3];
   int (*p)[3];
   ```
3. 指標陣列要畫出多個獨立指標格。
4. 陣列指標只畫一個指標格，箭頭指向完整陣列。
5. 使用 `pointers[i][j]` 時分兩步閱讀：
   ```text
   pointers[i] → 第 i 個指標
   pointers[i][j] → 該指標所指資料中的第 j 個元素
   ```
6. 使用 `(*p)[i]` 時先解參照指標，取得完整陣列，再取下標。
7. 每次傳入函式前，列出引數運算式的型態。
8. 不只比較位址數字，也要比較指標所指型態。
9. 二維陣列題先寫出一列的型態與大小。
10. 看見 `int **` 時，確認記憶體中是否真的存在「指標的陣列」。
11. 扁平化存取時先計算：
    ```text
    row * width + column
    ```
12. 每次使用第二個下標前，確認該列實際長度。
13. 所有完整且應合法的程式都使用嚴格 C17 選項編譯。
14. 錯誤範例只用來分析，不會作為可執行程式。

# Part A：指標陣列

## Section IV. 一般陣列與指標陣列

### 1. 一般整數陣列

```c
int values[3];
```

配置：

```text
values[0] values[1] values[2]
   int       int       int
```

每個元素保存一個整數。

---

### 2. 指標陣列

```c
int *pointers[3];
```

配置：

```text
pointers[0] pointers[1] pointers[2]
    int *       int *       int *
```

每個元素保存某個 `int` 物件的位址。

---

### 3. 為什麼它是陣列？

下標運算比前面的 `*` 更靠近變數名稱：

```c
int *pointers[3];
```

由 `pointers` 向外讀：

```text
pointers
→ 是具有三個元素的陣列
→ 每個元素是 int *
```

---

## Section V. 指標陣列指向同一陣列的元素

<p align="center">
  <img
    src="images/lesson_02/C_Advanced_02_img02_pointer_array_mapping.png"
    alt="指標陣列與原陣列元素的對應"
    width="700">
</p>

### 4. 按照原順序初始化

```c
#include <stdio.h>

int main(void) {
    int values[3] = {1, 2, 3};
    int *pointers[3] = {
        &values[0],
        &values[1],
        &values[2]
    };

    for (int i = 0; i < 3; i++) {
        *pointers[i] = 0;
    }

    *pointers[2] = 5;

    for (int i = 0; i < 3; i++) {
        printf("%d ", values[i]);
    }

    printf("\n");

    return 0;
}
```

輸出：

```text
0 0 5
```

---

### 5. `*pointers[i]` 的閱讀方式

```c
*pointers[i]
```

因為下標優先於前置 `*`，等同：

```c
*(pointers[i])
```

1. `pointers[i]` 取得第 `i` 個 `int *`。
2. `*` 取得該指標所指的整數。

---

### 6. 指標順序可以不同

```c
int *pointers[3] = {
    &values[2],
    &values[1],
    &values[0]
};
```

現在：

```text
pointers[0] → values[2]
pointers[1] → values[1]
pointers[2] → values[0]
```

因此：

```c
*pointers[2] = 5;
```

修改的是：

```c
values[0]
```

指標陣列的順序不必與原陣列元素順序相同。

---

## Section VI. 指標陣列指向獨立變數

```c
#include <stdio.h>

int main(void) {
    int a = 1;
    int b = 2;
    int c = 3;

    int *pointers[3] = {
        &a,
        &b,
        &c
    };

    for (int i = 0; i < 3; i++) {
        *pointers[i] = 0;
    }

    *pointers[2] = 5;

    printf("%d %d %d\n", a, b, c);

    return 0;
}
```

輸出：

```text
0 0 5
```

指標陣列中的目標不必來自同一個陣列，只要型態與生命週期合法即可。

## Section VII. 指標陣列指向多個陣列

### 7. 每個元素指向一列

```c
int first[2] = {1, 2};
int second[2] = {3, 4};
int third[2] = {5, 6};

int *rows[3] = {
    first,
    second,
    third
};
```

每個一維陣列名稱會轉成第一個元素的位址：

```text
rows[0] → &first[0]
rows[1] → &second[0]
rows[2] → &third[0]
```

---

### 8. 使用兩個下標

<p align="center">
  <img
    src="images/lesson_02/C_Advanced_02_img03_double_subscript.png"
    alt="雙下標操作的解析流程"
    width="700">
</p>

```c
rows[i][j]
```

等同：

```c
*(rows[i] + j)
```

第一個下標選擇哪一個列指標，第二個下標選擇該列中的元素。

---

### 9. 完整存取範例

```c
#include <stdio.h>

int main(void) {
    int first[2] = {1, 2};
    int second[2] = {3, 4};
    int third[2] = {5, 6};

    int *rows[3] = {
        first,
        second,
        third
    };

    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 2; j++) {
            rows[i][j] = 0;
        }
    }

    rows[2][0] = 7;

    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 2; j++) {
            printf("%d ", rows[i][j]);
        }
        printf("\n");
    }

    return 0;
}
```

---

## Section VIII. 每一列可以有不同長度

<p align="center">
  <img
    src="images/lesson_02/C_Advanced_02_img04_jagged_rows.png"
    alt="不等長列的指標陣列"
    width="700">
</p>

```c
int first[4] = {1, 2, 7, 8};
int second[2] = {3, 4};
int third[2] = {5, 6};

int *rows[3] = {
    first,
    second,
    third
};
```

合法：

```c
rows[0][2] = 9;
```

因為 `rows[0]` 指向長度四的 `first`。

錯誤：

```c
rows[1][2] = 10;
```

`second` 只有兩個元素，合法索引為 `0` 與 `1`。

> 指標陣列只保存起始位址，不會自動保存每一列的長度。若列長不同，程式必須另外保存每列長度。

## Section IX. 完整陣列也有位址

<p align="center">

### 10. 一個三元素陣列

```c
int values[3] = {1, 2, 3};
```

`values` 的型態是：

```text
int[3]
```

---

### 11. `&values` 的型態

```c
&values
```

取得完整陣列物件的位址。

型態是：

```text
int (*)[3]
```

讀成：

```text
指向 int[3] 的指標
```

---

### 12. 宣告陣列指標

```c
int (*array_pointer)[3] = &values;
```

由變數名稱向外讀：

```text
array_pointer
→ 是指標
→ 指向具有三個 int 元素的陣列
```

括號不能省略。

---

### 13. 與指標陣列比較

```c
int *a[3];
int (*b)[3];
```

| 宣告 | 變數本身 | 指向／包含 |
| --- | --- | --- |
| `int *a[3]` | 陣列 | 三個 `int *` |
| `int (*b)[3]` | 指標 | 一個 `int[3]` |

## Section X. 使用陣列指標存取元素

```c
#include <stdio.h>

int main(void) {
    int values[3] = {1, 2, 3};
    int (*array_pointer)[3] = &values;

    for (int i = 0; i < 3; i++) {
        (*array_pointer)[i] = 0;
    }

    (*array_pointer)[2] = 5;

    for (int i = 0; i < 3; i++) {
        printf("%d ", values[i]);
    }

    printf("\n");

    return 0;
}
```

輸出：

```text
0 0 5
```

---

### 14. 為什麼需要括號？

<p align="center">
  <img
    src="images/lesson_02/C_Advanced_02_img06_declaration_parentheses.png"
    alt="括號如何改變指標宣告"
    width="700">
</p>

```c
(*array_pointer)[i]
```

1. `*array_pointer` 取得完整 `int[3]` 陣列。
2. `[i]` 取得其中第 `i` 個整數。

若寫：

```c
*array_pointer[i]
```

會先執行：

```c
array_pointer[i]
```

意義完全不同。

# Part C：在函式間傳遞一維陣列

## Section XI. 使用陣列指標傳遞固定長度陣列

### 15. 固定三元素版本

```c
#include <stdio.h>

void print_three(const int (*values)[3]) {
    size_t length =
        sizeof(*values) / sizeof((*values)[0]);

    for (size_t i = 0; i < length; i++) {
        printf("%d ", (*values)[i]);
    }

    printf("\n");
}

int main(void) {
    int values[3] = {1, 2, 3};

    print_three(&values);

    return 0;
}
```

---

### 16. 為什麼函式內可以使用 `sizeof`？

參數：

```c
const int (*values)[3]
```

所指物件型態仍然是完整的：

```text
const int[3]
```

因此：

```c
sizeof(*values)
```

得到完整三元素陣列的大小。

---

### 17. 固定長度成為型態的一部分

<p align="center">
  <img
    src="images/lesson_02/C_Advanced_02_img07_pointer_stride.png"
    alt="不同陣列指標型態的移動距離"
    width="700">
</p>

指向三元素陣列：

```c
int (*)[3]
```

指向五元素陣列：

```c
int (*)[5]
```

兩者是不同型態。

因此固定三元素版本不能直接共用於五元素陣列。

---

## Section XII. 使用一般元素指標與長度

```c
#include <stdio.h>

void print_values(
    const int *values,
    size_t length
) {
    for (size_t i = 0; i < length; i++) {
        printf("%d ", values[i]);
    }

    printf("\n");
}

int main(void) {
    int first[3] = {1, 2, 3};
    int second[5] = {1, 2, 3, 4, 5};

    print_values(first, 3);
    print_values(second, 5);

    return 0;
}
```

同一個函式可處理不同長度陣列。

代價是呼叫者必須另外提供正確長度。

---

### 18. 為什麼不能只在函式內使用 `sizeof(values)`？

參數：

```c
const int *values
```

是指標。

```c
sizeof(values)
```

得到指標本身大小，不是呼叫端陣列大小。

---

### 19. 指向未知長度陣列的問題

概念宣告：

```c
int (*values)[];
```

這是指向不完整陣列型態的指標。

因為元素數量未知，不能使用：

```c
sizeof(*values)
```

計算完整陣列大小。

因此實務上仍要：

- 固定長度寫入型態；或
- 使用元素指標並另外傳入長度。

# Part D：在函式間傳遞真正的二維陣列

## Section XIII. 二維陣列是陣列的陣列

<p align="center">
  <img
    src="images/lesson_02/C_Advanced_02_img08_real_2d_array.png"

</p>

```c
int grid[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

型態：

```text
int[3][3]
```

第一層的每個元素：

```text
grid[0]
grid[1]
grid[2]
```

型態都是：

```text
int[3]
```

---

### 20. 二維陣列名稱的轉型

在多數運算式中：

```c
grid
```

轉成第一列的位址：

```c
&grid[0]
```

型態：

```text
int (*)[3]
```

不是：

```text
int **
```

---

## Section XIV. 固定欄數的二維陣列參數

```c
#include <stdio.h>

void print_grid(
    const int grid[][3],
    size_t height
) {
    for (size_t i = 0; i < height; i++) {
        for (size_t j = 0; j < 3; j++) {
            printf("%d ", grid[i][j]);
        }
        printf("\n");
    }
}

int main(void) {
    int grid[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    print_grid(grid, 2);

    return 0;
}
```

在函式參數中：

```c
const int grid[][3]
```

會調整成：

```c
const int (*grid)[3]
```

---

### 21. 為什麼可以省略第一維？

函式接收的是指向第一列的指標。

列數可由另外的 `height` 參數提供。

---

### 22. 為什麼必須知道欄數？

若每列有三個 `int`：

```c
grid + 1
```

必須向後跳過一整列，也就是三個 `int`。

編譯器需要知道每列型態是：

```text
int[3]
```

才能正確計算下一列位置。

## Section XV. 三種相關位址

<p align="center">
  <img
    src="images/lesson_02/C_Advanced_02_img11_same_address_different_type.png"
    alt="相同位址數值但不同指標型態"
    width="700">
</p>

已知：

```c
int grid[3][3];
```

| 運算式 | 型態 | 意義 |
| --- | --- | --- |
| `grid` | `int (*)[3]` | 第一列位址 |
| `&grid[0]` | `int (*)[3]` | 第一列位址 |
| `&grid` | `int (*)[3][3]` | 完整 3×3 陣列位址 |

位址數字可能相同，但型態不同，指標加一時移動距離也不同。

---

### 23. 指向完整二維陣列

```c
#include <stdio.h>

void print_complete(
    const int (*grid)[3][3]
) {
    for (size_t i = 0; i < 3; i++) {
        for (size_t j = 0; j < 3; j++) {
            printf("%d ", (*grid)[i][j]);
        }
        printf("\n");
    }
}

int main(void) {
    int grid[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    print_complete(&grid);

    return 0;
}
```

這個介面將兩個維度都固定在型態中，因此不適合處理其他高度或寬度。

## Section XVI. `int **` 需要兩層指標結構

參數：

```c
void print_rows(
    int **rows,
    size_t height,
    size_t width
);
```

期待：

```text
rows
→ 指向第一個 int *
→ 每個 int * 再指向一列 int
```

也就是記憶體中必須真的存在一個「列指標陣列」。

---

### 24. 真正二維陣列沒有列指標陣列

```c
int grid[2][3];
```

記憶體直接保存六個連續整數：

```text
grid[0][0] grid[0][1] grid[0][2]
grid[1][0] grid[1][1] grid[1][2]
```

其中沒有額外存放：

```text
&grid[0]
&grid[1]
```

這兩個指標值的陣列。

因此：

```c
print_rows(grid, 2, 3);
```

不能將 `int (*)[3]` 當成 `int **`。

# Part F：使用指標陣列傳遞二維資料

## Section XVII. 建立列指標陣列

```c
#include <stdio.h>

void print_rows(
    int *const rows[],
    size_t height,
    size_t width
) {
    for (size_t i = 0; i < height; i++) {
        for (size_t j = 0; j < width; j++) {
            printf("%d ", rows[i][j]);
        }
        printf("\n");
    }
}

int main(void) {
    int grid[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    int *rows[3] = {
        grid[0],
        grid[1],
        grid[2]
    };

    print_rows(rows, 3, 3);

    return 0;
}
```

函式參數中的：

```c
int *const rows[]
```

會調整成指向列指標的指標。

---

### 25. 指標陣列提供了什麼額外資訊？

真正二維陣列只保存資料元素。

指標陣列額外保存：

```text
rows[0] → 第一列起始位置
rows[1] → 第二列起始位置
rows[2] → 第三列起始位置
```

因此可傳給需要兩層指標結構的函式。

---

### 26. 可以重新排列列順序

<p align="center">
  <img
    src="images/lesson_02/C_Advanced_02_img12_reorder_row_pointers.png"
    alt="重新排列列指標而不搬動資料"
    width="700">
</p>

```c
int *rows[3] = {
    grid[0],
    grid[2],
    grid[1]
};
```

輸出順序會變成：

```text
第一列
第三列
第二列
```

而 `grid` 內部資料配置沒有被搬動。

### 27. 可以指向不同長度的列

```c
int first[4] = {1, 2, 3, 4};
int second[2] = {5, 6};
int third[3] = {7, 8, 9};

int *rows[3] = {
    first,
    second,
    third
};
```

但此時不能使用同一個固定 `width` 安全走訪所有列。

需要另外保存每列長度：

```c
size_t widths[3] = {4, 2, 3};
```

## Section XVIII. 方法一：固定欄數的陣列指標

```c
void print_grid(
    const int (*grid)[3],

```

優點：

- 保留真正二維陣列的列型態。
- 可直接使用 `grid[i][j]`。
- 編譯器知道每列寬度。

限制：

- 欄數 `3` 是型態的一部分。
- 不能直接處理欄數不同的陣列。

---

## Section XIX. 方法二：列指標陣列

```c
void print_rows(
    int *const rows[],
    size_t height,
    const size_t widths[]
);
```

優點：

- 每列可以位於不同位置。
- 每列可以具有不同長度。
- 可重新排列列順序。

限制：

- 呼叫端必須真正建立列指標。
- 需要額外指標儲存空間。
- 不能直接把真正二維陣列轉成 `int **`。

## Section XX. 方法三：扁平化指標與寬度

來源最後將連續二維資料視為一串 `int`，使用：

```text
索引 = row * width + column
```

存取：

```c
*(data + row * width + column)
```

---

### 28. 完整扁平化範例

```c
#include <stdio.h>

void print_flat(
    const int *data,
    size_t height,
    size_t width
) {
    for (size_t i = 0; i < height; i++) {
        for (size_t j = 0; j < width; j++) {
            printf(
                "%d ",
                *(data + i * width + j)
            );
        }
        printf("\n");
    }
}

int main(void) {
    int grid[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    print_flat(
        &grid[0][0],
        3,
        3
    );

    return 0;
}
```

<p align="center">

    width="700">

對位置：

```text
row = 2
column = 1
width = 3
```

一維索引：

```text
2 × 3 + 1 = 7
```

對應：

```c
grid[2][1]
```

也就是數值：

```text

```

此方法假設：

- 所有元素按列連續排列。
- `width` 與原資料實際欄數一致。
- 呼叫端提供的高度、寬度沒有超過合法範圍。

若 `width` 錯誤，程式會以錯誤位置切分每列。

# Part I：容易搞混的重點

## Section XXII. 指標陣列不等於二維陣列

指標陣列：

```c
int *rows[3];
```

包含三個位址。

真正二維陣列：

```c
int grid[3][3];
```

包含九個整數，沒有三個列指標物件。

---

## Section XXIII. 陣列指標不等於元素指標

```c
int *element_pointer;
```

加一移動一個 `int`。

```c
int (*row_pointer)[3];
```

加一移動一整列，也就是三個 `int`。

---

## Section XXIV. 位址數字相同不代表型態相同

對 `int grid[3][3]`：

```c
grid
&grid[0]
&grid
&grid[0][0]
```

在輸出時可能顯示同一起始數字，但型態與指標加一的距離不同。

---

## Section XXV. `int **` 不能修正錯誤型態

即使使用強制轉型把真正二維陣列轉成 `int **`，記憶體中仍不存在列指標陣列。

函式會把前幾個整數內容錯當成位址，造成未定義行為。

強制轉型只改變編譯器看待運算式的型態，不會重新建立正確記憶體結構。

---

## Section XXVI. 每列長度不同時要保存長度

```c
int *rows[3];
```

只知道三個列起始位置。

不知道各列有多少元素。

應另外保存：

```c
size_t widths[3];
```
