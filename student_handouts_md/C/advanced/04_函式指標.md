# Lesson 04：Function Pointers 函式指標

> 這堂課的重點：理解函式也有自己的型態與名稱，但函式型態本身不能像一般物件型態一樣被複製。若要保存、選擇或傳遞某個函式，必須保存「指向該函式的指標」。接著會分析函式指示符、取址運算子 `&`、間接運算子 `*` 和函式呼叫運算子 `()` 之間的特殊關係，最後將 `add()`、`multiply()` 等函式傳入另一個函式。

> 本章依照 `31-01` 到 `31-04` 的投影片順序編排。投影片中的無參數函式使用 `void hello()`；本講義的完整 C17 程式改用 `void hello(void)`，明確表示不接收任何參數。

1. 從變數名稱開始向外閱讀函式指標宣告。
2. 遇到：
   ```c
   int (*op)(int, int);
   ```
   先看到：
   ```text
   op 被括號包住並與 * 結合
   ```
3. 接著再看到：
   ```text
   op 指向一個接收兩個 int 的函式
   ```
4. 最後讀取最左側：
   ```text
   該函式回傳 int
   ```
5. 每次比較宣告時，分別記錄：

   - 函式參數型態
   - 函式回傳型態
6. 分析 `hello`、`&hello`、`*hello` 時，逐步寫出：

7. 函式指標呼叫題先使用完整形式：
   ```c
   (*func)();
   ```

   ```c
   func();
   ```
9. 傳遞函式題先畫出：

| --- | --- | --- |
| `int value` | `value` 是變數 | 保存 `int` |

# Part A：從普通指標到函式指標

## Section IV. 普通物件指標複習

```c
#include <stdio.h>

int main(void) {
    int a = 3;
    int *b = &a;

    *b = 5;

    printf("a = %d\n", a);

    return 0;
}
```

輸出：

```text
a = 5
```

推導：

```text
b
→ &a
→ *b 等價於 *&a
→ 取得 a 物件
```

---

## Section V. 一般函式定義與呼叫

```c
#include <stdio.h>

void hello(void) {
    printf("Hello world!\n");
}

int main(void) {
    hello();

    return 0;
}
```

`hello` 是函式名稱，也可稱為函式指示符。

函式型態：

```text
void (void)
```

表示：

```text
不接收參數
回傳 void
```

---

## Section VI. 函式宣告與定義

```c
void hello(void);
```

是函式宣告。

```c
void hello(void) {
    printf("Hello world!\n");
}
```

是函式定義。

宣告讓編譯器先知道：

- 函式名稱
- 參數型態
- 回傳型態

---

## Section VII. 函式型態不能像物件一樣複製

來源投影片嘗試：

```c
void hello(void);

/* 錯誤概念 */
void func(void) = hello;
```

問題：

```text
func 被宣告成另一個函式
不是一個可以保存函式位址的變數
```

函式型態不能透過賦值複製成另一個函式。

---

### 1. 普通物件型態可以建立變數

```c
int a = 3;
int b = a;
```

`b` 會取得 `a` 的值副本。

---

### 2. 函式型態不能建立可賦值的函式變數

不能將：

```c
hello
```

的函式內容複製成另一個名為 `func` 的函式物件。

若要保存「要呼叫哪一個函式」，必須保存函式指標。

# Part B：函式指標基本語法

## Section VIII. 宣告函式指標

```c
void (*func)(void);
```

由 `func` 向外閱讀：

```text
func
→ 是指標
→ 指向不接收參數
→ 並回傳 void 的函式
```

---

### 3. 為什麼需要括號？

<p align="center">
  <img
    src="images/lesson_04/C_Advanced_04_img02_parentheses_change_meaning.png"
    alt="函式指標宣告中括號的重要性"
    width="700">
</p>

```c
void (*func)(void);
```

括號讓：

```c
*func
```

先結合，表示 `func` 是指標。

若寫成：

```c
void *func(void);
```

意思變成：

```text
func 是函式
→ 不接收參數
→ 回傳 void *
```

這不是函式指標。

## Section IX. 讓函式指標指向函式

<p align="center">
  <img

    width="700">
</p>

```c
void (*func)(void) = &hello;
```

- `&hello` 是指向 `hello` 的函式指標。
- `func` 的型態與 `&hello` 相容。

## Section X. 透過函式指標呼叫

完整形式：

```c
(*func)();
```

完整程式：

```c
#include <stdio.h>

void hello(void);

int main(void) {
    void (*func)(void) = &hello;

    (*func)();

    return 0;
}

void hello(void) {
    printf("Hello world!\n");
}
```

輸出：

```text
Hello world!
```

## Section XI. 簡化呼叫方式

<p align="center">
  <img

    width="700">
</p>

函式指標也可以直接寫：

```c
func();
```

```c

```

這是正常程式較常使用的形式。

# Part C：函式與物件的相似與不同

## Section XII. 共用「名稱」的概念

普通變數名稱：

```c
int value = 3;
```

`value` 用來代表特定 `int` 物件。

函式名稱／函式指示符：

```c
void hello(void);
```

`hello` 用來代表特定函式。

---

## Section XIII. 都可以使用取址運算子

物件：

```c
&value
```

取得物件指標：

```text
int *
```

函式：

```c
&hello
```

取得函式指標：

```text
void (*)(void)
```

---

## Section XIV. 都能使用指標保存位置

```c
int *object_pointer = &value;
void (*function_pointer)(void) = &hello;
```

但兩者是不同種類的指標：

- 物件指標指向資料物件。
- 函式指標指向可執行函式。

不能假設它們可以任意互相轉換。

---

## Section XV. 都可以使用 `*` 間接運算

物件指標：

```c
*object_pointer
```

取得所指的物件。

函式指標：

```c
*function_pointer
```

取得所指函式的函式指示符。

函式指示符之後可搭配：

```c
()
```

執行呼叫。

# Part D：函式指示符的特殊性

## Section XVI. 什麼是函式指示符？

對已宣告的函式：

```c
void hello(void);
```

運算式：

```c
hello
```

代表該函式，稱為函式指示符。

在大多數運算式情境中，它會自動轉成：

```c
&hello
```

也就是函式指標。

---

## Section XVII. `hello` 與 `&hello`

下列兩種初始化都合法：

```c
void (*first)(void) = hello;
void (*second)(void) = &hello;
```

完整程式：

```c
#include <stdio.h>

void hello(void);

int main(void) {
    void (*first)(void) = hello;
    void (*second)(void) = &hello;

    first();
    second();

    return 0;
}

void hello(void) {
    printf("Hello world!\n");
}
```

輸出：

```text
Hello world!
Hello world!
```

---

## Section XVIII. 使用標準函式觀察規則

<p align="center">
  <img
    src="images/lesson_04/C_Advanced_04_img05_printf_pointer_relationship.png"
    alt="printf 與函式指標的關係"
    width="700">
</p>

來源使用：

```c
printf("Hello world!\n");
(&printf)("Hello world!\n");
(*printf)("Hello world!\n");
```


三行都呼叫 `printf()`。

---

### 4. `printf(...)`

`printf` 是函式指示符。

搭配函式呼叫運算子：

```c
()
```

完成呼叫。

---

### 5. `(&printf)(...)`

```c
&printf
```

取得指向 `printf` 的函式指標。

函式指標也能直接搭配：

```c
()
```

完成呼叫。

---

### 6. `(*printf)(...)`

推導：

```text
printf
→ 在 * 的運算元位置轉成 &printf
→ *(&printf)
→ 取得 printf 函式指示符
→ 搭配 () 呼叫
```

---

## Section XIX. 來源中的化簡關係

來源整理：

```text
*printf
→ *(&printf)
→ printf
→ 在需要指標的情境中又可轉成 &printf
```

因此以下形式可能仍可呼叫：

```c
(*func)();
(**func)();
(******func)();
```

但正常程式不應加入沒有意義的多重 `*`。

最清楚的寫法是：

```c
func();
```

或在教學中明確表示間接呼叫時：

```c
(*func)();
```

---

## Section XX. 教材補充：函式指示符轉換的例外

函式指示符在大多數情境中轉成函式指標，但對它直接使用：

```c
&
```

時，不需要先轉型，會直接取得函式位址。

函式不是可用 `sizeof` 測量的物件：

```c
/* sizeof(hello)  不合法 */
```

## Section XXIV. 改指向 `multiply()`

<p align="center">
  <img
    src="images/lesson_04/C_Advanced_04_img07_switch_function_target.png"
    alt="同一函式指標切換不同函式"
    width="700">
</p>

```c
#include <stdio.h>

int add(int a, int b);
int multiply(int a, int b);

int main(void) {
    int (*op)(int, int) = multiply;

    printf("%d\n", op(3, 5));

    op = add;

    printf("%d\n", op(3, 5));

    return 0;
}

int add(int a, int b) {
    return a + b;
}

int multiply(int a, int b) {
    return a * b;
}
```

輸出：

```text
15
8
```

同一個函式指標可以先後指向不同函式，只要函式型態相容。

# Part F：函式指標型態相容性

## Section XXV. 必須比較哪些部分？

<p align="center">
  <img
    src="images/lesson_04/C_Advanced_04_img08_function_pointer_compatibility.png"
    alt="函式指標型態相容性"
    width="700">
</p>

函式指標要安全指向某函式，至少需要正確匹配：

1. 回傳型態。
2. 參數數量。
3. 每個參數型態。
4. 是否使用可變參數。

---

### 7. 相容範例

```c
int add(int, int);
int multiply(int, int);

int (*op)(int, int);
```

`op` 可以指向 `add` 或 `multiply`。

---

### 8. 不相容範例

```c
double divide(double, double);
int (*op)(int, int);

/* op = divide; */
```

回傳型態與參數型態都不同。

---

### 9. 不要用強制轉型掩蓋問題

危險：

```c
op = (int (*)(int, int))divide;
```

強制轉型可能讓編譯器不再顯示原本的不相容診斷，但呼叫時仍會按照錯誤的參數與回傳規則執行，可能造成未定義行為。

---

## Section XXVI. 教材補充：無參數函式的正確宣告

在 C 中：

```c
void hello();
```

表示參數資訊未完整指定，不等同於明確表示「沒有參數」。

本講義使用：

```c
void hello(void);
```

明確表示不接收任何參數。

同理，函式指標寫成：

```c
void (*func)(void);
```

# Part G：在函式間傳遞函式

## Section XXVII. 原始固定計算方式

來源先計算：

```text
1 + 2 + 3 + 4 + 5
```

```c
int calculate(void) {
    int result = 1;

    for (int i = 2; i <= 5; i++) {
        result = result + i;
    }

    return result;
}
```

輸出：

```text
15
```

## Section XXXIII. 這就是 callback

<p align="center">

`calculate()` 不知道自己收到的一定是加法或乘法。

# Part J：函式指標的限制與安全使用

## Section XLII. 函式指標不能進行算術運算

普通陣列元素指標可在合法陣列範圍內：

```c
pointer + 1
pointer++
```

函式並不是陣列元素。

不能寫：

```c
/* func++; */
/* func + 1; */
```

C 沒有定義函式指標算術。

---

## Section XLIII. 使用 `NULL`

函式指標可以表示目前沒有指向任何函式：

```c
int (*op)(int, int) = NULL;
```

呼叫前：

```c
if (op != NULL) {
    int result = op(3, 5);
}
```

不能呼叫 `NULL` 函式指標。

---

## Section XLIV. 比較函式指標

相容函式指標可以比較是否相等：

```c
if (op == add) {
    printf("Current operation is add.\n");
}
```

這可以判斷目前指向哪一個函式。

---

## Section XLV. 函式指標不是 `void *`

教材補充：

`void *` 是通用**物件指標**。

C 標準不保證函式指標可以安全轉成 `void *` 再轉回。

不要假設：

```c
void *generic = (void *)add;
```

是可攜的函式保存方式。

應使用正確的函式指標型態。

---

## Section XLVI. 函式指標型態必須正確

錯誤型態可能導致：

- 參數使用錯誤暫存器或堆疊位置。
- 回傳值被使用錯誤方式解讀。
- 呼叫端與被呼叫端對參數數量理解不同。
- 未定義行為。

強制轉型不能修正真正的函式介面。

---

# Part K：容易搞混的重點

## Section XLVII. 函式與函式指標

```c
int add(int, int);
```

`add` 是函式。

```c
int (*op)(int, int);
```

`op` 是函式指標變數。

---

## Section XLVIII. 回傳指標的函式與函式指標

```c
int *make_value(void);
```

`make_value` 是函式，回傳 `int *`。

```c
int (*make_value)(void);
```

`make_value` 是指標，指向回傳 `int` 的函式。

變數名稱周圍的括號決定意義。

---

## Section XLIX. `*func()` 與 `(*func)()`

假設：

```c
int *(*func)(void);
```

```c
*func()
```

會先呼叫 `func()` 所指的函式，再對回傳的指標解參照。

```c
(*func)()
```

先對函式指標使用 `*` 取得函式指示符，再呼叫。

括號位置不同，運算順序不同。

---

## Section L. `hello` 與 `hello()`

<p align="center">
  <img
    src="images/lesson_04/C_Advanced_04_img12_function_vs_function_call.png"
    alt="函式本身與立即呼叫函式的差異"
    width="700">
</p>

```c
hello
```

代表函式指示符，在大多數情境中轉成函式指標。

```c

```

會真正執行函式。

傳入 callback 時應傳：

```c

```

不是：

```c

```

後者會先執行 `add()`，得到整數 `8`，不是函式指標。

函式型態不能這樣複製。

---

### 錯誤 3：函式指標型態不相容

參數或回傳型態不同時不能安全共用。

---

### 錯誤 4：以強制轉型隱藏函式型態問題

轉型不會改變函式真正的呼叫介面。

---

### 錯誤 5：傳入函式呼叫結果

```c
calculate(add(3, 5));
```

傳入的是整數，不是函式。

---

### 錯誤 6：呼叫 `NULL` 函式指標

必須先檢查：

```c
op != NULL
```

---

### 錯誤 7：對函式指標進行 `++`

函式指標沒有合法的陣列算術。

---

### 錯誤 8：把函式指標當成 `void *`

C 不保證函式指標與物件指標可以可攜地互轉。

---

### 錯誤 9：使用 `void hello()` 表示沒有參數

在 C 中應使用：

```c
void hello(void)
```

明確表示沒有參數。

---

### 錯誤 10：過度使用 `(*func)()`

此寫法合法，但正常情況下：

```c
func()
```

更容易閱讀。

---

### 錯誤 11：加入多個無意義的 `*`

來源用來展示特殊規則，但不適合作為程式風格。

---

### 錯誤 12：混淆函式與函式指標變數

`add` 是函式；`op` 是可改指向其他相容函式的指標變數。

---

### 錯誤 13：函式指標陣列索引越界

```c
operations[choice]
```

呼叫前必須檢查 `choice` 的合法範圍。

---

### 錯誤 14：忘記初始化函式指標

未初始化的區域函式指標具有不確定值，不能呼叫。

---

### 錯誤 15：假設 callback 會自動知道額外資料

函式指標只指定函式。若 callback 需要額外狀態，必須透過參數、結構或其他明確方式提供。

---

### 錯誤 16：把 `typedef` 名稱誤認成函式

`BinaryOperation` 是型態名稱，不是可呼叫函式。

---

### 錯誤 17：忽略可變參數差異

像 `printf` 一樣的可變參數函式，型態與固定參數函式不同。

---

### 錯誤 18：callback 的初始值不適合所有操作

來源的 `result = 1` 適合加法與乘法示範，但一般化時應由呼叫端提供正確初始值。
