# Lesson 01：Advanced Pointers 進階指標

> 這堂課的重點：進一步理解「指標的陣列」與「陣列的指標」是兩種完全不同的型態，並將它們應用到一維陣列、二維陣列與多個字串。接著比較真正的二維陣列、指標陣列與扁平化記憶體在函式參數中的差異，最後完成輸入不定個數字串及降低未使用空間的儲存優化。

> 本章依照 `28-01` 到 `28-10` 的投影片編排。這批來源沒有涵蓋指標強制轉型規則與函式指標，因此本章不加入這兩個主題。

## Section II. 今天的學習方式

1. 從變數名稱開始向外閱讀複雜宣告。
2. 看見 `[]` 時先判斷它是否表示陣列。
3. 看見 `()` 包住 `*name` 時，先判斷變數本身是指標。
4. 對以下兩行分別畫記憶體圖：
   ```c
   int *p[3];
   int (*q)[3];
   ```
5. 每個指標陣列元素都畫成一個獨立位址格。
6. 陣列指標則畫成單一指標，箭頭指向整個陣列物件。
7. 使用 `p[i][j]` 時分兩步閱讀：
   ```text
   p[i] 取得第 i 個指標
   → p[i][j] 取得該指標所指陣列的第 j 個元素
   ```
8. 使用 `(*q)[i]` 時先解參照 `q`，取得完整陣列，再取下標。
9. 函式參數題必須列出呼叫端運算式與參數型態。
10. 不只看位址數字相同，還要比較 C 型態是否相容。
11. 二維陣列題先寫出每一列的型態。
12. 真正二維陣列的第一層元素是完整的一維陣列，不是獨立指標。
13. `int **` 題要畫出兩層箭頭，確認第一層是否真的存有列指標。
14. 扁平化存取時先算：
    ```text
    row * width + column
    ```
15. 多個字串題同時標出：
    - 文字內容存在哪裡
    - 指標存在哪裡
    - 內容是否可修改
    - 指標是否可改指向
16. 優化題分開記錄：
    ```text
    len  = 字串數量
    size = 已使用字元數量
    ```
17. 所有完整合法 C 程式均使用嚴格 C17 選項編譯。
18. 來源中的不安全輸入寫法只用來說明推導；完整版本使用格式寬度與容量檢查。

## Section III. 核心宣告對照

| 宣告 | 由名稱向外閱讀 | 意義 |
| --- | --- | --- |
| `int values[3]` | `values` 是三元素陣列 | 每個元素是 `int` |
| `int *pointer` | `pointer` 是指標 | 指向 `int` |
| `int *pointers[3]` | `pointers` 是三元素陣列 | 每個元素是 `int *` |

| `int **pointer` | `pointer` 是指標 | 指向 `int *` |

| `const char *words[3]` | `words` 是三元素陣列 | 每個元素是 `const char *` |

# Part A：指標陣列

## Section IV. 一般陣列與指標陣列

<p align="center">
  <img
    src="images/lesson_01/C_Advanced_01_img01_pointer_array.png"
    alt="指標陣列的記憶體結構"
    width="700">
</p>

### 1. 一般整數陣列

```c
int values[3];
```

配置：

```text
values[0] values[1] values[2]
   int       int       int
```

每個元素保存一個整數。

---

### 2. 指標陣列

```c
int *pointers[3];
```

配置：

```text
pointers[0] pointers[1] pointers[2]
    int *       int *       int *
```

每個元素保存某個 `int` 物件的位址。

---

### 3. 為什麼它是陣列？

下標運算比前面的 `*` 更靠近變數名稱：

```c
int *pointers[3];
```

由 `pointers` 向外讀：

```text
pointers
→ 是具有三個元素的陣列
→ 每個元素是 int *
```

---

## Section V. 指標陣列指向同一陣列的元素

### 4. 按照原順序初始化

```c
#include <stdio.h>

int main(void) {
    int values[3] = {1, 2, 3};
    int *pointers[3] = {
        &values[0],
        &values[1],
        &values[2]
    };

    for (int i = 0; i < 3; i++) {
        *pointers[i] = 0;
    }

    *pointers[2] = 5;

    for (int i = 0; i < 3; i++) {
        printf("%d ", values[i]);
    }

    printf("\n");

    return 0;
}
```

輸出：

```text
0 0 5
```

---

### 5. `*pointers[i]` 的閱讀方式

```c
*pointers[i]
```

因為下標優先於前置 `*`，等同：

```c
*(pointers[i])
```

1. `pointers[i]` 取得第 `i` 個 `int *`。
2. `*` 取得該指標所指的整數。

---

### 6. 指標順序可以不同

```c
int *pointers[3] = {
    &values[2],
    &values[1],
    &values[0]
};
```

現在：

```text
pointers[0] → values[2]
pointers[1] → values[1]
pointers[2] → values[0]
```

因此：

```c
*pointers[2] = 5;
```

修改的是：

```c
values[0]
```

指標陣列的順序不必與原陣列元素順序相同。

---

## Section VI. 指標陣列指向獨立變數

```c
#include <stdio.h>

int main(void) {
    int a = 1;
    int b = 2;
    int c = 3;

    int *pointers[3] = {
        &a,
        &b,
        &c
    };

    for (int i = 0; i < 3; i++) {
        *pointers[i] = 0;
    }

    *pointers[2] = 5;

    printf("%d %d %d\n", a, b, c);

    return 0;
}
```

輸出：

```text
0 0 5
```

指標陣列中的目標不必來自同一個陣列，只要型態與生命週期合法即可。

---

## Section VII. 指標陣列指向多個陣列

### 7. 每個元素指向一列

```c
int first[2] = {1, 2};
int second[2] = {3, 4};
int third[2] = {5, 6};

int *rows[3] = {
    first,
    second,
    third
};
```

每個一維陣列名稱會轉成第一個元素的位址：

```text
rows[0] → &first[0]
rows[1] → &second[0]
rows[2] → &third[0]
```

---

### 8. 使用兩個下標

```c
rows[i][j]
```

等同：

```c
*(rows[i] + j)
```

第一個下標選擇哪一個列指標，第二個下標選擇該列中的元素。

---

### 9. 完整存取範例

```c
#include <stdio.h>

int main(void) {
    int first[2] = {1, 2};
    int second[2] = {3, 4};
    int third[2] = {5, 6};

    int *rows[3] = {
        first,
        second,
        third
    };

    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 2; j++) {
            rows[i][j] = 0;
        }
    }

    rows[2][0] = 7;

    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 2; j++) {
            printf("%d ", rows[i][j]);
        }
        printf("\n");
    }

    return 0;
}
```

---

## Section VIII. 每一列可以有不同長度

```c
int first[4] = {1, 2, 7, 8};
int second[2] = {3, 4};
int third[2] = {5, 6};

int *rows[3] = {
    first,
    second,
    third
};
```

合法：

```c
rows[0][2] = 9;
```

因為 `rows[0]` 指向長度四的 `first`。

錯誤：

```c
rows[1][2] = 10;
```

`second` 只有兩個元素，合法索引為 `0` 與 `1`。

> 指標陣列只保存起始位址，不會自動保存每一列的長度。若列長不同，程式必須另外保存每列長度。

## Section X. 使用陣列指標存取元素

```c
#include <stdio.h>

int main(void) {
    int values[3] = {1, 2, 3};
    int (*array_pointer)[3] = &values;

    for (int i = 0; i < 3; i++) {
        (*array_pointer)[i] = 0;
    }

    (*array_pointer)[2] = 5;

    for (int i = 0; i < 3; i++) {
        printf("%d ", values[i]);
    }

    printf("\n");

    return 0;
}
```

輸出：

```text
0 0 5
```

---

### 14. 為什麼需要括號？

<p align="center">
  <img
    src="images/lesson_01/C_Advanced_01_img04_parentheses_precedence.png"
    alt="指標宣告中括號與下標的優先順序"
    width="700">
</p>

```c
(*array_pointer)[i]
```

1. `*array_pointer` 取得完整 `int[3]` 陣列。
2. `[i]` 取得其中第 `i` 個整數。

若寫：

```c
*array_pointer[i]
```

會先執行：

```c
array_pointer[i]
```

意義完全不同。

# Part C：在函式間傳遞一維陣列

## Section XI. 使用陣列指標傳遞固定長度陣列

### 15. 固定三元素版本

```c
#include <stdio.h>

void print_three(const int (*values)[3]) {
    size_t length =
        sizeof(*values) / sizeof((*values)[0]);

    for (size_t i = 0; i < length; i++) {
        printf("%d ", (*values)[i]);
    }

    printf("\n");
}

int main(void) {
    int values[3] = {1, 2, 3};

    print_three(&values);

    return 0;
}
```

---

### 16. 為什麼函式內可以使用 `sizeof`？

參數：

```c
const int (*values)[3]
```

所指物件型態仍然是完整的：

```text
const int[3]
```

因此：

```c
sizeof(*values)
```

得到完整三元素陣列的大小。

---

### 17. 固定長度成為型態的一部分

指向三元素陣列：

```c
int (*)[3]
```

指向五元素陣列：

```c
int (*)[5]
```

兩者是不同型態。

因此固定三元素版本不能直接共用於五元素陣列。

---

## Section XII. 使用一般元素指標與長度

```c
#include <stdio.h>

void print_values(
    const int *values,
    size_t length
) {
    for (size_t i = 0; i < length; i++) {
        printf("%d ", values[i]);
    }

    printf("\n");
}

int main(void) {
    int first[3] = {1, 2, 3};
    int second[5] = {1, 2, 3, 4, 5};

    print_values(first, 3);
    print_values(second, 5);

    return 0;
}
```

同一個函式可處理不同長度陣列。

代價是呼叫者必須另外提供正確長度。

---

### 18. 為什麼不能只在函式內使用 `sizeof(values)`？

參數：

```c
const int *values
```

是指標。

```c
sizeof(values)
```

得到指標本身大小，不是呼叫端陣列大小。

---

### 19. 指向未知長度陣列的問題

概念宣告：

```c
int (*values)[];
```

這是指向不完整陣列型態的指標。

因為元素數量未知，不能使用：

```c
sizeof(*values)
```

計算完整陣列大小。

因此實務上仍要：

- 固定長度寫入型態；或
- 使用元素指標並另外傳入長度。

## Section XIV. 固定欄數的二維陣列參數

```c
#include <stdio.h>

void print_grid(
    const int grid[][3],
    size_t height
) {
    for (size_t i = 0; i < height; i++) {
        for (size_t j = 0; j < 3; j++) {
            printf("%d ", grid[i][j]);
        }
        printf("\n");
    }
}

int main(void) {
    int grid[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    print_grid(grid, 2);

    return 0;
}
```

在函式參數中：

```c
const int grid[][3]
```

會調整成：

```c
const int (*grid)[3]
```

---

### 21. 為什麼可以省略第一維？

函式接收的是指向第一列的指標。

列數可由另外的 `height` 參數提供。

---

### 22. 為什麼必須知道欄數？

若每列有三個 `int`：

```c
grid + 1
```

必須向後跳過一整列，也就是三個 `int`。

編譯器需要知道每列型態是：

```text
int[3]
```

才能正確計算下一列位置。

---

## Section XV. 三種相關位址

已知：

```c
int grid[3][3];
```

| 運算式 | 型態 | 意義 |
| --- | --- | --- |
| `grid` | `int (*)[3]` | 第一列位址 |
| `&grid[0]` | `int (*)[3]` | 第一列位址 |
| `&grid` | `int (*)[3][3]` | 完整 3×3 陣列位址 |

位址數字可能相同，但型態不同，指標加一時移動距離也不同。

---

### 23. 指向完整二維陣列

```c
#include <stdio.h>

void print_complete(
    const int (*grid)[3][3]
) {
    for (size_t i = 0; i < 3; i++) {
        for (size_t j = 0; j < 3; j++) {
            printf("%d ", (*grid)[i][j]);
        }
        printf("\n");
    }
}

int main(void) {
    int grid[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    print_complete(&grid);

    return 0;
}
```

這個介面將兩個維度都固定在型態中，因此不適合處理其他高度或寬度。

# Part E：為什麼真正二維陣列不是 `int **`

<p align="center">
  <img
    src="images/lesson_01/C_Advanced_01_img06_2d_array_vs_double_pointer.png"
    alt="真正二維陣列與雙重指標的差異"
    width="700">
</p>

## Section XVI. `int **` 需要兩層指標結構

參數：

```c
void print_rows(
    int **rows,
    size_t height,
    size_t width
);
```

期待：

```text
rows
→ 指向第一個 int *
→ 每個 int * 再指向一列 int
```

也就是記憶體中必須真的存在一個「列指標陣列」。

---

### 24. 真正二維陣列沒有列指標陣列

```c
int grid[2][3];
```

記憶體直接保存六個連續整數：

```text
grid[0][0] grid[0][1] grid[0][2]
grid[1][0] grid[1][1] grid[1][2]
```

其中沒有額外存放：

```text
&grid[0]
&grid[1]
```

這兩個指標值的陣列。

因此：

```c
print_rows(grid, 2, 3);
```

不能將 `int (*)[3]` 當成 `int **`。

# Part F：使用指標陣列傳遞二維資料

## Section XVII. 建立列指標陣列

```c
#include <stdio.h>

void print_rows(
    int *const rows[],
    size_t height,
    size_t width
) {
    for (size_t i = 0; i < height; i++) {
        for (size_t j = 0; j < width; j++) {
            printf("%d ", rows[i][j]);
        }
        printf("\n");
    }
}

int main(void) {
    int grid[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    int *rows[3] = {
        grid[0],
        grid[1],
        grid[2]
    };

    print_rows(rows, 3, 3);

    return 0;
}
```

函式參數中的：

```c
int *const rows[]
```

會調整成指向列指標的指標。

---

### 25. 指標陣列提供了什麼額外資訊？

真正二維陣列只保存資料元素。

指標陣列額外保存：

```text
rows[0] → 第一列起始位置
rows[1] → 第二列起始位置
rows[2] → 第三列起始位置
```

因此可傳給需要兩層指標結構的函式。

---

### 26. 可以重新排列列順序

<p align="center">
  <img

```c
int *rows[3] = {
    grid[0],

    grid[1]

```

輸出順序會變成：

```text
第一列
第三列
第二列
```

而 `grid` 內部資料配置沒有被搬動。

### 27. 可以指向不同長度的列

```c
int first[4] = {1, 2, 3, 4};
int second[2] = {5, 6};
int third[3] = {7, 8, 9};

int *rows[3] = {
    first,
    second,
    third
};
```

但此時不能使用同一個固定 `width` 安全走訪所有列。

需要另外保存每列長度：

```c
size_t widths[3] = {4, 2, 3};
```

# Part G：傳遞任意長寬二維資料

## Section XVIII. 方法一：固定欄數的陣列指標

```c
void print_grid(
```

優點：

- 保留真正二維陣列的列型態。
- 可直接使用 `grid[i][j]`。

限制：

- 欄數 `3` 是型態的一部分。
- 不能直接處理欄數不同的陣列。

## Section XIX. 方法二：列指標陣列

```c
void print_rows(
    int *const rows[],
    size_t height,
    const size_t widths[]

```

優點：

- 每列可以位於不同位置。
- 每列可以具有不同長度。
- 可重新排列列順序。

限制：

- 呼叫端必須真正建立列指標。
- 需要額外指標儲存空間。
- 不能直接把真正二維陣列轉成 `int **`。

## Section XX. 方法三：扁平化指標與寬度

來源最後將連續二維資料視為一串 `int`，使用：

```text
索引 = row * width + column
```

存取：

```c
*(data + row * width + column)
```

---

### 28. 完整扁平化範例

```c
#include <stdio.h>

void print_flat(
    const int *data,
    size_t height,
    size_t width
) {
    for (size_t i = 0; i < height; i++) {
        for (size_t j = 0; j < width; j++) {
            printf(
                "%d ",
                *(data + i * width + j)
            );
        }
        printf("\n");
    }
}

int main(void) {
    int grid[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    print_flat(
        &grid[0][0],
        3,
        3
    );

    return 0;
}
```

# Part H：儲存多個字串

## Section XXI. 使用二維字元陣列

```c
char words[3][4] = {
    "How",
    "are",
    "you"
};
```

配置：

```text
words[0] = {'H', 'o', 'w', '\0'}
words[1] = {'a', 'r', 'e', '\0'}
words[2] = {'y', 'o', 'u', '\0'}
```

每一列固定四格。

---

### 32. 修改單一字元

```c
words[2][0] = 'Y';
```

合法，因為 `words` 自己擁有可修改的 `char` 陣列。

---

### 33. 一列不能改指向其他字串

錯誤：

```c
words[0] = "What";
```

`words[0]` 是陣列，不是可以重新賦值的指標。

---

### 34. `strcpy()` 仍受列容量限制

```c
strcpy(words[0], "What");
```

`"What"` 需要：

```text
5 格
```

但 `words[0]` 只有四格，因此會寫出該列範圍。

即使使用字串複製函式，也不會自動增加目的地容量。

---

## Section XXII. 使用字串指標陣列

```c
const char *words[3] = {
    "How",
    "are",
    "you"
};
```

配置分成兩部分：

1. 三個 `const char *` 指標元素。
2. 三個字串字面常數的文字內容。

---

### 35. 不能修改字串字面常數

錯誤：

```c
words[2][0] = 'Y';
```

指標指向字串字面常數，不可透過它修改內容。

---

### 36. 可以改變指標元素的指向

```c
words[0] = "What";
```

合法。

只會讓：

```text
words[0]
```

改指向另一個字串字面常數，不會修改原本 `"How"`。

---

## Section XXIII. 兩種方法比較

| --- | --- | --- |

# Part J：輸入不定個數字串

## Section XXV. 題目

讓使用者逐一輸入多個單字：

```text
How
Are
You
END
```

輸入：

```text
END
```

時停止，最後輸出：

```text
How Are You
```

來源練習以 `%s` 讀取，因此每次輸入是一個不含空白的單字。

---

## Section XXVI. 判斷結束字串

需要：

```c
#include <string.h>
```

判斷：

```c
strcmp(input, "END") == 0
```

不能使用：

```c
input == "END"
```

因為後者比較位址，不是字串內容。

---

## Section XXVII. 固定二維陣列版本

來源逐步建立：

```c
char words[100][5];
char input[5];
int length = 0;
```

每個字串最多保存：

```text
4 個可見字元 + '\0'
```

---

### 40. 安全完整版本

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char words[100][5];
    char input[5];
    size_t length = 0;

    while (length < 100) {
        if (scanf("%4s", input) != 1) {
            break;
        }

        if (strcmp(input, "END") == 0) {
            break;
        }

        strcpy(words[length], input);
        length++;
    }

    printf("------\n");

    for (size_t i = 0; i < length; i++) {
        printf("%s ", words[i]);
    }

    printf("\n");

    return 0;
}
```

---

### 41. 為什麼使用 `%4s`？

目標陣列：

```c
char input[5];
```

需要保留一格給：

```c
'\0'
```

因此最多讀入四個非空白字元。

來源投影片使用 `%s` 來推導流程；完整程式加入寬度限制，避免輸入過長造成溢位。

---

### 42. 固定二維陣列的限制

```c
char words[100][50];
```

無論每個單字實際多短，都為每一列保留五十格。

例如只輸入：

```text
How
Are
You
```

實際文字含三個結束字元只需要：

```text
4 + 4 + 4 = 12 格
```

但固定配置：

```text
100 × 50 = 5000 格
```

大量空間未使用。

# Part K：緊密儲存多個字串

## Section XXVIII. 單一原始字元陣列

來源優化方法：

```c
char raw[5000];
char *words[100];
```

- `raw` 保存所有字串內容。
- `words[i]` 保存第 `i` 個字串在 `raw` 中的起始位置。

### 43. `size` 與 `length`

```c
size_t size = 0;
size_t length = 0;
```

| 變數 | 意義 |
| --- | --- |
| `length` | 已保存幾個字串 |
| `size` | `raw` 中已使用幾個字元位置 |

---

### 44. 保存一個新字串

```c
words[length] = raw + size;
strcpy(words[length], input);

size += strlen(input) + 1;

```

步驟：

1. 讓下一個指標指向目前未使用區域。
2. 將輸入字串複製到該位置。
3. 將 `size` 增加文字長度。
4. 再增加一格，計入 `'\0'`。
5. 將字串數量增加一。

### 45. 記憶體圖

### 46. 安全完整版本

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char raw[5000];
    char *words[100];
    char input[50];

    size_t size = 0;
    size_t length = 0;

    while (length < 100) {
        size_t needed;

        if (scanf("%49s", input) != 1) {
            break;
        }

        if (strcmp(input, "END") == 0) {
            break;
        }

        needed = strlen(input) + 1;

        if (needed > sizeof(raw) - size) {
            fprintf(
                stderr,
                "Storage is full.\n"
            );
            break;
        }

        words[length] = raw + size;
        strcpy(words[length], input);

        size += needed;
        length++;
    }

    printf("------\n");

    for (size_t i = 0; i < length; i++) {
        printf("%s ", words[i]);
    }

    printf("\n");
    printf(
        "(strings: %zu, bytes used: %zu)\n",
        length,
        size
    );

    return 0;
}
```

## Section XXIX. 固定二維陣列與緊密儲存比較

| 特性 | 固定二維陣列 | `raw` + 指標陣列 |
| --- | --- | --- |
| 宣告 | `char words[N][M]` | `char raw[B]` + `char *words[N]` |
| 每列容量 | 全部相同 | 依實際字串長度 |
| 未使用空間 | 可能很多 | 較少 |
| 存取方式 | `words[i]` | `words[i]` |
| 內容是否連續 | 固定列形式連續 | 所有文字緊密連續 |
| 指標額外空間 | 無 | 每個字串一個指標 |
| 新增前檢查 | 字串長度與列數 | 原始字元容量與指標數量 |
| 某個字串改指向 | 不可 | 可 |
| 刪除中間字串 | 需搬動或標記 | 指標易調整，但原字元空間不會自動回收 |

## Section XXX. 來源方法仍有固定上限

名稱是「輸入不定個數字串」，但來源最終版本仍使用：

```c
char raw[5000];
char *words[100];
```

因此實際上限仍然是：

- 最多一百個字串。
- 所有字串與結束字元總共最多五千格。
- 單次輸入暫存陣列也有長度限制。

它的「不定個數」是指執行前不需要知道實際會輸入幾個，但仍受到預先配置容量限制。

若需要真正可成長空間，可在後續動態記憶體章節使用 `malloc()` 與 `realloc()`。

# Part M：容易搞混的重點

## Section XXXII. 指標陣列不等於二維陣列

包含三個位址。

真正二維陣列：

```c
int grid[3][3];
```

包含九個整數，沒有三個列指標物件。

## Section XXXIII. 陣列指標不等於元素指標

```c
int *element_pointer;
```

加一移動一個 `int`。

```c
int (*row_pointer)[3];
```

加一移動一整列，也就是三個 `int`。

---

## Section XXXIV. 位址數字相同不代表型態相同

對 `int grid[3][3]`：

```c
grid
&grid[0]
&grid
&grid[0][0]
```

在輸出時可能顯示同一起始數字，但型態與指標加一的距離不同。

---

## Section XXXV. `int **` 不能修正錯誤型態

即使使用強制轉型把真正二維陣列轉成 `int **`，記憶體中仍不存在列指標陣列。

函式會把前幾個整數內容錯當成位址，造成未定義行為。

強制轉型只改變編譯器看待運算式的型態，不會重新建立正確記憶體結構。

---

## Section XXXVI. 每列長度不同時要保存長度

```c
int *rows[3];
```

只知道三個列起始位置。

不知道各列有多少元素。

應另外保存：

```c
size_t widths[3];
```

---

## Section XXXVII. 字串指標可以改指向，不代表內容可修改

```c
const char *words[3];
```

- `words[i]` 可以改成另一個位址。
- 不能透過它修改字串字面常數。

---

## Section XXXVIII. `strcpy()` 不會檢查容量

目的地容量不足仍會繼續寫入。

在呼叫前必須自行保證：

```text
destination capacity
>=
strlen(source) + 1
```

---

## Section XXXIX. 緊密儲存需要兩種容量檢查

<p align="center">
  <img
    src="images/lesson_01/C_Advanced_01_img12_compact_storage_capacity.png"

    width="700">
</p>

1. 字串指標陣列是否還有空格：
   ```c
   length < pointer_capacity
   ```
2. `raw` 是否仍有足夠字元空間：
   ```c
   strlen(input) + 1 <= raw_capacity - size
   ```

# Part R：常見錯誤提醒

## Section XLIV. 常見錯誤

### 錯誤 1：漏掉陣列指標括號

```c
int *p[3];
```

不是陣列指標，而是指標陣列。

---

### 錯誤 2：將指標陣列當成所有列等長

指標陣列本身不保存列長度。

---

### 錯誤 3：使用超過該列實際長度的第二個下標

會造成未定義行為。

---

### 錯誤 4：使用 `sizeof(pointer)` 計算呼叫端陣列長度

只會得到指標大小。

---

### 錯誤 5：以為 `int (*p)[]` 可以知道陣列長度

所指陣列型態不完整，無法取得完整 `sizeof(*p)`。

---

### 錯誤 6：省略二維陣列參數的欄數

編譯器無法計算下一列位置。

---

### 錯誤 7：把真正二維陣列傳給 `int **`

兩種記憶體結構不同。

---

### 錯誤 8：使用強制轉型掩蓋 `int (*)[N]` 與 `int **` 的不相容

轉型不會建立列指標陣列。

---

### 錯誤 9：解讀相同位址數字時忽略型態

`grid`、`&grid[0]` 與 `&grid` 的移動單位不同。

---

### 錯誤 10：扁平化時使用錯誤欄數

會計算出錯誤元素位置。

---

### 錯誤 11：修改字串字面常數

```c
const char *word = "test";

/* word[0] = 'T'; */
```

不可透過指標修改。

---

### 錯誤 12：把二維陣列的一列當成可重新賦值指標

```c
words[0] = "new";
```

對二維陣列不合法。

---

### 錯誤 13：使用 `strcpy()` 複製較長字串到較短列

造成緩衝區溢位。

---

### 錯誤 14：使用 `%s` 時沒有格式寬度

輸入可能超過暫存陣列容量。

---

### 錯誤 15：未限制可保存字串數量

會寫出字串指標陣列或二維陣列範圍。

---

### 錯誤 16：緊密儲存時忘記計入 `'\0'`

下一個字串會覆蓋前一個字串的結束位置。

---

### 錯誤 17：只檢查 `raw` 容量，不檢查指標陣列容量

即使字元空間仍足夠，也可能沒有位置保存新字串指標。

---

### 錯誤 18：將 `length` 與 `size` 混為一談

一個是字串數量，一個是字元數量。
