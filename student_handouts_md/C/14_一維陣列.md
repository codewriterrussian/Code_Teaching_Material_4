## Section IV. 寫題目前的提醒

### 1. 陣列只能保存相同資料型態的元素

```c
int values[5];
```

這五個元素全部都是 `int`。

不能讓同一個 C 陣列中的部分元素是 `int`、另一部分是 `double`。

---

### 2. 宣告語法中的方括號表示元素個數

```c
int values[5];
```

代表建立五個整數元素，不是建立索引為 `5` 的單一元素。

---

### 3. 五個元素的索引是 `0–4`

```text
values[0]
values[1]
values[2]
values[3]
values[4]
```

沒有合法的：

```c
values[5]
```

---

### 4. 最後一個合法索引是元素個數減一

<p align="center">
  <img
    src="images/lesson_14/C_Lesson_14_img03_length_vs_index.png"
    alt="元素個數與最大合法索引"
    width="700">
</p>


```text
最後索引 = length - 1
```

長度為 `6`：

```text
最後索引 = 5
```

---

### 5. 陣列元素可以像一般變數使用

```c
values[0] = 3;
values[1] = values[0] + 2;
printf("%d\n", values[1]);
```

`values[1]` 可以出現在指定的左邊，也可以出現在表示式中。

---

### 6. 未初始化的區域陣列內容不可靠

```c
int values[5];
```

若它是函式中的一般區域陣列，不能假設元素自動是 `0`。

使用前應明確設定或初始化。

---

### 7. 計數陣列一定要從 `0` 開始

```c
int counter[6] = {0};
```

每個元素代表目前出現次數。尚未開始統計時，全部應為 `0`。

---

### 8. 部分初始化會將剩餘元素設為 `0`

```c
int values[5] = {3, 5};
```

結果：

```text
values[0] = 3
values[1] = 5
values[2] = 0
values[3] = 0
values[4] = 0
```

---

### 9. `{0}` 不表示陣列只有一個元素

```c
int counter[6] = {0};
```

`6` 決定元素個數。

初始化串列只明確指定第一個元素為 `0`，其餘元素依初始化規則也會成為 `0`。

---

### 10. 有初始化串列時可以省略元素個數

```c
int prices[] = {90, 75, 83, 89, 71};
```

編譯器會依初始化值推得元素個數為 `5`。

下面則無法省略：

```c
int prices[];
```

因為編譯器不知道需要多少元素。

---

### 11. 循序存取通常從 `0` 開始

```c
for (i = 0; i < 5; i++) {
    printf("%d\n", values[i]);
}
```

不要習慣性從 `1` 開始，否則會漏掉第一個元素。

---

### 12. 陣列迴圈通常使用 `< length`

正確：

```c
for (i = 0; i < 5; i++)
```

錯誤：

```c
for (i = 0; i <= 5; i++)
```

後者會嘗試存取 `values[5]`。

---

### 13. 找最大值時，初始值應來自陣列

```c
int maximum = values[0];
```

不要固定寫：

```c
int maximum = 0;
```

如果陣列全部是負數，固定從 `0` 開始會得到錯誤結果。

---

### 14. 骰子點數與索引相差 `1`

骰子點數：

```text
1 2 3 4 5 6
```

陣列索引：

```text
0 1 2 3 4 5
```

轉換：

```c
index = dice - 1;
```

---

### 15. 輸出骰子次數時要做反向轉換

若索引是 `i`：

```c
printf("%d: %d\n", i + 1, counter[i]);
```

顯示給使用者的是骰子點數 `1–6`，不是內部索引 `0–5`。

---

### 16. 「隨機存取」不是「隨機產生索引」

隨機存取的重點是：

> 已知某個索引時，可以直接存取對應元素，不需要先讀過前面的元素。

例如：

```c
prices[id - 1]
```

商品編號決定要直接讀取哪個價格。

---

### 17. 直接使用索引前要確認編號合法

```c
if (id >= 1 && id <= 5) {
    total += prices[id - 1];
}
```

若 `id == 0` 時仍執行：

```c
total += prices[id - 1];
```

就會變成：

```c
prices[-1]
```

這是越界存取。

---

### 18. 結束值要在存取陣列之前處理

安全結構：

```c
while (1) {
    scanf("%d", &id);

    if (id == 0) {
        break;
    }

    if (id >= 1 && id <= 5) {
        total += prices[id - 1];
    }
}
```

---

### 19. 兩顆骰子的點數和不是 `1–12`

最小：

```text
1 + 1 = 2
```

最大：

```text
6 + 6 = 12
```

因此可能結果是：

```text
2, 3, 4, ..., 12
```

共有十一種。

---

### 20. 點數和與索引相差 `2`

點數和：

```text
2 3 4 ... 12
```

索引：

```text
0 1 2 ... 10
```

轉換：

```c
index = sum - 2;
```

---

## Section V. 核心概念說明

## Section V-A. 為什麼需要陣列？

### 1. 多個相同用途的變數

假設要保存三個整數：

```c
int a = 3;
int b = 5;
int c = 0;
```

這在數量很少時可以使用。

若要保存：

```text
100 個成績
6000 次骰子結果的分類
大量商品價格
```

就不適合建立：

```text
value1, value2, value3, ..., value100
```

---

### 2. 使用陣列整理同類資料

```c
int values[3];

values[0] = 3;
values[1] = 5;
values[2] = 0;
```

三個元素：

- 使用相同資料型態 `int`
- 使用相同陣列名稱 `values`
- 使用不同索引 `0`、`1`、`2`

---

## Section V-B. 一維陣列宣告與元素存取

### 5. 基本宣告語法

```c
元素資料型態 陣列變數名稱[元素個數];
```

範例：

```c
int values[3];
```

| 部分 | 內容 |
| --- | --- |
| 元素資料型態 | `int` |
| 陣列名稱 | `values` |
| 元素個數 | `3` |

---

### 6. 元素存取語法

```c
陣列變數名稱[元素索引];
```

範例：

```c
values[0] = 3;
values[1] = 5;
values[2] = 0;
```

---

### 7. 完整基本範例

```c
#include <stdio.h>

int main(void) {
    int values[3];

    values[0] = 3;
    values[1] = 5;
    values[2] = 0;

    printf("%d\n", values[0]);
    printf("%d\n", values[1]);
    printf("%d\n", values[2]);

    return 0;
}
```

輸出：

```text
3
5
0
```

---

### 8. 陣列元素參與運算

```c
#include <stdio.h>

int main(void) {
    int values[3] = {3, 5, 0};

    values[2] = values[0] + values[1];

    printf("%d\n", values[2]);

    return 0;
}
```

輸出：

```text
8
```

`values[2]` 與一般 `int` 變數一樣，可以被指定與輸出。

### 18. 使用迴圈找最大值

來源教材先使用獨立變數比較，再改用陣列與迴圈。

```c
#include <stdio.h>

int main(void) {
    int values[4] = {3, 5, 0, 7};
    int maximum = values[0];
    int i;

    for (i = 1; i < 4; i++) {
        if (values[i] > maximum) {
            maximum = values[i];
        }
    }

    printf("Max: %d\n", maximum);

    return 0;
}
```

為什麼從 `i = 1` 開始？

因為：

```c
maximum = values[0];
```

第一個元素已經作為初始最大值，不必再與自己比較。

## Section V-E. 一顆骰子的次數統計：沒有陣列

### 20. 題目

模擬擲六千次公正骰子，分別顯示點數 `1–6` 出現的次數。

最直接的版本建立六個計數器：

```c
int counter1 = 0;
int counter2 = 0;
int counter3 = 0;
int counter4 = 0;
int counter5 = 0;
int counter6 = 0;
```

每次擲骰子後使用 `switch` 增加對應變數。

---

### 21. 六個獨立變數版本

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    int counter1 = 0;
    int counter2 = 0;
    int counter3 = 0;
    int counter4 = 0;
    int counter5 = 0;
    int counter6 = 0;
    int i;

    srand((unsigned int)time(NULL));

    for (i = 1; i <= 6000; i++) {
        int dice = rand() % 6 + 1;

        switch (dice) {
            case 1: counter1++; break;
            case 2: counter2++; break;
            case 3: counter3++; break;
            case 4: counter4++; break;
            case 5: counter5++; break;
            case 6: counter6++; break;
        }
    }

    printf("1: %d\n", counter1);
    printf("2: %d\n", counter2);
    printf("3: %d\n", counter3);
    printf("4: %d\n", counter4);
    printf("5: %d\n", counter5);
    printf("6: %d\n", counter6);

    return 0;
}
```

這個版本能工作，但：

- 有六個用途相同的變數
- 有六個相似的 `case`
- 有六個相似的 `printf()`
- 若分類數量增加，程式會快速變長

### 23. 先保留 `switch`，只替換計數器

這一步先將資料整理成陣列，但仍保留原本的控制流程。

觀察：


### 26. 完整陣列版本

```c
int main(void) {
```

### 35. 安全的商品總額程式

```c
#include <stdio.h>

int main(void) {
    int prices[] = {90, 75, 83, 89, 71};

    int id;

    while (1) {
        scanf("%d", &id);

        if (id == 0) {
            break;
        }

        if (id >= 1 && id <= 5) {
            total += prices[id - 1];
        } else {
            printf("Invalid product ID.\n");
        }
    }

    printf("Total: %d\n", total);

    return 0;
}
```


## Section V-J. 容易搞混的重點

### 43. 元素個數與最大索引不同

```c
int values[6];
```

- 元素個數：`6`
- 最大索引：`5`

---

### 44. 方括號中的數字在不同位置意義不同

宣告：

```c
int values[6];
```

`6` 表示元素個數。

存取：

```c
values[5]
```

`5` 表示索引。

---

### 45. `counter[dice]` 不符合六元素設計

骰子可能是 `6`：

```c
counter[6]
```

但六元素陣列最後索引是 `5`。

因此要使用：

```c
counter[dice - 1]
```

---

### 46. `counter[i - 1]` 需要配合 `i = 1..6`

來源教材有一種輸出寫法：

```c
for (i = 1; i <= 6; i++) {
    printf("%d: %d\n", i, counter[i - 1]);
}
```

也可以使用更典型的零起始版本：

```c
for (i = 0; i < 6; i++) {
    printf("%d: %d\n", i + 1, counter[i]);
}
```

兩者映射相同。

---

### 47. 循序存取不代表只能正向

可以正向：

```c
for (i = 0; i < length; i++)
```

也可以反向：

```c
for (i = length - 1; i >= 0; i--)
```

只要依某種順序逐一處理元素，都屬於循序處理。

---

### 48. 直接存取不等於不需要檢查

```c
prices[id - 1]
```

很精簡，但只有在 `id` 合法時才安全。

程式長度減少不能取代範圍驗證。

---

### 49. `0` 可以是合法元素值，也可以是控制值

計數陣列中的：

```text
0
```

表示目前次數為零。

商品輸入中的：

```text
0
```

表示結束輸入。

同一個數值的意義由使用情境决定。

---

### 50. 兩顆骰子需要十一元素，不是十二元素

點數和範圍為 `2–12`，包含十一種結果。

可以选擇：

```c
int counter[11];
counter[sum - 2]++;
```

來源使用的就是這種緊密映射設計。

## Section XI. 重點複習

1. 陣列保存多個相同資料型態的元素。
2. 同一陣列元素使用一段連續的記憶体空間。
3. 一維陣列使用一個索引选取元素。
4. 宣告语法包含元素型態、陣列名稱與元素個數。
5. 第一個元素索引是 `0`。
6. 長度為 `N` 的陣列最後索引是 `N - 1`。
7. 陣列元素可以像一般變數參與运算。
8. 初始化串列使用大括號。
9. 部分初始化時，其餘元素會成為 `0`。
10. `{0}` 常用於將計數陣列全部初始化為零。
11. 有初始化串列時，可以省略元素個數。
12. 循序存取使用迴圈逐一處理元素。
13. 典型範圍是 `i = 0; i < length; i++`。
14. 找最大值時可以從第一個元素開始初始化。
15. 陣列可以取代大量用途相同的獨立變數。
16. 骰子點數 `1–6` 映射到索引 `0–5`。
17. 轉換公式是 `dice - 1`。
18. `counter[dice - 1]++` 能直接增加對應次數。
19. 使用迴圈可以輸出全部次數。
20. 随機存取表示根據索引直接取得元素。
21. 商品編號 `1–5` 映射到 `prices[0–4]`。
22. 轉換公式是 `id - 1`。
23. 結束值 `0` 必须在陣列存取前處理。
24. 陣列越界可能造成不可预測結果。
25. 兩顆骰子的點數和範圍是 `2–12`。
26. 十一種點數和需要十一元素陣列。
27. 點數和映射公式是 `sum - 2`。
28. 所有統計次數相加應等於實驗總次數。
29. 直接索引虽精簡，仍必须驗證範圍。
30. 下一章會使用陣列完成更多查询、最大值、最接近值、長條圖與眾數问題。

## Section XII. 常見錯誤提醒

<p align="center">
  <img
    src="images/lesson_14/C_Lesson_14_img11_array_bounds.png"
    alt="陣列合法索引與越界比較"
    width="700">
</p>


### 錯誤 1：把元素個數當成合法索引

```c
int values[5];
values[5] = 10;
```

合法最後索引是 `4`。

---

### 錯誤 2：迴圈條件使用 `<= length`

```c
for (i = 0; i <= 5; i++)
```

會多處理一次索引 `5`。

---

### 錯誤 3：從索引 `1` 開始遍歷

```c
for (i = 1; i < 5; i++)
```

會漏掉 `values[0]`。

---

### 錯誤 4：沒有初始化計數陣列

```c
int counter[6];
counter[dice - 1]++;
```

元素起始內容不可靠。

---

### 錯誤 5：骰子點數直接作為六元素索引

```c
counter[dice]++;
```

當 `dice == 6` 時越界。

---

### 錯誤 6：輸出標签與索引混淆

```c
printf("%d: %d\n", i, counter[i]);
```

若 `i` 從 `0` 開始，標签會顯示 `0–5`，不是點數 `1–6`。

應顯示：

```c
i + 1
```

---

### 錯誤 7：找最大值固定從 `0` 開始

全負數陣列會錯誤地保留 `0`。

---

### 錯誤 8：商品結束值被用於索引

```c
id = 0;
total += prices[id - 1];
```

會產生負索引。

---

### 錯誤 9：只檢查上限，沒有檢查下限

```c
if (id <= 5)
```

負數也可能通過。

應檢查：

```c
id >= 1 && id <= 5
```

---

### 錯誤 10：兩骰陣列使用十個元素

點數和有十一種，因此十元素陣列不足。

---

### 錯誤 11：兩骰映射減一

```c
counter[sum - 1]++;
```

點數和 `12` 會對應索引 `11`，超出十一元素陣列的 `0–10`。

正确：

```c
counter[sum - 2]++;
```

---

### 錯誤 12：輸入元素時漏掉 `&`

錯誤：

```c
scanf("%d", values[i]);
```

正确：

```c
scanf("%d", &values[i]);
```

---

### 錯誤 13：省略元素個數却沒有初始化串列

```c
int values[];
```

編譯器无法推得長度。

---

### 錯誤 14：認為直接存取一定比迴圈安全

直接存取減少程式码，但錯誤索引仍然會越界。

---

### 2. 循序存取陣列

```mermaid
flowchart TD
    A[index 設為 0] --> B{index 小於 length}
    B -- 否 --> E[處理結束]
    B -- 是 --> C[處理 array index]
    C --> D[index 加 1]
    D --> B
```

### 3. 找陣列最大值

```mermaid
flowchart TD
    A[maximum 設為第一個元素] --> B[index 設為 1]

    C -- 否 --> G[輸出 maximum]
    C -- 是 --> D{目前元素大於 maximum}
    D -- 是 --> E[更新 maximum]
    D -- 否 --> F[index 加 1]
    E --> F
    F --> C
```
