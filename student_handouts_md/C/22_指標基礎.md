## Section II. 今天的學習方式

1. 每個普通變數畫成一個記憶體方格。
2. 方格內寫入變數保存的資料值。
3. 方格外標記變數名稱。
4. 方格下方標記一個示意記憶體位址。
5. 指標變數也畫成自己的記憶體方格。
6. 指標方格內保存的是另一個方格的位址。
7. 使用箭頭表示：
   ```text
   指標變數 → 被指向的變數
   ```
8. 每遇到一個運算式，都同時寫出：
   - 運算式
   - 資料型別
   - 值的意義
9. 對 `count`、`&count`、`countAddr`、`*countAddr` 建立對照表。
10. 先判斷型別，再判斷賦值是否合理。
11. 將 `&` 讀成「取得……的位址」。
12. 將運算式中的 `*` 讀成「取得該位址所指的物件」。
13. 修改指標時，分辨是在改：
    - 指標保存的位址
    - 指標所指物件的值
14. 追蹤指標改指向另一個變數前後的箭頭。
15. `*&` 與 `&*` 題目先由內向外閱讀。
16. 本章先處理指向一般變數的基礎用法。
17. 指標參數、交換函式、指標算術與動態記憶體留待後續章節。

## Section IV. 為什麼需要指標？

### 1. 被呼叫函式中的普通參數是副本

```c
#include <stdio.h>

void add_one(int number) {
    number++;
    printf("Inside: %d\n", number);
}

int main(void) {
    int number = 3;

    add_one(number);
    printf("Outside: %d\n", number);

    return 0;
}
```

輸出：

```text
Inside: 4
Outside: 3
```

在函式內修改參數，不會修改呼叫端原本的整數。

投影片將「在被呼叫函式中修改引數值」列為沒有指標時尚未處理的問題之一。指標與函式的正式寫法會在下一章介紹。

---

### 2. 陣列不能直接整體複製

```c
int source[5] = {1, 2, 3, 4, 5};
int target[5];

/* target = source;  編譯失敗 */
```

必須逐元素複製。

---

### 3. 字串所在的字元陣列不能直接整體複製

```c
char source[6] = "Hello";
char target[6];

/* target = source;  編譯失敗 */
```

---

### 4. 固定陣列不能在執行期間直接改變長度

```c
int values[5];
```

不能在稍後直接把同一個陣列物件變成：

```c
int values[10];
```

投影片以這些限制引出「指標型別」：指標能讓程式保存並操作記憶體位址，後續可以用來解決更多資料存取問題。

---

## Section V. 指標變數宣告

### 5. 普通整數變數

```c
int count;
```

可以讀成：

```text
count 是一個 int 變數
```

它的記憶體空間用來保存一個 `int` 值。

---

### 6. 整數指標變數

```c
int *countAddr;
```

可以讀成：

```text
countAddr 是一個指向 int 的指標
```

或：

```text
countAddr 是一個 int * 變數
```

它的記憶體空間用來保存某個 `int` 物件的位址。

---

### 7. 指標宣告的一般形式

```c
資料型別 *變數名稱;
```

例如：

```c
int *intPointer;
double *doublePointer;
char *charPointer;
```

---

### 8. 普通變數與指標變數都需要記憶體

假設只是示意：

```text
count 的位址      = 2293620
countAddr 的位址  = 2293624
```

若：

```c
int count = 9;
int *countAddr = &count;
```

則：

```text
count 方格中保存      9
countAddr 方格中保存  2293620
```

指標保存的是 `count` 的位址，不是 `countAddr` 自己的位址。

## Section VI. 取址運算子 `&`

### 10. 取得普通變數位址

```c
int count = 9;

&count;
```

`&count` 表示：

```text
count 的記憶體起始位址
```

---

### 11. `&count` 的型別

若：

```c
count
```

的型別是：

```text
int
```

則：

```c
&count
```

的型別是：

```text
int *
```

因此可以存入：

```c
int *countAddr;
```

### 12. 宣告時直接初始化

```c
int count = 9;
int *countAddr = &count;
```

此時可以說：

```text
countAddr 指向 count
```

---

### 13. 先宣告再指派

```c
int count = 9;
int *countAddr;

countAddr = &count;
```

結果與宣告時初始化相同。

---

### 14. 完整位址觀察程式

```c
#include <stdio.h>

int main(void) {
    int count = 9;
    int *countAddr = &count;

    printf("count = %d\n", count);
    printf("&count = %p\n", (void *)&count);
    printf("countAddr = %p\n", (void *)countAddr);
    printf("&countAddr = %p\n", (void *)&countAddr);

    return 0;
}
```

應觀察：

```text
&count 與 countAddr 顯示相同位址
&countAddr 通常是另一個位址
```

實際數字由每次執行環境決定。

## Section VII. 指標型別與賦值

### 16. 正確的普通值賦值

```c
int count = 9;
int value;

value = count;
```

型別：

```text
int = int
```

---

### 17. 正確的位址賦值

```c
int count = 9;
int *countAddr;

countAddr = &count;
```

型別：

```text
int * = int *
```

---

### 18. 錯誤：將整數值放入指標

```c
int count = 9;
int *countAddr;

/* countAddr = count; */
```

左邊需要：

```text
int *
```

右邊卻是：

```text
int
```

---

### 19. 錯誤：將位址放入普通整數

```c
int count = 9;
int value;

/* value = &count; */
```

左邊是：

```text
int
```

右邊是：

```text
int *
```

---

### 20. 指標型別應和目標物件型別對應

```c
int count = 9;
double amount = 3.5;

int *countAddr = &count;
double *amountAddr = &amount;
```

不要把 `double` 物件位址任意存入 `int *`。

不同資料型別可能具有不同大小、表示法與對齊需求。

---

### 21. 型別對照表

| 運算式 | 型別 |
| --- | --- |
| `count` | `int` |
| `&count` | `int *` |
| `countAddr` | `int *` |
| `*countAddr` | `int` |
| `&countAddr` | `int **` |

本章主要操作到 `int` 與 `int *`；`int **` 只作為觀察。

## Section VIII. 間接運算子 `*`

### 22. 從位址取得物件

```c
int count = 9;
int *countAddr = &count;

*countAddr;
```

運算式中的：

```c
*countAddr
```

表示：

```text
取得 countAddr 所保存位址所指向的 int 物件
```

---

### 23. `*countAddr` 的值

因為 `countAddr` 指向 `count`，所以：

```text
count       的值是 9
*countAddr  的值也是 9
```

### 24. 將間接存取結果存入普通變數

```c
#include <stdio.h>

int main(void) {
    int count = 9;
    int *countAddr = &count;
    int result = *countAddr;

    printf("count = %d\n", count);
    printf("*countAddr = %d\n", *countAddr);
    printf("result = %d\n", result);

    return 0;
}
```

---

### 25. 指標運算式對照

| 運算式 | 型別 | 值的意義 |
| --- | --- | --- |
| `count` | `int` | `count` 保存的整數 |
| `&count` | `int *` | `count` 的位址 |
| `countAddr` | `int *` | 指標中保存的位址 |
| `*countAddr` | `int` | 該位址所指 `int` 的值 |

## Section IX. 透過指標修改變數

```c
int count = 9;

count = 10;
```

---

### 27. 透過指標修改

```c
int count = 9;
int *countAddr = &count;

*countAddr = 10;
```

因為 `countAddr` 指向 `count`，所以最後：

```text
count == 10
```

### 28. 完整修改範例

```c
#include <stdio.h>

int main(void) {
    int count = 9;
    int *countAddr = &count;

    printf("Before: %d\n", count);

    *countAddr = 10;

    printf("After count: %d\n", count);
    printf("After *countAddr: %d\n", *countAddr);

    return 0;
}
```

---

### 29. 指標的特殊能力

普通複製：

```c
int count = 9;
int result = count;
```

此後：

```c
result = 10;
```

不會改變 `count`。

但指標保存的是 `count` 的位址：

```c
int *countAddr = &count;
```

因此：

```c
*countAddr = 10;
```

會找到並修改原本的 `count`。

---

### 30. 複製值與保存位址的差異

```c
#include <stdio.h>

int main(void) {
    int count = 9;
    int copiedValue = count;
    int *countAddr = &count;

    copiedValue = 20;
    printf("copiedValue = %d\n", copiedValue);
    printf("After copiedValue change: %d\n", count);

    *countAddr = 30;
    printf("After pointer change: %d\n", count);

    return 0;
}
```

輸出：

```text
After copiedValue change: 9
After pointer change: 30
```

```text
countA
```

---

### 33. 再改指向 `countB`

```c
countAddr = &countB;
```

現在：

```c
*countAddr = 0;
```

修改的是：

```text
countB
```

### 34. 完整重新指向範例

```c
#include <stdio.h>

int main(void) {
    int countA = 9;
    int countB = 10;
    int *countAddr = &countA;

    *countAddr = 0;

    countAddr = &countB;
    *countAddr = 20;

    printf("countA = %d\n", countA);
    printf("countB = %d\n", countB);

    return 0;
}
```

輸出：

```text
countA = 0
countB = 20
```

---

### 35. 改指向時沒有複製兩個整數

```c
countAddr = &countB;
```

只把新的位址放進 `countAddr`。

`countA` 與 `countB` 原本的資料仍在各自位置中。

---

### 36. 多個指標可指向同一物件

```c
#include <stdio.h>

int main(void) {
    int count = 9;
    int *first = &count;
    int *second = &count;

    *first = 15;

    printf("count = %d\n", count);
    printf("*second = %d\n", *second);

    return 0;
}
```

兩個指標保存相同位址，所以都能找到同一個 `count`。

## Section XI. `*` 的兩種角色

### 37. 宣告中的 `*`

## Section XII. `&` 與 `*` 的關係

### 41. 先取址，再間接取得物件

```c
int count = 9;
int result = *&count;
```

由內向外：

1. `&count` 取得 `count` 的位址。
2. `*` 再取得該位址所指的物件。

所以：

```c
*&count
```

表示原本的：

```c
count
```

---

### 42. `*&count` 化簡

```c
#include <stdio.h>

int main(void) {
    int count = 9;
    int result = *&count;

    printf("%d\n", result);

    return 0;
}
```

結果：

```text
9
```

---

### 43. 先間接取得物件，再取回位址

```c
int count = 9;
int *countAddr = &count;

&*countAddr;
```

由內向外：

1. `*countAddr` 表示 `count` 物件。
2. `&` 再取得該物件位址。

所以結果與：

```c
countAddr
```

保存的位址相同。

---

### 44. `&*countAddr` 化簡

```c
#include <stdio.h>

int main(void) {
    int count = 9;
    int *countAddr = &count;

    printf(
        "countAddr = %p\n",
        (void *)countAddr
    );
    printf(
        "&*countAddr = %p\n",
        (void *)&*countAddr
    );

    return 0;
}
```

兩行應顯示相同位址。

### 45. 相鄰的 `*&`

在運算式有效時：

```text
*&物件
```

可以理解成：

```text
物件
```

例如：

```c
*&count = 10;
```

等同：

```c
count = 10;
```

---

### 46. 相鄰的 `&*`

在指標運算式有效時：

```text
&*指標
```

可以理解成原本的指標值。

例如：

```c
int *sameAddr = &*countAddr;
```

得到與 `countAddr` 相同的位址。

---

### 47. 較長運算式由內向外化簡

```c
*&*countAddr
```

可以先看：

```c
*&
```

它們作用在：

```c
*countAddr
```

這個物件上，因此整體可理解成：

```c
*countAddr
```

---

### 48. 化簡範例

```c
#include <stdio.h>

int main(void) {
    int count = 9;
    int *countAddr = &count;

    *&*countAddr = 20;

    printf("%d\n", count);

    return 0;
}
```

結果：

```text
20
```

化簡後可看成：

```c
*countAddr = 20;
```

---

### 49. 化簡不代表無效指標可以安全使用

本章所有間接存取都建立在：

```text
指標確實指向仍然存在、型別正確的物件
```

這個前提上。

不能因為看到 `&*`，就忽略指標本身是否有效。

6. 指標變數本身也有自己的位址。

11. `&count` 與 `countAddr` 可表示相同目標位址。
12. `&countAddr` 是指標變數自己的位址。
13. `int` 與 `int *` 是不同型別。
14. `int *` 與 `double *` 也是不同型別。
15. 不應把普通整數直接放入指標。
16. 不應把物件位址直接放入普通整數。
17. 間接運算子 `*` 取得指標所指向的物件。
18. 若 `countAddr` 是 `int *`，`*countAddr` 是 `int`。
19. `count` 與 `*countAddr` 可指同一個實際物件值。
20. 將 `*countAddr` 複製到普通變數只會複製值。
21. 對 `*countAddr` 賦值會修改原物件。
22. 指標可以改指向另一個同型態變數。
23. 修改指標本身與修改被指向物件是不同操作。
24. 多個指標可以保存同一個物件位址。
25. 宣告中的 `*` 表示指標型別。

## Section XX. 常見錯誤提醒

### 錯誤 2：忘記使用 `&`

```c
int number = 10;

```

應讓指標取得位址：

```c
pointer = &number;
```

### 錯誤 3：把位址存入普通整數

```c
int value;

/* value = &number; */
```

---

### 錯誤 4：指標型別與物件型別不對應

讓 `int *` 指向 `double` 物件不是本章允許的正常用法。

---

### 錯誤 5：混淆 `pointer` 與 `*pointer`

```text
pointer   → 位址
*pointer  → 該位址所指物件
```

---

### 錯誤 6：混淆 `pointer` 與 `&pointer`

```text
pointer   → 目標位址
&pointer  → 指標變數本身的位址
```

---

### 錯誤 7：修改了普通副本，卻期待原物件改變

```c

```

不會修改 `number`。

---

### 錯誤 8：想改指向，卻寫成修改物件


這是把 `other` 的值放入目前所指物件。

改指向應寫：

```c
pointer = &other;
```

### 錯誤 9：想修改物件，卻只改了指標

```c
pointer = &other;
```

只改箭頭方向，不會自動改變兩個整數的值。

---

### 錯誤 10：多變數宣告判讀錯誤

```c

```

`b` 不是指標。

---

### 錯誤 11：對未初始化指標使用 `*`

```c

/* *pointer = 10; */
```

---

### 錯誤 12：以為 `NULL` 可以被間接存取

```c
int *pointer = NULL;

/* printf("%d", *pointer); */
```

---

### 錯誤 13：使用 `%d` 輸出位址

位址應使用 `%p`。

---

### 錯誤 14：把示意位址當成固定答案

實際位址可能因執行、系統與編譯器而變動。

---

### 錯誤 15：看到 `&*` 就忽略指標有效性

化簡規則仍建立在運算式符合語言要求的前提上。

---

### 錯誤 16：由外向內錯讀複合運算式

```c
*&*pointer
```

應先處理最內層的 `*pointer`。

## Section XXI. Mermaid 流程圖

### 1. 普通變數與指標

```mermaid
flowchart LR
    A[count 變數] -->|保存| B[int 值 9]
    C[countAddr 指標] -->|保存| D[count 的位址]
    D -->|指向| A
```

---

### 2. 取址運算

```mermaid
flowchart LR
    A[count 物件] --> B[使用取址運算子]
    B --> C[得到 count 的位址]
    C --> D[型別為 int 指標]
```

---

### 3. 間接運算

```mermaid
flowchart LR
    A[countAddr 保存位址] --> B[使用間接運算子]
    B --> C[找到該位址所指物件]
    C --> D[取得或修改 count]
```

---

### 4. 指標重新指向

```mermaid
flowchart TD
    A[p 先保存 a 的位址] --> B[p 指向 a]
    B --> C[p 改存 b 的位址]
    C --> D[p 改指向 b]
    D --> E[星號 p 修改 b]
```

---

### 5. 值複製與位址存取

```mermaid
flowchart TD
    A[number 等於 9] --> B[copied 等於 number]
    A --> C[pointer 等於 number 的位址]
    B --> D[修改 copied 不影響 number]
    C --> E[修改星號 pointer 會影響 number]
```

---

### 6. `*&`

```mermaid
flowchart LR
    A[count] --> B[取址得到 count 的位址]
    B --> C[間接取得該位址所指物件]
    C --> D[回到 count]
```

---

### 7. `&*`

```mermaid
flowchart LR
    A[pointer 位址值] --> B[間接取得所指物件]
    B --> C[再取得該物件位址]
    C --> D[回到 pointer 的位址值]
```

---

### 8. 指標安全檢查

```mermaid
flowchart TD
    A[準備使用星號 pointer] --> B{pointer 是否指向有效物件}
    B -- 是 --> C[安全讀取或修改]
    B -- 否 --> D[不可間接存取]
```
