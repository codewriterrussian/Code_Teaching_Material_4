# Lesson 15：Array Queries and Statistics 陣列搜尋與統計

> 這堂課的重點：在陣列中依序號直接查詢資料、逐一篩選符合範圍的元素、找出上限內最大值與最接近值，再使用次數陣列完成分組長條圖、眾數、最大值與平均值等統計工作。

## Section II. 今天的學習方式

1. 先畫出陣列的索引與資料值。
2. 若外部編號從 `1` 開始，先寫出它與索引的轉換。
3. 查詢前先判斷是否輸入結束值。
4. 將查詢問題拆成：
   - 候選元素
   - 合格條件
   - 目前最佳答案
5. 要找全部結果時，不要在第一個結果後停止。
6. 要找最佳結果時，每看到一個更好的候選就更新答案。
7. 不要任意使用 `0` 當初始答案；先確認 `0` 是否可能是合法資料。
8. 最近值問題先計算距離，再比較距離。
9. 平手規則要寫進條件，不能依輸入順序碰運氣。
10. 小範圍整數統計優先考慮次數陣列。
11. 建立次數陣列前，先確定資料值如何映射到索引。
12. 畫長條圖時：
    - 外層處理每一組
    - 內層輸出該組對應數量的星號
13. 計算平均前先完成總和。
14. 明確分辨整數平均與浮點平均。
15. 先依來源教材完成逐步版本，再整理成較安全或較通用的版本。
16. 本章不進行排序；所有查詢都直接走訪原始輸入順序。
17. 陣列傳入函式只作為來源教材末段的預覽，正式原理留到後面的「陣列與函式」。

## Section IV. 寫題目前的提醒

### 1. 順序號碼不是陣列索引

使用者輸入：

```text
1
```

代表第一筆資料。

C 陣列第一個元素是：

```c
numbers[0]
```

因此：

```text
索引 = 順序號碼 - 1
```

---

### 2. `0` 是結束值，不是合法順序號碼

來源第一個查詢題使用：

```text
Q: 0
```

結束。

如果直接執行：

```c
numbers[q - 1]
```

當 `q == 0` 時會變成：

```c
numbers[-1]
```

這是陣列越界。

必須先檢查：

```c
if (q == 0) {
    break;
}
```

---

### 3. 第 `1–5` 筆資料只能查詢 `1–5`

來源程式假設使用者輸入合法順序號碼。

完整教學版本可以額外檢查：

```c
if (q < 1 || q > 5)
```

避免存取陣列外部。

這是教材安全性補強，不是來源投影片的主要步驟。

---

### 4. 範圍查詢包含上下限

來源條件：

```c
numbers[i] >= lower && numbers[i] <= upper
```

代表：

```text
lower <= numbers[i] <= upper
```

下限與上限本身都會被輸出。

---

### 5. `0 0` 要在掃描陣列前判斷

```c
if (lower == 0 && upper == 0) {
    break;
}
```

若只檢查其中一個為 `0`，就會改變來源題目的結束規則。

---

### 6. 範圍查詢要保留原始輸入順序

來源範例輸入：

```text
13 23 78 77 37 30 40 50 83 99
```

查詢：

```text
1 100
```

會依原本陣列順序輸出，不會自動排序。

---

### 7. 上限內最大值不是一般最大值

候選元素必須先符合：

```c
numbers[i] <= query
```

再比較它是否比目前答案大。

---

### 8. 来源投影片有一處題目敘述誤植

`16-03` 的標題與程式都在處理：

```text
查詢上限內最大的數字
```

但部分投影片敘述誤寫成「最接近的一個」。

本章依標題、執行範例與完整程式，將它解讀為：

> 找出不大於查詢值的最大陣列元素。

---

### 9. `max = -1` 依賴資料範圍假設

來源逐步程式使用：

```c
int max = -1;
```

表示尚未找到候選值。

這在範例中的正整數資料可行。

若陣列可能包含比 `-1` 更小的整數，應改用：

```c
int max_index = -1;
```

以索引表示是否找到，避免把某個數值硬當成哨兵。

---

### 10. 每次重複查詢都要重新初始化答案

錯誤：

```c
int max = -1;

while (1) {
    ...
}
```

若 `max` 只初始化一次，前一次查詢結果可能影響下一次。

來源後續版本將它放入查詢迴圈：

```c
while (1) {
    int max = -1;
    ...
}
```

---

### 11. 最近值需要絕對距離

不能只比較：

```c
query - numbers[i]
```

因為位於查詢值右邊的數字會得到負數。

應使用：

```c
abs(query - numbers[i])
```

---

### 12. 使用 `abs()` 要包含 `<stdlib.h>`

```c
#include <stdlib.h>
```

`abs()` 接收與回傳 `int`。

---

### 13. 最近值應由實際陣列元素初始化

來源正確版本：

```c
int nearest_number = numbers[0];
int nearest_distance = abs(query - numbers[0]);
```

不要把 `nearest_number` 留成未初始化。

---

### 14. 最近值平手時選較小數字

更新條件：

```c
distance < nearest_distance ||
(distance == nearest_distance &&
 numbers[i] < nearest_number)
```

第一部分找到更近的數字。

第二部分處理同距離時選較小值。

---

### 15. 次數陣列要先清零

```c
int bins[10] = {0};
```

每個元素代表某個區間目前有幾筆資料。

---

### 16. `1–100` 的分組公式是 `(n - 1) / 10`

| 數值範圍 | `(n - 1) / 10` | 索引 |
| --- | ---: | ---: |
| 1–10 | 0–9 除以 10 | 0 |
| 11–20 | 10–19 除以 10 | 1 |
| 21–30 | 20–29 除以 10 | 2 |
| ... | ... | ... |
| 91–100 | 90–99 除以 10 | 9 |

若直接寫：

```c
n / 10
```

則 `10` 會被分到索引 `1`，不符合來源區間。

---

### 17. 分組資料必須符合 `1–100`

來源題目明確要求輸入：

```text
1 到 100
```

如果輸入 `0`：

```c
(0 - 1) / 10
```

不再符合預期映射。

如果輸入大於 `100`，也可能造成索引越界。

---

### 18. 長條圖需要巢狀迴圈

外層：

```c
for (i = 1; i <= 10; i++)
```

處理十個區間。

內層：

```c
for (j = 1; j <= bins[i - 1]; j++)
```

輸出該區間對應數量的星號。

---

### 19. 眾數的值與次數不能混淆

```c
answer
```

保存眾數的數值，例如 `3`。

```c
frequency[answer]
```

才是它出現的次數。

---

### 20. 来源眾數題的平手規則是選較大的數字

來源掃描：

```c
for (number = 1; number < 10; number++) {
    if (frequency[number] >= frequency[answer]) {
        answer = number;
    }
}
```

因為由小到大掃描，而且平手也更新，所以最後保留較大的數字。

---

### 21. 平手規則中的 `>=` 不能任意改成 `>`

使用：

```c
>
```

會保留較早看到的較小數字。

使用：

```c
>=
```

才會在相同次數時更新成較大的數字。

---

### 22. 来源數字統計的平均值是整數平均

```c
int average;
average = sum / 10;
```

如果真實平均為 `53.7`，整數除法結果是：

```text
53
```

來源輸出格式也是：

```c
printf("Avg: %d\n", average);
```

---

### 23. 最大值不能在未初始化時直接比較

錯誤：

```c
int maximum;

if (number > maximum) {
    maximum = number;
}
```

來源逐步修正包括：

```c
int maximum = 0;
```

以及更通用的：

```c
if (i == 1 || number > maximum) {
    maximum = number;
}
```

或在陣列版中：

```c
int maximum = numbers[0];
```

---

### 24. 第一筆初始化可以支援負數

```c
maximum = first_input;
sum = first_input;
```

再從第二筆資料開始處理。

這比假設：

```c
maximum = 0;
```

更通用。

---

### 25. 来源最後使用函式整理陣列統計

来源將：

```c
int max10(int numbers[10]);
int avg10(int numbers[10]);
```

作為函式介面。

本章只觀察它能讓 `main()` 更簡潔。

陣列傳入函式的實際原理會在後面的「陣列與函式」正式說明。

### 11. 完整重複查詢

```c
#include <stdio.h>

int main(void) {
    int i;
    int numbers[10];

    for (i = 1; i <= 10; i++) {
        scanf("%d", &numbers[i - 1]);
    }

    while (1) {
        int lower;
        int upper;

        printf("L R: ");
        scanf("%d%d", &lower, &upper);

        if (lower == 0 && upper == 0) {
            break;
        }

        printf("Ans: ");

        for (i = 0; i < 10; i++) {
            if (numbers[i] >= lower &&
                numbers[i] <= upper) {
                printf("%d ", numbers[i]);
            }
        }

        printf("\n");
    }

    return 0;
}
```

## Section V-C. 查詢上限內最大的數字

### 13. 題目真正要求

給定查詢值 `Q`，從輸入的十個整數中找出：

```text
不大於 Q 的最大值
```

範例資料：

```text
13 23 78 77 37 30 40 50 83 99
```

查詢：

```text
Q: 25
```

輸出：

```text
23
```

查詢：

```text
Q: 33
```

輸出：

```text
30
```

因為資料中沒有 `33`，而不大於 `33` 的最大值是 `30`。

---

### 14. 使用數值哨兵的來源版本

```c
int maximum = -1;

for (i = 0; i < 10; i++) {
    if (numbers[i] <= query &&
        numbers[i] > maximum) {
        maximum = numbers[i];
    }
}

if (maximum != -1) {
    printf("%d\n", maximum);
}
```

```c

    }
}

if (maximum_index != -1) {
    printf("%d\n", numbers[maximum_index]);
}
```

这里：

```text

```

表示「目前沒有合法索引」，不假設陣列資料一定是正數。

### 17. 完整重複查詢

```c
#include <stdio.h>

int main(void) {
    int i;
    int numbers[10];

    for (i = 1; i <= 10; i++) {
        scanf("%d", &numbers[i - 1]);
    }

    while (1) {
        int query;
        int maximum_index = -1;

        printf("Q: ");
        scanf("%d", &query);

        if (query == 0) {
            break;
        }

        for (i = 0; i < 10; i++) {
            if (numbers[i] <= query &&
                (maximum_index == -1 ||
                 numbers[i] > numbers[maximum_index])) {
                maximum_index = i;
            }
        }

        if (maximum_index != -1) {
            printf("%d\n", numbers[maximum_index]);
        } else {
            printf("Not found\n");
        }
    }

    return 0;
}
```

## Section V-I. 容易搞混的重點

### 48. 第一個來源練習不是搜尋資料值

使用者輸入：

```text
Q: 3
```

代表查詢第三筆輸入，不是搜尋陣列中是否存在數字 `3`。

---

### 49. 直接查詢與完整走訪不同

<p align="center">
  <img
    src="images/lesson_15/C_Lesson_15_img02_direct_vs_scan.png"
    alt="直接查詢與完整走訪"
    width="700">
</p>


顺序号查询：

```c
numbers[query - 1]
```

只存取一個位置。

範圍查詢：

```c
for (...)
```

必須檢查全部元素。

---

### 50. 上限內最大值可能不是最接近值

資料：

```text
23 30
```

查詢：

```text
25
```

上限內最大值是：

```text
23
```

最近值也是 `23`。

但資料：

```text
23 26
```

查詢 `25`：

- 上限內最大值：`23`
- 最近值：`26`

兩個問題不能使用相同條件。

---

### 51. 最接近值不要求小於查詢值

最近候選可以位於查詢值左邊或右邊。

只比較：

```text
絕對距離
```

---

### 52. 區間索引不是區間標籤

```c
bins[0]
```

代表 `1–10`。

輸出標籤卻是：

```text
10
```

索引、區間與顯示標籤是三個不同概念。

---

### 53. 眾數不是最大數字

眾數是出現次數最多的數字。

只有在次數平手時，來源才選較大的數字。

---

### 54. 平均值來源使用整數，不保留小數

這是來源題目與程式的行為。

若要浮點平均，需要改變型態與輸出格式，但那是另一個版本。

---

### 55. 先存陣列與立即統計各有用途

立即統計：

- 不需要保留全部資料
- 單次統計較直接

先存陣列：

- 可以重複進行不同查詢
- 可以分開計算最大值、平均值與其他統計
- 後續可以排序或傳給函式

## Section XI. 重點複習

1. 使用者的順序號碼通常從 `1` 開始。
2. C 陣列索引從 `0` 開始。
3. 第 `k` 筆資料通常對應索引 `k - 1`。
4. 查詢結束值要在陣列存取之前判斷。
5. 直接查詢已知位置不需要走訪整個陣列。
6. 範圍查詢需要逐一檢查所有元素。
7. 閉區間同時包含下限與上限。
8. 來源範圍查詢使用 `0 0` 結束。
9. 上限內最大值要求候選值不大於查詢值。
10. 最佳值問題需要保存目前答案。
11. 使用索引 `-1` 可以安全表示尚未找到候選。
12. 每次重複查詢都要重新初始化候選答案。
13. 最近值使用絕對距離。
14. `abs()` 需要 `<stdlib.h>`。
15. 最近值平手時，來源要求選較小數字。
16. `1–100` 分十組可使用 `(number - 1) / 10`。
17. 計數陣列必須先初始化為 `0`。
18. 文字長條圖使用次數決定星號數量。
19. `0–9` 可以直接用資料值作為索引。
20. 眾數是出現次數最多的數字。
21. 来源眾數平手時選較大數字。
22. 由小到大掃描配合 `>=` 可以保留較大平手值。
23. 最大值應從合法陣列元素初始化。
24. 總和使用累加器。
25. 来源平均值使用整數除法。
26. 先存入陣列可以讓相同資料接受多種查詢與統計。
27. 查詢、篩選、最佳值與頻率統計是四種不同的陣列處理模式。
28. 来源最後使用函式整理最大值與平均值。
29. 陣列傳入函式的原理會在後續章節正式學習。
30. 下一章會學習如何重新排列陣列元素。

## Section XII. 常見錯誤提醒

### 錯誤 1：直接使用順序號碼作索引

錯誤：

```c
numbers[query]
```

查詢第一筆時會取得第二個元素。

應使用：

```c
numbers[query - 1]
```

---

### 錯誤 2：先存取再檢查 `0`

錯誤：

```c
printf("%d\n", numbers[query - 1]);

if (query == 0) {
    break;
}
```

---

### 錯誤 3：範圍條件使用 `||`

錯誤：

```c
value >= lower || value <= upper
```

大多數數值都會符合至少一邊。

閉區間應使用 `&&`。

---

### 錯誤 4：只輸出第一個範圍內數字

來源要求顯示所有符合元素，不應在第一個答案後 `break`。

---

### 錯誤 5：上限內最大值只比較大小

錯誤：

```c
if (numbers[i] > maximum)
```

還要先確認：

```c
numbers[i] <= query
```

---

### 錯誤 6：重複查詢時沒有重設最大值

前一次查詢的答案可能使下一次較小上限永遠無法更新。

---

### 錯誤 7：最近值不使用絕對值

```c
query - numbers[i]
```

不能正確表示雙方向距離。

---

### 錯誤 8：最近值只用 `<`

只使用：

```c
distance < nearest_distance
```

不能實作平手時選較小數字。

---

### 錯誤 9：`abs()` 沒有包含標頭檔

應加入：

```c
#include <stdlib.h>
```

---

### 錯誤 10：十位分組直接使用 `number / 10`

`10` 會被分到第二組。

來源需要：

```c
(number - 1) / 10
```

---

### 錯誤 11：計數陣列未初始化

未初始化次數會造成錯誤長條與眾數。

---

### 錯誤 12：把 `100` 映射到索引 `10`

正確公式會得到：

```text
9
```

合法索引為 `0–9`。

---

### 錯誤 13：眾數比較的是數字大小

應比較：

```c
frequency[number]
```

不是直接比較 `number`。

---

### 錯誤 14：眾數平手時使用 `>`

來源要求較大數字，因此需使用 `>=` 配合升序掃描。

---

### 錯誤 15：最大值初始為 `0`，但資料可能全為負數

應使用第一筆資料或找到狀態初始化。

---

### 錯誤 16：以為來源平均會保留小數

来源宣告 `int average`，並以 `sum / 10` 計算整數平均。

---

### 錯誤 17：函式原型與定義不一致

```c
int max10(int numbers[10]);
```

宣告、定義與呼叫中的名稱可以不同，但回傳型態與參數型態必須相容。
