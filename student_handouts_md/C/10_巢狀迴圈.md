## Section II. 今天的學習方式

1. 先決定輸出有幾列。
2. 再決定每一列有幾個位置。
3. 讓外層迴圈控制列或第一個變數。
4. 讓內層迴圈控制欄或第二個變數。
5. 每完成一列後，再輸出一次換行。
6. 先用固定的 `N = 3` 或 `N = 5` 觀察規律。
7. 將每個位置標上 `(列, 欄)` 座標。
8. 先說出「什麼位置要印星號」，再翻譯成條件。
9. 實心圖形通常判斷區域；空心圖形通常判斷邊界。
10. 複雜圖形先畫座標表，不要直接猜條件。
11. 搜尋兩個未知數時，先列出所有合法範圍。
12. 找到答案後，再思考能否去除重複組合。
13. 再利用已知方程式減少一層迴圈。
14. 每個範例都測試最小合理輸入、一般輸入與邊界輸入。
15. 本章先專注雙層迴圈；更多數學解題會放在下一章。

## Section III. 今天會學到的內容

| 主題 | 你需要知道的事 |
| --- | --- |
| 巢狀迴圈 | 一個迴圈本體中包含另一個迴圈 |

| 內層迴圈 | 控制欄、組內項目或第二個未知數 |

| 枚舉 | 把有限範圍內的所有可能逐一測試 |

| 去除重複 | 例如限制 `i <= j` |
| 降維 | 用一個方程式算出另一個未知數 |

## Section IV. 寫題目前的提醒

### 1. 巢狀迴圈不是兩個連續迴圈

<!-- lesson-image: C_Lesson_10_img01_sequential_vs_nested_loops.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img01_sequential_vs_nested_loops.png"
       alt="C 語言教材圖解：sequential vs nested loops"
       width="700">
</p>

兩個連續迴圈：

```c
for (i = 1; i <= 3; i++) {
    printf("A\n");
}

for (j = 1; j <= 3; j++) {
    printf("B\n");
}
```

第一個完整結束後，第二個才開始。

巢狀迴圈：

```c
for (i = 1; i <= 3; i++) {
    for (j = 1; j <= 3; j++) {
        printf("(%d, %d)\n", i, j);
    }
}
```

每一個 `i` 都會搭配 `j = 1, 2, 3`。

---

### 2. 內層變數每次都會重新初始化

<!-- lesson-image: C_Lesson_10_img04_inner_variable_reset.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img04_inner_variable_reset.png"
       alt="C 語言教材圖解：inner variable reset"
       width="700">
</p>

```c
for (i = 1; i <= 3; i++) {
    for (j = 1; j <= 3; j++) {
        printf("(%d, %d)\n", i, j);
    }
}
```

當 `i` 從 `1` 變成 `2` 時，內層會再次執行：

```c
j = 1
```

不是從上一次結束後的 `j = 4` 繼續。

---

### 3. 換行通常放在內層迴圈之後

正確的正方形：

```c
for (i = 1; i <= n; i++) {
    for (j = 1; j <= n; j++) {
        printf("*");
    }

    printf("\n");
}
```

如果把換行放進內層：

```c
printf("*\n");
```

每一個星號都會單獨一行。

---

### 4. 外層與內層不要誤用同一個控制變數

錯誤：

```c
for (i = 1; i <= n; i++) {
    for (i = 1; i <= n; i++) {
        printf("*");
    }
}
```

內層會修改外層的 `i`，流程失去控制。

應使用不同變數：

```c
i
j
```

---

### 5. 內層條件可以依賴外層變數

三角形：

```c
for (i = 1; i <= n; i++) {
    for (j = 1; j <= i; j++) {
        printf("*");
    }

    printf("\n");
}
```

第 `i` 列執行 `i` 次，所以星號數量逐列增加。

---

### 6. 空白也是圖形的一部分

座標法通常需要：

```c
printf(" ");
```

不能只在星號位置輸出內容，否則靠右對齊與空心區域可能塌縮。

---

### 7. 實心區域與空心邊界的條件不同

實心左下三角形：

```c
i >= j
```

空心左下三角形：

```c
j == 1 || i == n || i == j
```

空心圖形只保留三條邊。

---

### 8. 使用 `||` 表示「位於任一條邊」

空心正方形：

```c
i == 1 || i == n || j == 1 || j == n
```

只要其中一個條件成立，就在邊界上。

---

### 9. `&&` 與 `||` 不可混淆

空心正方形邊界應使用 `||`。

若寫成：

```c
i == 1 && i == n && j == 1 && j == n
```

除非 `n == 1`，否則不可能同時位於所有邊。

---

### 10. 星號與空白最好維持相同顯示寬度

使用：

```c
printf("*");
printf(" ");
```

兩者各占一個字元位置。

若使用：

```c
printf("* ");
```

星號占兩個位置，相關座標與寬度也要一起調整。

---

### 11. 乘法表中的兩個變數角色不同

```c
printf("%d x %d = %d\n", i, j, i * j);
```

通常：

- `i`：目前第幾組乘法
- `j`：這一組中的乘數

---

### 12. 雙層迴圈的總次數不是相加

<!-- lesson-image: C_Lesson_10_img06_nested_iteration_count.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img06_nested_iteration_count.png"
       alt="C 語言教材圖解：nested iteration count"
       width="760">
</p>

```c
for (i = 1; i <= 9; i++) {
    for (j = 1; j <= 9; j++) {
        ...
    }
}
```

內層本體執行：

```text
9 × 9 = 81 次
```

不是 `9 + 9 = 18` 次。

若外層從 `2` 到 `9`，則是：

```text
8 × 9 = 72 次
```

---

### 13. 枚舉解時要避免超出題目範圍

題目說「正整數」，因此起點應為：

```c
1
```

不是 `0`，也不是負數。

---

### 14. 對稱解可能會輸出兩次

若檢查所有 `(i, j)`：

```text
(13, 17)
(17, 13)
```

兩者都符合和與積的條件。

如果題目把兩個數視為無順序的一組，可以限制：

```c
i <= j
```

或縮小 `i` 的範圍。

---

### 15. 先使用方程式再搜尋，通常比較有效率

已知：

```text
i + j = 30
```

可以得到：

```c
j = 30 - i;
```

此時不需要再用第二個迴圈猜 `j`。

---

### 16. `break` 只會離開目前那一層迴圈

<!-- lesson-image: C_Lesson_10_img29_break_only_inner_loop.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img29_break_only_inner_loop.png"
       alt="C 語言教材圖解：break only inner loop"
       width="700">
</p>

若 `break` 寫在內層，只離開內層，不會自動結束外層。

本章的完整搜尋範例不依賴雙層 `break`，避免造成誤解。

---

### 17. `N = 1` 是重要邊界測試

對空心正方形或空心三角形而言，`N = 1` 時同一位置同時屬於多條邊。

使用座標條件通常仍能自然輸出一個星號。

## Section V. 核心概念說明

### 1. 什麼是巢狀迴圈？

<!-- lesson-image: C_Lesson_10_img02_outer_vs_inner_roles.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img02_outer_vs_inner_roles.png"
       alt="C 語言教材圖解：outer vs inner roles"
       width="700">
</p>

巢狀迴圈是：

> 在一個迴圈的本體中，再放入另一個迴圈。

```c
for (i = 1; i <= outer_limit; i++) {
    for (j = 1; j <= inner_limit; j++) {
        /* 重複工作 */
    }
}
```

外層執行一輪時，內層會完整跑完。

---

### 2. 巢狀迴圈的執行順序

<!-- lesson-image: C_Lesson_10_img03_nested_loop_execution_flow.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img03_nested_loop_execution_flow.png"
       alt="C 語言教材圖解：nested loop execution flow"
       width="700">
</p>

```c
for (i = 1; i <= 2; i++) {
    for (j = 1; j <= 3; j++) {
        printf("(%d,%d)\n", i, j);
    }
}
```

輸出：

```text
(1,1)
(1,2)
(1,3)
(2,1)
(2,2)
(2,3)
```

流程如下：

1. `i = 1`
2. `j = 1, 2, 3`
3. 內層結束
4. `i = 2`
5. `j` 重新從 `1` 開始
6. `j = 1, 2, 3`
7. 全部結束

---

### 3. 使用追蹤表理解組合

<!-- lesson-image: C_Lesson_10_img05_coordinate_combination_order.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img05_coordinate_combination_order.png"
       alt="C 語言教材圖解：coordinate combination order"
       width="760">
</p>

| 外層 `i` | 內層依序出現的 `j` | 產生的組合 |
| ---: | --- | --- |
| 1 | 1, 2, 3 | `(1,1) (1,2) (1,3)` |
| 2 | 1, 2, 3 | `(2,1) (2,2) (2,3)` |

內層本體總共執行：

```text
2 × 3 = 6 次
```

## Section V-A. 九九乘法表

### 4. 先印出 2 的乘法表

```c
#include <stdio.h>

int main(void) {
    int j;

    for (j = 1; j <= 9; j++) {
        printf("2 x %d = %d\n", j, 2 * j);
    }

    return 0;
}
```

這一個迴圈只能完成：

```text
2 x 1
...
2 x 9
```

---

### 5. 重複撰寫多個 `for` 的問題

若要接著印 `3`、`4`、`5` 的乘法表，可以複製：

```c
for (j = 1; j <= 9; j++) {
    printf("3 x %d = %d\n", j, 3 * j);
}
```

但這會產生大量重複程式碼。

真正改變的只有被乘數：

```text
2, 3, 4, ..., 9
```

因此可以再使用一個迴圈控制它。

---

### 6. 使用雙層迴圈印出九九乘法表

<p align="center">

</p>

```c
#include <stdio.h>
```

```c
i = 2, 3, ..., 9
```

### 8. 延伸：使用單一迴圈展開 72 筆

<!-- lesson-image: C_Lesson_10_img09_one_dimensional_to_2d_index.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img09_one_dimensional_to_2d_index.png"
       alt="C 語言教材圖解：one dimensional to 2d index"
       width="700">
</p>

來源也展示把 72 個乘法組合排成一維序列。

令：

```c
c = 1, 2, ..., 72
```

可以將 `c` 轉回：

```c
i = (c - 1) / 9 + 2;
j = (c - 1) % 9 + 1;
```

完整範例：

```c
#include <stdio.h>

int main(void) {
    int c;

    for (c = 1; c <= 72; c++) {
        int i = (c - 1) / 9 + 2;
        int j = (c - 1) % 9 + 1;

        printf("%d x %d = %d\n", i, j, i * j);
    }

    return 0;
}
```

這不是取代巢狀迴圈的必要寫法，而是展示：

> 一維索引也能映射到二維座標。

```c
for (j = 1; j <= n; j++) {
```

### 10. 重複列形成 `N × N` 正方形

<!-- lesson-image: C_Lesson_10_img10_rows_and_columns.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img10_rows_and_columns.png"

       width="700">
</p>

每一列要印 `N` 個星號，一共要印 `N` 列。

因此：

- 外層控制第幾列
- 內層控制該列第幾個星號

```c
#include <stdio.h>

int main(void) {

    int i;
    int j;

    printf("N = ");
    scanf("%d", &n);

    for (i = 1; i <= n; i++) {
        for (j = 1; j <= n; j++) {
            printf("*");
        }

        printf("\n");
    }

    return 0;
}
```

輸入 `3`：

```text
***
***
***
```

### 12. 從正方形延伸成長方形

<!-- lesson-image: C_Lesson_10_img12_square_vs_rectangle.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img12_square_vs_rectangle.png"

```c
}
```

## Section V-C. 空心正方形

### 13. 方法一：分成上、中、下三部分

空心 `N × N` 正方形可以拆成：

1. 第一列：`N` 個星號
2. 中間 `N - 2` 列：星號、空白、星號
3. 最後一列：`N` 個星號

例如 `N = 5`：

```text
*****
*   *
*   *
*   *
*****
```

---

### 14. 分段繪製的程式

```c
#include <stdio.h>

int main(void) {
    int n;
    int i;
    int j;

    printf("N = ");
    scanf("%d", &n);

    for (j = 1; j <= n; j++) {
        printf("*");
    }
    printf("\n");

    for (i = 1; i <= n - 2; i++) {
        printf("*");

        for (j = 1; j <= n - 2; j++) {
            printf(" ");
        }

        printf("*\n");
    }

    for (j = 1; j <= n; j++) {
        printf("*");
    }
    printf("\n");

    return 0;
}
```

這個寫法清楚呈現圖形的三個部分。

已知兩個正整數：

### 32. 最直接的方法：列出所有可能組合

<!-- lesson-image: C_Lesson_10_img24_double_loop_search_space.png -->
<p align="center">

因為兩個數都是正整數，而且和為 `30`，可以先讓：

```c

    int j;
```

### 33. 為什麼會有兩行答案？

<!-- lesson-image: C_Lesson_10_img25_symmetric_duplicate_solutions.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img25_symmetric_duplicate_solutions.png"
       alt="C 語言教材圖解：symmetric duplicate solutions"
       width="700">
</p>

因為雙層迴圈把順序不同的組合都視為不同座標：

```text
(i, j) = (13, 17)
(i, j) = (17, 13)
```

但題目問的是「兩個數」，通常只需要其中一組。

### 34. 方法一：限制 `i` 不超過總和的一半

若只保留較小的數作為 `i`：

```c
for (i = 1; i <= 30 / 2; i++) {
    for (j = 1; j <= 30; j++) {
        if (i + j == 30 && i * j == 221) {
            printf("%d, %d\n", i, j);
        }
    }
}
```

只會輸出：

```text
13, 17
```

---

### 35. 方法二：縮小 `j` 的起點

較小值放在 `i`，較大值放在 `j`：

```c
for (i = 1; i <= 30 / 2; i++) {
    for (j = 30 / 2; j <= 30; j++) {
        if (i + j == 30 && i * j == 221) {
            printf("%d, %d\n", i, j);
        }
    }
}
```

候選組合數量比完整 `30 × 30` 更少。

### 36. 方法三：用和的方程式算出 `j`

<!-- lesson-image: C_Lesson_10_img27_double_to_single_loop_search.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img27_double_to_single_loop_search.png"
       alt="C 語言教材圖解：double to single loop search"
       width="700">
</p>

已知：

```text
i + j = 30
```

因此：

```c
j = 30 - i;
```

只需要搜尋 `i`：

```c
#include <stdio.h>

int main(void) {
    int i;

    for (i = 1; i <= 30 / 2; i++) {
        int j = 30 - i;

        if (i * j == 221) {
            printf("%d, %d\n", i, j);
        }
    }

    return 0;
}
```

輸出：

```text
13, 17
```

這是從雙層搜尋簡化成單層搜尋。

## Section V-I. 容易搞混的重點

### 1. 外層不是永遠代表列

在圖形中，外層通常代表列。

在整數解搜尋中，外層可能代表第一個未知數。

變數角色由問題決定。

---

### 2. 內層完成後才回到外層

外層的 `i` 不會在內層每一輪都增加。

只有內層完整結束後，外層才執行自己的迴圈式。

---

### 3. `j` 的最後值不會直接帶進下一列

因為內層初始式：

```c
j = 1
```

每次進入內層都會重新執行。

---

### 4. 圖形的「空白」不是沒有工作

靠右圖形需要輸出前導空白。

空心圖形需要輸出內部空白。

不輸出空白會改變位置。

---

### 5. `i >= j` 與 `i <= j` 會產生不同區域

<!-- lesson-image: C_Lesson_10_img23_coordinate_conditions_and_shapes.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img23_coordinate_conditions_and_shapes.png"
       alt="C 語言教材圖解：coordinate conditions and shapes"
       width="760">
</p>

- `i >= j`：主對角線及左下方
- `i <= j`：主對角線及右上方

寫條件前應先在座標表上標記。

---

### 6. `i + j == n + 1` 是另一條斜線

`i == j` 是左上到右下。

`i + j == n + 1` 是右上到左下。

---

### 7. 空心圖形不是把實心圖形中的星號隨機刪掉

要保留的通常是明確邊界：

```text
第一列
最後一列
第一欄
最後一欄
斜邊
```

---

### 8. 分段繪圖與座標法都可能正確

分段法重視圖形結構。

座標法重視每個位置的判斷。

應選擇較容易描述及維護的方法。

---

### 9. 雙層枚舉能找到答案，不代表搜尋範圍最佳

先求正確，再使用已知條件減少候選，是更完整的解題過程。

---

### 10. 去除對稱重複前，要先確認順序是否重要

若 `(a, b)` 與 `(b, a)` 代表不同情況，就不能任意刪除。

本章的「兩個正整數」通常不重視順序。

</details>

<details>
<summary>查看答案</summary>


因為沒有換行，輸出會連在同一列。


### 題目 4：換行放錯位置

```c
}
```

<details>
<summary>查看答案</summary>

### 題目 5：座標條件

```c
for (i = 1; i <= 4; i++) {

        } else {
            printf(".");
```

```text
...*
```

<details>


### 題目 7：整數解搜尋

```c
for (i = 1; i <= 30; i++) {
    int j = 30 - i;

    if (i * j == 221) {
        printf("%d %d\n", i, j);
    }
}
```

<details>
<summary>查看答案</summary>

若沒有限制 `i <= 15`，會輸出：

```text
13 17
17 13
```

限制 `i <= 15` 後只留下 `13 17`。

</details>

---

### 題目 8：找出錯誤

```c
for (i = 1; i <= n; i++) {
    for (j = 1; j <= n; i++) {
        printf("*");
    }

    printf("\n");
}
```

<details>
<summary>查看答案</summary>

內層迴圈式錯誤地增加 `i`：

```c
i++
```

應該是：

```c
j++
```

否則 `j` 不改變，外層變數卻被內層修改。

</details>

## Section IX. 做題時可以使用的提示

### 1. 圖形題先填寫兩個問題

```text
總共有幾列？
每一列有幾個位置？
```

這通常直接對應外層與內層。

---

### 2. 先用小尺寸手畫

推薦：

```text
N = 3
N = 5
```

小尺寸容易看出第一列、中間列、最後一列與斜邊。

---

### 3. 把每個位置改印座標

還不知道條件時，先輸出：

```c
printf("(%d,%d)", i, j);
```

再在紙上圈出應該是星號的位置。

---

### 4. 邊界條件分開寫，再用 `||` 合併

例如空心三角形：

```text
左邊：j == 1
斜邊：i == j
底邊：i == n
```

最後合併：

```c
j == 1 || i == j || i == n
```

---

### 5. 實心圖形找「區域不等式」

例如：

```text
左下區域：i >= j
靠右區域：i + j >= n + 1
```

---

### 6. 搜尋題先寫最直觀版本

先完整枚舉，確認答案正確。

接著再問：

1. 有沒有對稱重複？
2. 哪些範圍不可能？
3. 能否由一條方程式算出另一個變數？

---

### 7. 檢查迴圈式是否更新正確變數

外層：

```c
i++
```

內層：

```c
j++
```

是最常見的結構。

---

### 8. 懷疑輸出形狀錯誤時，檢查換行

換行通常應：

```c
在內層結束後
在外層本體內
```

## Section XI. 重點複習

1. 巢狀迴圈是一個迴圈包含另一個迴圈。
2. 外層每執行一輪，內層通常完整執行一次。
3. 外層常控制列，內層常控制欄。
4. 每個外層值會與所有合法內層值形成組合。
5. 固定 `a` 次外層與 `b` 次內層，內層本體通常執行 `a × b` 次。
6. 內層初始式會在每次重新進入時再次執行。
7. 換行通常放在內層結束後。
8. 九九乘法表可用外層控制被乘數、內層控制乘數。
9. `N × N` 正方形會處理 `N²` 個位置。
10. 長方形的列數與欄數可以分開控制。
11. 空心圖形只輸出邊界。
12. 空心正方形邊界是第一／最後列與第一／最後欄。
13. 第 `i` 列印 `i` 個星號可形成左下實心三角形。
14. `i == j` 表示主對角線。
15. `i >= j` 表示主對角線及左下區域。
16. `i + j == n + 1` 表示另一條對角線。
17. `i + j >= n + 1` 可形成靠右實心三角形。
18. 多條邊界使用 `||` 合併。
19. 座標法會逐一判斷每個 `(i, j)`。
20. 雙層枚舉可以搜尋兩個未知數的所有組合。
21. 對稱問題可能產生順序相反的重複答案。
22. 限制範圍可以去除重複並減少檢查。
23. 已知一個方程式時，可以用它算出另一個未知數。
24. 將雙層搜尋化成單層搜尋，是重要的優化思考。
25. 下一章會把迴圈應用到因數、質數與其他數學問題。

## Section XII. 常見錯誤提醒

<!-- lesson-image: C_Lesson_10_img30_common_nested_loop_errors.png -->
<p align="center">
  <img src="images/lesson_10/C_Lesson_10_img30_common_nested_loop_errors.png"
       alt="C 語言教材圖解：common nested loop errors"
       width="700">
</p>

### 錯誤 1：外層與內層使用相同變數

錯誤：

```c
for (i = 1; i <= n; i++) {
    for (i = 1; i <= n; i++) {
        ...
    }
}
```

---

### 錯誤 2：內層更新外層變數

錯誤：

```c
for (j = 1; j <= n; i++)
```

應為：

```c
j++
```

---

### 錯誤 3：換行放進內層

錯誤：

```c
printf("*\n");
```

正方形會變成每個星號一列。

---

### 錯誤 4：忘記每列換行

若完全沒有：

```c
printf("\n");
```

所有列會連成一條長線。

---

### 錯誤 5：三角形內層永遠跑到 `N`

若只輸出星號而不輸出空白：

```c
for (j = 1; j <= n; j++) {
    printf("*");
}
```

每一列都會一樣長，形成正方形。

---

### 錯誤 6：空心圖形內部仍印星號

空心圖形的非邊界位置應輸出空白：

```c
else {
    printf(" ");
}
```

---

### 錯誤 7：空心正方形使用 `&&`

錯誤：

```c
i == 1 && i == n && j == 1 && j == n
```

應使用 `||` 連接各條邊。

---

### 錯誤 8：斜線條件寫反

主對角線：

```c
i == j
```

另一條對角線：

```c
i + j == n + 1
```

兩者不能互換。

---

### 錯誤 9：靠右圖形沒有輸出前導空白

若只輸出星號，不處理空白，圖形會靠左。

---

### 錯誤 10：完整枚舉的範圍從 `0` 開始

題目要求正整數時，`0` 不屬於候選。

---

### 錯誤 11：把對稱答案誤認成兩組不同數字

```text
13, 17
17, 13
```

若順序不重要，它們代表同一組數。

---

### 錯誤 12：推導出 `j = 30 - i` 後仍使用第二層迴圈

既然 `j` 已由 `i` 決定，就不需要再枚舉所有 `j`。

---

### 錯誤 13：用 `break` 只離開內層，卻以為全部結束

巢狀結構中的 `break` 只影響最近的一層迴圈。

---

### 錯誤 14：只測試 `N = 5`

應至少再測：

```text
N = 1
N = 2
N = 3
```

小尺寸能暴露空心圖形與 `N - 2` 的邊界問題。

## Section XIII. Mermaid 流程圖

### 1. 巢狀迴圈的基本流程

```mermaid
flowchart TD
    A[初始化外層 i] --> B{外層條件成立嗎}
    B -- 否 --> H[離開全部迴圈]
    B -- 是 --> C[初始化內層 j]
    C --> D{內層條件成立嗎}
    D -- 是 --> E[執行內層本體]
    E --> F[更新 j]
    F --> D
    D -- 否 --> G[更新 i]
    G --> B
```

---

### 2. 正方形輸出

```mermaid
flowchart TD
    A[進入第 i 列] --> B[令 j 從 1 開始]
    B --> C{j 小於等於 N}
    C -- 是 --> D[輸出一個星號]
    D --> E[j 加 1]
    E --> C
    C -- 否 --> F[輸出換行]
    F --> G[進入下一列]
```

---

### 3. 空心正方形座標判斷

```mermaid
flowchart TD
    A[取得位置 i j] --> B{在第一或最後列}
    B -- 是 --> C[輸出星號]
    B -- 否 --> D{在第一或最後欄}
    D -- 是 --> C
    D -- 否 --> E[輸出空白]
```

---

### 4. 左下實心三角形

```mermaid
flowchart TD
    A[取得位置 i j] --> B{i 大於等於 j}
    B -- 是 --> C[輸出星號]
    B -- 否 --> D[輸出空白]
```

---

### 5. 空心三角形

```mermaid
flowchart TD
    A[取得位置 i j] --> B{j 等於 1}
    B -- 是 --> F[輸出星號]
    B -- 否 --> C{i 等於 j}
    C -- 是 --> F
    C -- 否 --> D{i 等於 N}
    D -- 是 --> F
    D -- 否 --> E[輸出空白]
```

---

### 6. 雙層枚舉整數解

```mermaid
flowchart TD
    A[i 從 1 開始] --> B[j 從 1 開始]
    B --> C{和為 30 且積為 221}
    C -- 是 --> D[輸出 i 和 j]
    C -- 否 --> E[測試下一個 j]
    D --> E
    E --> F{j 範圍結束}
    F -- 否 --> C
    F -- 是 --> G[測試下一個 i]
```

---

### 7. 單層化搜尋

```mermaid
flowchart TD
    A[i 從 1 到 15] --> B[j 設為 30 減 i]
    B --> C{i 乘 j 等於 221}
    C -- 是 --> D[輸出答案]
    C -- 否 --> E[測試下一個 i]
    D --> E
```
