# Lesson 21：Structures 結構

> 這堂課的重點：使用 `struct` 將姓名、學號、成績等不同型態但屬於同一筆資料的內容組合成一個完整物件，並學會宣告結構型態、建立結構變數、使用 `.` 存取成員、初始化與複製結構、將結構傳入函式及從函式回傳結構。最後會使用結構陣列完成學生資料的搜尋、統計與排序。

> 本章依一般 C17 語言知識獨立編寫，未使用 FEIS 第 22 章投影片。

## Section II. 今天的學習方式

1. 先選一筆熟悉的資料，例如學生：
   ```text
   學號
   姓名
   成績
   ```
2. 為每一項資料決定型態。
3. 將屬於同一位學生的欄位畫在同一個方框內。
4. 將方框命名為：
   ```c
   struct Student
   ```
5. 先宣告型態，再建立變數。
6. 每次看到：
   ```c
   student.score
   ```
   都讀成：
   ```text
   student 這筆資料中的 score 成員
   ```
7. 初始化時，在成員宣告旁標出第幾個初始化值。
8. 使用指定初始化時，檢查成員名稱是否拼寫正確。
9. 結構中有字元陣列時，另外畫出它內部的字元格子與 `'\0'`。
10. 比較：
    ```c
    second = first;
    ```
    對結構與陣列的不同結果。
11. 函式參數練習中，分別畫出：
    - 呼叫端原結構
    - 函式內參數副本
12. 結構陣列中，同時追蹤：
    - 陣列索引
    - 結構成員
13. 排序時直接交換完整結構，不要逐欄位交換。
14. 巢狀結構先從外層成員開始，再進入內層成員。
15. `typedef` 只改變型態名稱的寫法，不會建立新資料。
16. 使用 `sizeof()` 時，只觀察結果，不背誦固定大小。
17. 所有完整且應合法的 C 程式都使用嚴格 C17 選項編譯。

## Section IV. 寫題目前的提醒

### 1. 結構是型態，不是單一固定變數

```c
struct Student {
    int id;
    char name[20];
    int score;
};
```

這段宣告建立一種新的結構型態：

```text
struct Student
```

它還沒有建立名為 `student` 的變數。

---

### 2. 結構型態宣告後要加分號

正確：

```c
struct Student {
    int id;
    int score;
};
```

錯誤：

```c
struct Student {
    int id;
    int score;
}   /* 缺少分號 */
```

---

### 3. 成員宣告不能直接使用一般執行述句

結構型態內放的是成員宣告：

```c
struct Student {
    int id;
    int score;
};
```

不能在其中寫：

```c
score = 100;
printf("...");
```

初始值要在建立變數時提供，或在程式執行時賦值。

---

### 4. 建立變數時必須寫完整型態名稱

未使用 `typedef` 前：

```c
struct Student student;
```

不是：

```c
Student student;   /* 尚未建立 typedef 時錯誤 */
```

---

### 5. 使用 `.` 存取成員

```c
student.id = 1001;
student.score = 95;
```

左邊：

```text
student
```

是結構變數。

右邊：

```text
id、score
```

是成員名稱。

---

### 6. 成員名稱必須存在於該結構型態

錯誤：

```c
student.grade = 95;
```

如果結構中沒有 `grade` 成員，便無法編譯。

---

### 7. 初始化清單依成員宣告順序對應

```c
struct Student {
    int id;
    char name[20];
    int score;
};

struct Student student = {
    1001,
    "Amy",
    95
};
```

對應：

```text
id    ← 1001
name  ← "Amy"
score ← 95
```

---

### 8. 改變成員順序可能改變一般初始化的意義

如果型態改成：

```c
struct Student {
    int score;
    int id;
    char name[20];
};
```

原本的初始化清單便不再正確對應。

指定初始化可以降低這種風險。

---

### 9. 指定初始化可改變書寫順序

```c
struct Student student = {
    .score = 95,
    .id = 1001,
    .name = "Amy"
};
```

編譯器依成員名稱放入資料，而不是依書寫順序猜測。

---

### 10. 未指定成員會初始化為零

```c
struct Student student = {
    .id = 1001
};
```

其餘成員：

- `name` 的字元全部為 `0`
- `score` 為 `0`

---

### 11. 字元陣列成員不能在建立後使用 `=` 指定字串

錯誤：

```c
struct Student student;

student.name = "Amy";
```

`name` 是陣列，陣列不能整體賦值。

---

### 12. 字元陣列成員可以在結構初始化時設定

```c
struct Student student = {
    1001,
    "Amy",
    95
};
```

這屬於初始化，不是執行期的陣列賦值。

---

### 13. 修改字元陣列成員時要確保容量與 `'\0'`

可以使用：

```c
snprintf(
    student.name,
    sizeof(student.name),
    "%s",
    "Amy"
);
```

這個寫法會依目標容量限制輸出。

---

### 14. 結構可以整體賦值

```c
struct Student first = {
    1001, "Amy", 95
};

struct Student second;

second = first;
```

所有成員都會被複製，包括陣列成員的每個元素。

---

### 15. 結構賦值後兩個變數彼此獨立

```c
second.score = 60;
```

不會改變：

```c
first.score
```

---

### 16. 只有相同或相容結構型態才能直接賦值

即使兩個不同標籤的結構擁有相同成員，它們仍是不同型態。

```c
struct A {
    int value;
};

struct B {
    int value;
};
```

不能直接假設：

```c
a = b;
```

合法。

---

### 17. C 不支援完整結構的 `==`

錯誤：

```c
if (first == second) {
}
```

必須自行決定哪些成員代表相等，並逐成員比較。

---

### 18. 字串成員比較不能使用 `==`

即使逐成員比較：

```c
first.name == second.name
```

也不是比較文字內容。

字串內容比較可使用：

```c
strcmp(first.name, second.name)
```

需要：

```c
#include <string.h>
```

---

### 19. 結構傳入函式時預設會複製整個物件

```c
void lower_score(struct Student student) {
    student.score = 0;
}
```

函式修改的是參數副本，不是呼叫端原物件。

---

### 20. 函式可以回傳結構

```c
struct Student add_bonus(
    struct Student student,
    int bonus
) {
    student.score += bonus;
    return student;
}
```

呼叫端可以接回新結構：

```c
student = add_bonus(student, 5);
```

---

### 21. 結構陣列的每個元素都是完整結構

```c
struct Student students[3];
```

合法元素：

```text
students[0]
students[1]
students[2]
```

每個元素都有自己的：

```text
id、name、score
```

---

### 22. 存取結構陣列成員需要兩個階段

```c
students[i].score
```

先選擇：

```c
students[i]
```

再選擇：

```text
score
```

---

### 23. 結構陣列排序時應交換完整結構

```c
struct Student temporary = students[j];
students[j] = students[j + 1];
students[j + 1] = temporary;
```

這會讓學號、姓名與成績保持同一筆資料。

---

### 24. 使用平行陣列排序容易漏掉同步交換

例如：

```c
int ids[3];
char names[3][20];
int scores[3];
```

交換成績時，如果忘記同步交換姓名或學號，資料關係會被破壞。

結構陣列可避免這類錯誤。

---

### 25. 巢狀結構使用多個 `.`

```c
student.birthday.year
```

讀成：

```text
student 的 birthday 成員中的 year 成員
```

---

### 26. `typedef` 不會建立變數

```c
typedef struct Student Student;
```

只建立型態別名：

```text
Student
```

之後仍要：

```c
Student student;
```

才會建立變數。

---

### 27. 結構大小可能大於成員大小總和

```c
struct Example {
    char code;
    int value;
};
```

編譯器可能在 `code` 與 `value` 之間加入 padding。

因此不要假設：

```text
sizeof(struct Example)
==
sizeof(char) + sizeof(int)
```

---

### 28. 成員排列可能影響結構大小

這屬於記憶體配置與對齊問題。

本章只要求：

- 使用 `sizeof()` 查詢
- 不依賴手算結果
- 不自行把結構當成緊密排列的位元組資料

## Section V. 核心概念說明

## Section V-A. 為什麼需要結構？

### 1. 一筆學生資料

一位學生可能具有：

```text
學號：1001
姓名：Amy
成績：95
```

三項資料型態不同：

```c
int id;
char name[20];
int score;
```

它們在概念上屬於同一位學生。

---

### 2. 只使用獨立變數

```c
int student1_id;
char student1_name[20];
int student1_score;

int student2_id;
char student2_name[20];
int student2_score;
```

學生數量增加後，變數名稱大量重複。

---

### 3. 使用平行陣列

```c
int ids[30];
char names[30][20];
int scores[30];
```

這比大量獨立變數好，但同一位學生的資料分散在三個陣列中。

必須一直記住：

```text
ids[i]
names[i]
scores[i]
```

三者才是同一筆記錄。

---

### 4. 使用結構

```c
struct Student {
    int id;
    char name[20];
    int score;
};
```

一筆資料可以寫成：

```c
struct Student student;
```

同一位學生的相關內容集中在一個物件中。

### 8. 完整成員賦值與輸出

```c
#include <stdio.h>

struct Student {
    int id;
    char name[20];
    int score;
};

int main(void) {
    struct Student student = {0};

    student.id = 1001;
    student.score = 95;

    snprintf(
        student.name,
        sizeof(student.name),
        "%s",
        "Amy"
    );

    printf("ID: %d\n", student.id);
    printf("Name: %s\n", student.name);
    printf("Score: %d\n", student.score);

    return 0;
}
```

```c
struct Student {

        student.id,
```


指定初始化可讓讀者直接看出每個值屬於哪個成員。

### 19. 自行定義相等條件

```c
    int id;
    char name[20];
    int score;
};

    struct Student first,
    struct Student second
) {

        strcmp(first.name, second.name) == 0 &&
```

## Section V-K. 搜尋結構陣列

### 29. 依學號搜尋

```c
#include <stdio.h>

struct Student {
    int id;
    char name[20];
    int score;

int find_student_index(
    struct Student students[],
    int length,
    int target_id
) {
    int i;

    for (i = 0; i < length; i++) {
        if (students[i].id == target_id) {
            return i;
        }
    }

    return -1;

        {1002, "Bob", 82},

    }

    return 0;
}
```

## Section V-L. 找出最高分學生

### 31. 回傳完整結構

```c
#include <stdio.h>

struct Student {
    int id;
    char name[20];
    int score;
};

struct Student highest_student(
    struct Student students[],
    int length
) {
    int i;
    struct Student highest = students[0];

    for (i = 1; i < length; i++) {
        if (students[i].score > highest.score) {
            highest = students[i];
        }
    }

    return highest;
}

int main(void) {
    struct Student students[3] = {
        {1001, "Amy", 95},
        {1002, "Bob", 82},
        {1003, "Cathy", 91}
    };
    struct Student highest =
        highest_student(students, 3);

    printf(
        "%s %d\n",
        highest.name,
        highest.score
    );

    return 0;
}
```

來源陣列至少要有一個元素：

```text
length >= 1
```

因為函式使用：

```c

```

初始化答案。

## Section V-M. 排序結構陣列

### 33. 依成績由高到低排序

```c
#include <stdio.h>

struct Student {
    int id;
    char name[20];
    int score;
};

void sort_by_score_descending(
    struct Student students[],
    int length
) {
    int i;
    int j;

    for (i = 0; i < length - 1; i++) {
        for (j = 0; j < length - i - 1; j++) {
            if (
                students[j].score <
                students[j + 1].score
            ) {
                struct Student temporary =
                    students[j];

                students[j] = students[j + 1];
                students[j + 1] = temporary;
            }
        }
    }
}

int main(void) {
    int i;
    struct Student students[4] = {
        {1001, "Amy", 95},
        {1002, "Bob", 82},
        {1003, "Cathy", 91},
        {1004, "David", 88}
    };

    sort_by_score_descending(students, 4);

    for (i = 0; i < 4; i++) {
        printf(
            "%d %s %d\n",
            students[i].id,
            students[i].name,
            students[i].score
        );
    }

    return 0;
}
```


姓名與學號便不再和成績對應。

交換完整結構可保持每筆資料完整。

### 45. 為什麼可能比成員總和大？

### 47. `struct Student` 是型態，`student` 是變數

結構參數：

```text
完整物件副本
```

陣列參數：

```text
第一個元素的位置資訊
```

因此兩者在函式內修改時有不同結果。

```text
point.x
```

仍為 `1`。

</details>

---

### 題目 5：回傳結構

```c
struct Point move_right(
    struct Point point
) {
    point.x++;
    return point;
}
```

呼叫：

```c
point = move_right(point);
```

<details>
<summary>查看答案</summary>

`point.x` 增加 `1`。

</details>

---

### 題目 6：結構陣列

```c
struct Point points[3] = {
    {1, 2},
    {3, 4},
    {5, 6}
};
```

`points[1].x` 是多少？

<details>
<summary>查看答案</summary>

```text
3
```

</details>

---

### 題目 7：巢狀結構

```c
student.birthday.month = 8;
```

<details>
<summary>查看答案</summary>

將 `student` 的生日月份成員設為 `8`。

</details>

---

### 題目 8：排序交換

```c
struct Student temporary = students[0];
students[0] = students[1];
students[1] = temporary;
```

<details>
<summary>查看答案</summary>

第一筆與第二筆完整學生資料交換，包括所有成員。

</details>

### 題目 9：`typedef`

```c
typedef struct {
    int value;
} Number;

Number number = {5};
```

<details>
<summary>查看答案</summary>

`Number` 是型態別名，`number.value` 為 `5`。

</details>

---

### 題目 10：錯誤比較

```c
if (first == second) {
}
```

其中兩者都是結構。

<details>
<summary>查看答案</summary>

C 不支援完整結構的 `==` 比較，必須逐成員比較。

</details>

## Section XI. 重點複習

1. 結構可以組合不同型態的相關資料。
2. `struct` 用來宣告結構型態。
3. 結構內的欄位稱為成員。
4. 結構型態宣告結尾需要分號。
5. `struct Student` 是型態名稱的一部分。
6. 建立變數時可寫 `struct Student student;`。
7. 使用 `.` 存取結構變數成員。
8. 成員名稱必須存在於該型態。
9. 一般初始化依成員宣告順序對應。
10. 指定初始化使用 `.member = value`。
11. 未指定的剩餘成員會初始化為零。
12. 字元陣列可以作為結構成員。
13. 字元陣列成員不能在建立後使用整體賦值。
14. 可在結構初始化時設定字元陣列成員。
15. 可使用具容量限制的方法修改字串成員。
16. 同型態結構可以使用 `=` 整體複製。
17. 結構整體複製包含陣列成員。
18. 複製後兩個結構變數彼此獨立。
19. C 不支援使用 `==` 比較完整結構。
20. 結構相等規則必須由程式逐成員定義。
21. 字串成員內容比較可使用 `strcmp()`。
22. 結構作為普通函式參數時以值傳遞。
23. 函式內修改參數副本不會改變呼叫端。
24. 函式可以回傳完整結構。
25. 可以傳入結構並回傳修改後副本。
26. 結構陣列的每個元素都是完整記錄。
27. `students[i].score` 同時使用索引與成員存取。
28. 結構陣列可以使用迴圈搜尋與統計。
29. 找最高分時可以保存完整學生結構。
30. 排序時應交換完整結構。
31. 結構可避免平行陣列不同步。
32. 結構成員可以是另一個結構。
33. 巢狀成員可使用多個 `.` 存取。
34. `typedef` 可以為結構型態建立較短名稱。
35. `typedef` 不會建立資料物件。
36. 結構大小可能包含 padding。
37. 應使用 `sizeof()` 查詢實際大小。
38. 不應假設不同平台的結構記憶體配置相同。
39. 下一章將開始學習指標與物件位址。

## Section XII. 常見錯誤提醒

### 錯誤 1：結構型態宣告後漏掉分號

```c
struct Student {
    int id;
}
```

---

### 錯誤 2：未使用 `struct` 或 `typedef`

```c
Student student;
```

如果尚未建立 `Student` 別名，會編譯失敗。

---

### 錯誤 3：使用不存在的成員

```c
student.grade
```

但型態中只有 `score`。

---

### 錯誤 4：一般初始化順序與成員順序不一致

可能將學號放入成績、成績放入學號。

---

### 錯誤 5：字串成員使用整體賦值

```c
student.name = "Amy";
```

---

### 錯誤 6：複製字串成員時忽略容量

可能造成緩衝區溢位或缺少 `'\0'`。

---

### 錯誤 7：以為結構不能整體賦值

結構與陣列不同，結構可以：

```c
second = first;
```

---

### 錯誤 8：使用 `==` 比較完整結構

C 不支援。

---

### 錯誤 9：使用 `==` 比較字串成員內容

應使用 `strcmp()`。

---

### 錯誤 10：函式內修改結構參數，卻期待原物件改變

普通結構參數是副本。

---

### 錯誤 11：回傳新結構後沒有接住結果

```c
add_bonus(student, 5);
```

若函式以值回傳，應：

```c
student = add_bonus(student, 5);
```

---

### 錯誤 12：結構陣列存取漏掉索引

```c
students.score
```

`students` 是陣列，應先選擇元素：

```c
students[i].score
```

---

### 錯誤 13：排序時只交換成績

會破壞姓名、學號與成績的對應。

---

### 錯誤 14：巢狀結構少寫一層成員

```c
student.year
```

如果 `year` 位於 `birthday` 中，應寫：

```c
student.birthday.year
```

---

### 錯誤 15：認為 `typedef` 會配置記憶體

它只建立型態名稱。

---

### 錯誤 16：手算結構大小並假設所有平台相同

可能忽略 padding 與對齊規則。
