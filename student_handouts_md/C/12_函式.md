## Section IV. 寫題目前的提醒

### 1. 函式定義不能寫在另一個函式裡面

錯誤：

```c
int main(void) {
    int add3(int x) {
        return x + 3;
    }

    return 0;
}
```

標準 C 不允許在 `main()` 裡面再定義一般函式。

正確：

```c
int add3(int x) {
    return x + 3;
}

int main(void) {
    return 0;
}
```

---

### 2. 函式呼叫與函式定義外觀不同

定義：

```c
int add3(int x) {
    return x + 3;
}
```

呼叫：

```c
add3(4)
```

呼叫時不重複寫回傳型態與參數型態。

---

### 3. 參數與引數不是同一個概念

<p align="center">
  <img
    src="images/lesson_12/C_Lesson_12_img03_parameter_vs_argument.png"
    alt="Parameter 與 Argument"
    width="700">
</p>


```c
int add3(int x) {
    return x + 3;
}

int result = add3(4);
```

- `x`：形式參數
- `4`：引數

呼叫時，`4` 的值會交給參數 `x`。

---

### 4. 引數可以是表示式

```c
int foo = 2;
double answer = half(foo * 2);
```

程式先計算：

```c
foo * 2
```

得到 `4`，再將 `4` 傳給 `half()`。

---

### 5. 引數數量要和參數數量相符

函式：

```c
int max2(int a, int b);
```

正確：

```c
max2(3, 5)
```

錯誤：

```c
max2(3)
max2(3, 5, 7)
```

---

### 6. 參數型態與引數型態應相容

```c
double half(double x);
```

呼叫：

```c
half(4)
```

整數 `4` 可以轉換成 `double` 的 `4.0`。

但型態轉換可能造成資訊改變，因此不能完全忽略型態。

---

### 7. 有回傳值的函式要提供合適的 `return`

```c
int max2(int a, int b) {
    if (a >= b) {
        return a;
    }

    return b;
}
```

每一條可能執行路徑都應回傳一個 `int`。

---

### 8. `return` 會立即結束目前函式

<p align="center">
  <img
    src="images/lesson_12/C_Lesson_12_img05_return_flow.png"
    alt="return 如何立即結束函式"
    width="700">
</p>


```c
int max2(int a, int b) {
    if (a >= b) {
        return a;
        printf("This line will not run.\n");
    }

    return b;
}
```

`return a;` 執行後，後面的 `printf()` 不會執行。

---

### 9. `void` 函式不能回傳一般數值

正確：

```c
void print_stars(int n) {
    ...
    return;
}
```

也可以省略最後的：

```c
return;
```

錯誤：

```c
void print_stars(int n) {
    return n;
}
```

---

### 10. 函式在呼叫前必須先讓編譯器知道

方法一：把完整定義放在 `main()` 前面。

```c
int max2(int a, int b) {
    ...
}

int main(void) {
    printf("%d\n", max2(3, 5));
}
```

方法二：先寫函式原型。

```c
int max2(int, int);

int main(void) {
    printf("%d\n", max2(3, 5));
}

int max2(int a, int b) {
    ...
}
```

---

### 11. 函式原型以分號結束

```c
int max2(int, int);
```

函式定義則有本體：

```c
int max2(int a, int b) {
    ...
}
```

---

### 12. 原型中的參數名稱可以省略

以下兩個宣告都表示相同介面：

```c
int max2(int a, int b);
```

```c
int max2(int, int);
```

在函式定義中則需要名稱，才能在本體內使用參數。

---

### 13. 原型、定義與呼叫的型態要一致

錯誤：

```c
double max2(int, int);

int max2(int a, int b) {
    ...
}
```

宣告說回傳 `double`，定義卻回傳 `int`，介面不一致。

---

### 14. `#include` 不是把整個函式實作貼進程式

```c
#include <math.h>
```

主要讓編譯器取得相關宣告與定義。

標準函式的實作通常由函式庫提供，最後由連結步驟組合進程式。

---

### 15. 使用 `sqrt()` 要包含 `<math.h>`

```c
#include <math.h>

double root = sqrt(9.0);
```

在部分系統使用 GCC 編譯時，連結數學函式庫可能需要：

```bash
gcc program.c -o program -lm
```

---

### 16. `sqrt()` 的回傳型態是 `double`

```c
double sqrt(double x);
```

因此應使用：

```c
double root;
```

並以：

```c
%f
```

輸出。

---

### 17. `printf()` 也有回傳值

`printf()` 成功時，會回傳實際輸出的字元數量。

```c
int count = printf("Hello world!\n");
printf("%d\n", count);
```

來源範例中，第一個 `printf()` 的回傳值會再被第二個 `printf()` 輸出。

---

### 18. 同一區塊不能重複宣告同名變數

錯誤：

```c
int main(void) {
    int i;
    int i;

    return 0;
}
```

---

### 19. 不同區塊可以出現同名變數

```c
int main(void) {
    int i = 2;

    {
        int i = 3;
        printf("%d\n", i);
    }

    printf("%d\n", i);

    return 0;
}
```

內層的 `i` 與外層的 `i` 是不同變數。

---

### 20. 內層名稱會優先於外層同名名稱

```c
int i = 1;

int main(void) {
    int i = 2;

    {
        int i = 3;
        printf("%d\n", i);
    }

    return 0;
}
```

最內層輸出的值是 `3`。

---

### 21. 區域變數不會自動修改呼叫端變數

<p align="center">
  <img
    src="images/lesson_12/C_Lesson_12_img12_pass_by_value.png"
    alt="傳值與呼叫端變數"
    width="700">
</p>


```c
int max2(int a, int b) {
    a = 100;

    if (a >= b) {
        return a;
    }

    return b;
}
```

函式內的 `a` 是形式參數的區域變數。

在目前學過的「傳值」呼叫中，修改它不會直接改變呼叫端原本的變數。

指標參數會在後面的章節再學習。

---

### 22. `main()` 不應知道函式內部所有細節

```c
printf("%d\n", max2(a, b));
```

呼叫端只需要知道：

- 函式名稱
- 需要哪些引數
- 會回傳什麼型態

不需要在每次呼叫時重寫比較邏輯。

## Section V. 核心概念說明

## Section V-A. 函式是什麼？

<p align="center">
  <img
    src="images/lesson_12/C_Lesson_12_img01_function_input_process_output.png"
    alt="函式的 Input Process Return"
    width="700">
</p>


### 1. 從數學函數開始理解

數學中可以寫：

```text
f(x) = x + 3
```

例如：

```text
f(4) = 4 + 3 = 7
```

可以把它想成：

```text
輸入 x → 執行規則 → 產生結果
```

---

### 2. C 語言中的相似函式

```c
int add3(int x) {
    return x + 3;
}
```

對照：

| 數學概念 | C 函式 |
| --- | --- |
| 函數名稱 `f` | 函式名稱 `add3` |
| 輸入 `x` | 參數 `int x` |
| 規則 `x + 3` | 函式本體 |
| 函數值 | `return` 的結果 |

呼叫：

```c
add3(4)
```

結果為：

```text
7
```

---

### 3. 程式中的函式比數學函數更廣

程式函式除了計算並回傳數值，也可以：

- 顯示文字
- 讀取或輸出資料
- 修改函式內的區域狀態
- 呼叫其他函式
- 不回傳任何值

因此函式也可以被看成：

> 為特定工作整理的一組程式述句。

---

### 4. 為什麼需要函式？

沒有函式時，常見問題包括：

1. 同一段程式碼重複出現。
2. `main()` 過長，不容易閱讀。
3. 修改功能時要改很多地方。
4. 無法單獨測試某一項功能。
5. 程式意圖不清楚。

函式可以提供：

- 名稱
- 清楚介面
- 重複使用
- 問題拆分
- 局部測試

---

## Section V-B. 函式定義

### 5. 基本語法

```c
回傳型態 函式名稱(參數列) {
    函式本體;
    return 回傳值;
}
```

範例：

```c
int add3(int x) {
    return x + 3;
}
```

---

### 6. 定義的四個主要部分

<p align="center">
  <img
    src="images/lesson_12/C_Lesson_12_img02_function_definition_parts.png"
    alt="C 函式定義的四個主要部分"
    width="700">
</p>


```c
int add3(int x) {
    return x + 3;
}
```

| 部分 | 內容 | 意義 |
| --- | --- | --- |
| 回傳型態 | `int` | 呼叫結果是一個整數 |
| 函式名稱 | `add3` | 呼叫時使用的名稱 |
| 參數列 | `int x` | 接收一個整數 |
| 函式本體 | `{ ... }` | 實際執行的程式碼 |

---

### 7. 多個參數

```c
int max2(int a, int b) {
    if (a >= b) {
        return a;
    }

    return b;
}
```

參數之間使用逗號：

```c
int a, int b
```

函式可以接收多個參數，但一次呼叫只有一個回傳值。

---

### 8. 沒有參數的函式

```c
void print_title(void) {
    printf("C Functions\n");
}
```

`void` 參數列明確表示：

> 這個函式不接收引數。

---

### 9. 沒有回傳值的函式

<p align="center">
  <img
    src="images/lesson_12/C_Lesson_12_img11_void_vs_return_value.png"
    alt="void 與有回傳值函式"
    width="700">
</p>


```c
void print_title(void) {
    printf("C Functions\n");
}
```

前面的 `void` 表示：

> 這個函式不產生可以放入表示式的回傳值。

可以直接呼叫：

```c
print_title();
```

不應寫：

```c
int value = print_title();
```

## Section V-C. 函式呼叫

### 10. 呼叫語法

```c
函式名稱(引數列)
```

例如：

```c
add3(4)
max2(a, b)
sqrt(9.0)
```

---

### 11. 完整的自訂函式程式

```c
#include <stdio.h>

int add3(int x) {
    return x + 3;
}

int main(void) {
    printf("%d\n", add3(4));

    return 0;
}
```

輸出：

```text
7
```

---

### 12. 呼叫流程

<p align="center">
  <img
    src="images/lesson_12/C_Lesson_12_img04_function_call_flow.png"
    alt="完整函式呼叫流程"
    width="700">
</p>


呼叫：

```c
int result = add3(4);
```

概念流程：

1. 計算引數 `4`。
2. 將引數值交給參數 `x`。
3. 進入 `add3()`。
4. 計算 `x + 3`。
5. 執行 `return 7;`。
6. 回到呼叫位置。
7. 將 `7` 存入 `result`。

---

### 13. 引數為表示式

```c
int foo = 2;
double answer = half(foo * 2);
```

假設：

```c
double half(double x) {
    return x / 2.0;
}
```

執行概念：

1. 讀取 `foo`，值為 `2`。
2. 計算 `foo * 2`，得到整數 `4`。
3. 將 `4` 轉換成參數需要的 `double 4.0`。
4. 執行 `half(4.0)`。
5. 回傳 `2.0`。
6. 存入 `answer`。

---

### 14. 函式呼叫可以放在表示式中

```c
int result = add3(4) * 2;
```

先得到：

```text
add3(4) → 7
```

再計算：

```text
7 * 2 → 14
```

---

### 15. 函式呼叫可以作為另一個函式的引數

```c
int answer = max2(max2(a, b), c);
```

執行概念：

1. 先計算內層 `max2(a, b)`。
2. 將內層結果作為外層第一個引數。
3. 再比較該結果與 `c`。
4. 回傳三者最大值。

### 16. 為什麼需要函式宣告？

編譯器讀到：

```c
max2(a, b)
```

時，需要先知道：

- `max2` 是否存在
- 接收幾個參數
- 參數型態
- 回傳型態

如果完整定義在後面，可以先提供函式原型。

---

### 17. 原型範例

```c
int max2(int, int);
```

或：

```c
int max2(int a, int b);
```

兩者對呼叫端提供相同的型態資訊。

---

### 18. 定義放在 `main()` 後面

```c
#include <stdio.h>

int max2(int, int);

int main(void) {
    printf("%d\n", max2(3, 5));

    return 0;
}

int max2(int a, int b) {
    if (a >= b) {
        return a;
    }

    return b;
}
```

---

### 19. 宣告與定義的差異

宣告：

```c
int max2(int, int);
```

- 沒有函式本體
- 以分號結束
- 說明介面

定義：

```c
int max2(int a, int b) {
    ...
}
```

- 包含函式本體
- 實作真正功能

## Section V-E. C 標準函式庫與標頭檔

### 21. 什麼是 C 標準函式庫？

C 語言除了定義語法，也定義了一系列標準函式，提供常用功能，例如：

- 輸入與輸出
- 數學運算
- 字元處理
- 字串處理
- 記憶體管理
- 其他系統相關功能

不同編譯器通常會依 C 標準實作這些函式，但實際支援程度仍可能有差異。

### 22. 常見標頭檔

| 功能 | 標頭檔 | 範例 |
| --- | --- | --- |
| 輸入輸出 | `<stdio.h>` | `printf()`、`scanf()` |
| 數學 | `<math.h>` | `sqrt()`、`ceil()` |
| 一般工具 | `<stdlib.h>` | 轉換、記憶體與其他工具 |
| 字串 | `<string.h>` | 字串處理 |
| 字元分類 | `<ctype.h>` | 字元判斷與轉換 |

本章主要使用 `<stdio.h>` 與 `<math.h>`。

## Section V-F. 兩個整數的最大值函式

### 28. 原本全部寫在 `main()` 中

```c
#include <stdio.h>

int main(void) {
    int a;
    int b;
    int maximum;

    printf("Please enter the first integer: ");
    scanf("%d", &a);

    printf("Please enter the second integer: ");
    scanf("%d", &b);

    if (a >= b) {
        maximum = a;
    } else {
        maximum = b;
    }

    printf("The maximum is %d.\n", maximum);

    return 0;
}
```

比較邏輯可以整理成一個獨立功能。

---

### 29. 抽出 `max2()`

```c
int max2(int a, int b) {
    int maximum;

    if (a >= b) {
        maximum = a;
    } else {
        maximum = b;
    }

    return maximum;
}
```

---

### 30. 完整程式

```c
#include <stdio.h>

int max2(int, int);

int main(void) {
    int a;
    int b;

    printf("Please enter the first integer: ");
    scanf("%d", &a);

    printf("Please enter the second integer: ");
    scanf("%d", &b);

    printf("The maximum is %d.\n", max2(a, b));

    return 0;
}

int max2(int a, int b) {
    int maximum;

    if (a >= b) {
        maximum = a;
    } else {
        maximum = b;
    }

    return maximum;
}
```

---

### 31. 直接回傳可以更精簡

```c
int max2(int a, int b) {
    if (a >= b) {
        return a;
    }

    return b;
}
```

不需要額外的 `maximum`。

---

### 32. 參數名稱不必和呼叫端相同

呼叫端：

```c
int a;
int b;

max2(a, b);
```

定義可以寫：

```c
int max2(int x, int y) {
    if (x >= y) {
        return x;
    }

    return y;
}
```

甚至可以寫：

```c
int max2(int b, int a)
```

名稱只是函式內部使用的區域名稱。

真正重要的是：

- 引數順序
- 參數型態
- 函式內的邏輯

### 33. 使用固定測試呼叫

```c
printf("max2(3, 5) = %d\n", max2(3, 5));
printf("max2(5, 3) = %d\n", max2(5, 3));
printf("max2(4, 4) = %d\n", max2(4, 4));
printf("max2(-2, -7) = %d\n", max2(-2, -7));
```

這能獨立測試：

- 第一個較大
- 第二個較大
- 兩者相等
- 負數

## Section V-G. 名稱可視範圍 scope

### 34. 變數名稱依宣告位置分類

來源教材將名稱依宣告位置區分為：

1. 全域變數 global variable
2. 區域變數 local variable
3. 形式參數 formal parameter

---

### 35. 全域變數

```c
int i;

int main(void) {
    return 0;
}
```

`i` 宣告在所有函式之外。

全域名稱通常可以從宣告位置之後，被多個函式看見。

但全域變數容易造成：

- 名稱污染
- 不明確的資料依賴
- 不容易追蹤誰修改了資料

因此一般應避免不必要的全域變數。

---

### 36. 區域變數

```c
int main(void) {
    int i;

    return 0;
}
```

`i` 只屬於 `main()` 的區塊。

另一個函式不能直接使用這個 `i`。

---

### 37. 形式參數

```c
int add3(int x) {
    return x + 3;
}
```

`x` 是形式參數，也是一個屬於 `add3()` 的區域名稱。

函式外不能直接使用這個 `x`。

---

### 38. 區塊建立新的作用域

```c
int main(void) {
    int i = 2;

    {
        int j = 3;
        printf("%d\n", j);
    }

    return 0;
}
```

`j` 只在內層大括號中可見。

離開區塊後不能再使用 `j`。

---

### 39. 同一區塊不能有同名變數

```c
int main(void) {
    int i;
    int i;  /* 錯誤 */

    return 0;
}
```

同一個作用域內，一個名稱只能代表一個變數宣告。

---

### 40. 不同區塊可以同名

```c
int main(void) {
    int i = 2;

    {
        int i = 3;
        printf("%d\n", i);
    }

    printf("%d\n", i);

    return 0;
}
```

輸出：

```text
3
2
```

內層變數離開區塊後，外層 `i` 再次可見。

---

### 41. 作用域的優先順序

<p align="center">
  <img
    src="images/lesson_12/C_Lesson_12_img08_scope_shadowing.png"
    alt="Scope 與 Shadowing"
    width="700">
</p>


```c
#include <stdio.h>

int i = 1;

int main(void) {
    int i = 2;

    printf("%d\n", i);

    {
        int i = 3;
        printf("%d\n", i);
    }

    printf("%d\n", i);

    return 0;
}
```

輸出：

```text
2

```

在每個位置，程式使用最接近且仍可見的同名宣告。

---

### 42. 函式也有自己的區域

```c
int i = 5;

void change(void) {
    i = i + 1;
    printf("%d\n", i);
}

int main(void) {
    int i = 6;

    i = i + 1;
    change();
    printf("%d\n", i);

    return 0;
}
```

`main()` 的區域 `i` 會遮蔽全域 `i`。

`change()` 中沒有區域 `i`，因此會使用全域 `i`。

這種程式較難追蹤，也說明為什麼一般要小心全域變數。

## Section V-H. 三個整數的最大值函式

### 43. 直接寫 `max3()`

```c
int max3(int a, int b, int c) {
    int maximum = a;

    if (b > maximum) {
        maximum = b;

    if (c > maximum) {
        maximum = c;

}
```

### 44. 完整程式

```c

    int c;

    }

    }

    return maximum;
}
```

### 45. 重複利用 `max2()`

已有：

```c
int max2(int a, int b) {
    if (a >= b) {
        return a;
    }

    return b;
}
```

三數最大值可以寫成：

```c
int max3(int a, int b, int c) {
    return max2(max2(a, b), c);
}
```

- `max3()` 的意圖清楚
- `max2()` 已經測試過
- 修改兩數比較規則時，只改一個地方

## Section V-I. 使用函式繪製文字三角形

### 48. 原始三角形程式

```c
#include <stdio.h>

int main(void) {
    int n;
    int i;
    int j;

    printf("N = ");
    scanf("%d", &n);

    for (i = 1; i <= n; i++) {
        for (j = 1; j <= i; j++) {
            printf("*");
        }

        printf("\n");
    }

    return 0;
}
```

輸入 `5`：

```text
*
**
***
****
*****
```

---

### 49. 先抽出「印一列星號」

```c
void print_stars(int n) {
    int j;

    for (j = 1; j <= n; j++) {
        printf("*");
    }
}
```

這個函式：

- 接收星號數量
- 執行輸出
- 不需要回傳值

因此回傳型態是 `void`。

---

### 50. 在 `main()` 中使用 `print_stars()`

```c
#include <stdio.h>

void print_stars(int);

int main(void) {
    int n;
    int i;

    printf("N = ");
    scanf("%d", &n);

    for (i = 1; i <= n; i++) {
        print_stars(i);
        printf("\n");
    }

    return 0;
}

void print_stars(int n) {
    int j;

    for (j = 1; j <= n; j++) {
        printf("*");
    }
}
```

---

### 51. 再抽出整個三角形

```c
void print_triangle(int n) {
    int i;

    for (i = 1; i <= n; i++) {
        print_stars(i);
        printf("\n");
    }
}
```

---

### 52. 最後的模組化程式

```c
#include <stdio.h>

void print_stars(int);
void print_triangle(int);

int main(void) {
    int n;

    printf("N = ");
    scanf("%d", &n);

    print_triangle(n);

    return 0;
}

void print_triangle(int n) {
    int i;

    for (i = 1; i <= n; i++) {
        print_stars(i);
        printf("\n");
    }
}

void print_stars(int n) {
    int j;

    for (j = 1; j <= n; j++) {
        printf("*");
    }
}
```

現在 `main()` 只負責：

1. 讀取 `n`
2. 呼叫 `print_triangle(n)`

## Section V-J. 容易搞混的重點

### 54. 函式名稱後有括號不一定是定義

```c
max2(a, b)
```

是呼叫。

```c
int max2(int a, int b) {
    ...
}
```

才是定義。

---

### 55. 函式原型不是空函式

```c
int max2(int, int);
```

只是宣告介面，不代表函式沒有內容。

真正內容會出現在定義中。

---

### 56. `void` 有兩種常見位置

```c
void print_title(void)
```

第一個 `void`：

```text
不回傳值
```

小括號中的 `void`：

```text
不接收參數
```

---

### 57. 參數名稱只在函式內有意義

```c
int max2(int x, int y)
```

呼叫端不需要有 `x` 與 `y`。

---

### 58. 回傳值不一定要先存入變數

可以：

```c
int maximum = max2(a, b);
printf("%d\n", maximum);
```

也可以：

```c
printf("%d\n", max2(a, b));
```

---

### 59. 函式呼叫不是文字替換

呼叫時會建立參數、執行函式本體並取得回傳值。

不要把它只想成把程式碼複製到呼叫位置。

---

### 60. 作用域與變數生命週期不是完全相同概念

本章來源主要聚焦：

> 在哪個程式範圍可以使用某個名稱。

變數實際存在多久，會在後面的動態記憶體與生命週期內容再深化。

---

### 61. 全域變數方便，不代表應大量使用

全域變數能被多個函式看見，但也會讓函式依賴隱藏狀態。

能以參數傳入、以回傳值送回的資料，通常不必設為全域。

---

### 62. 函式拆得越多不一定越好

適合抽成函式的工作通常：

- 有明確名稱
- 可能重複使用
- 可以獨立測試
- 能讓主流程更清楚

只包含一個沒有意義、且不會重複的片段，不一定需要單獨成為函式。

```c
int max2(int a, int b) {
    if (a >= b) {
        return a;
    }

    return b;
}

int max3(int a, int b, int c) {
    return max2(max2(a, b), c);
}
```

呼叫：

```c
max3(-2, -7, -4)
```

<details>
<summary>查看答案</summary>

內層 `max2(-2, -7)` 回傳 `-2`。

外層 `max2(-2, -4)` 回傳 `-2`。

</details>

### 題目 7：`void` 函式

```c
void print_twice(char c) {
    printf("%c%c", c, c);
}

int main(void) {
    print_twice('A');
    printf("\n");

    return 0;
}
```

<details>
<summary>查看答案</summary>

```text
AA
```

</details>

### 題目 8：找出宣告問題

```c
int main(void) {
    printf("%d\n", max2(3, 5));

    return 0;
}

int max2(int a, int b) {
    if (a >= b) {
        return a;
    }

    return b;
}
```

<details>
<summary>查看答案</summary>

`main()` 呼叫 `max2()` 前沒有看見函式宣告。

可在前面加入：

```c
int max2(int, int);
```

或把完整定義移到 `main()` 前面。

</details>

## Section XI. 重點複習

1. 函式是具有名稱、可以被呼叫的程式模組。
2. 函式可以接收參數。
3. 一般 `return` 一次送回一個值。
4. 函式定義包含回傳型態、名稱、參數列及本體。
5. 呼叫函式時提供的是引數。
6. 函式定義中接收值的是形式參數。
7. 引數可以是常數、變數或表示式。
8. 呼叫時會先計算引數表示式。
9. 引數值會依參數型態進行必要轉換。
10. `return` 會結束目前函式並送回結果。
11. `void` 表示函式不回傳值。
12. 小括號中的 `void` 表示不接收參數。
13. 函式不能定義在另一個函式內。
14. 呼叫前必須先有可見的函式宣告。
15. 函式原型以分號結束。
16. 函式宣告與定義的介面必須一致。
17. 標頭檔保存函式宣告及相關定義。
18. C 標準函式庫提供常用功能。
19. `<stdio.h>` 提供輸入輸出相關宣告。
20. `<math.h>` 提供 `sqrt()` 等數學函式。
21. `printf()` 也有回傳值。
22. `max2()` 可以把比較邏輯從 `main()` 抽離。
23. 函式參數名稱不必和呼叫端變數名稱相同。
24. 全域變數宣告在函式外。
25. 區域變數宣告在函式或區塊內。
26. 形式參數屬於函式的區域名稱。
27. 同一作用域不能重複宣告同名變數。
28. 內層同名名稱會遮蔽外層名稱。
29. `max3()` 可以重複利用 `max2()`。
30. `print_triangle()` 可以重複利用 `print_stars()`。
31. 良好的函式拆分能讓 `main()` 更容易閱讀。
32. 下一章會學習函式呼叫自己，也就是遞迴。

## Section XII. 常見錯誤提醒

### 錯誤 1：在 `main()` 裡定義函式

標準 C 不允許一般巢狀函式定義。

---

### 錯誤 2：呼叫時寫出型態

錯誤：

```c
max2(int a, int b);
```

這是宣告形式，不是一般呼叫。

正確呼叫：

```c
max2(a, b);
```

---

### 錯誤 3：引數數量不符

函式接收兩個參數，呼叫時卻提供一個或三個引數。

---

### 錯誤 4：原型與定義型態不同

回傳型態、參數數量或參數型態不一致。

---

### 錯誤 5：忘記原型後的分號

錯誤：

```c
int max2(int, int)
```

正確：

```c
int max2(int, int);
```

---

### 錯誤 6：有回傳型態卻漏掉回傳值

```c
int f(int x) {
    printf("%d\n", x);
}
```

應在所有可能路徑提供適合的 `return`。

---

### 錯誤 7：`void` 函式回傳一般數值

```c
void f(void) {
    return 3;
}
```

---

### 錯誤 8：呼叫 `sqrt()` 卻沒有 `<math.h>`

```c
#include <math.h>
```

不可省略。

---

### 錯誤 9：以 `%d` 輸出 `sqrt()` 結果

`sqrt()` 回傳 `double`，應使用適合浮點數的格式。

---

### 錯誤 10：把宣告當成定義

```c
int max2(int, int);
```

沒有實際函式本體，程式仍需要某處提供定義。

---

### 錯誤 11：同一區塊重複宣告同名變數

```c
int i;
int i;
```

---

### 錯誤 12：以為內層修改的是外層同名變數

```c
int i = 2;

{
    int i = 3;
    i++;
}
```

內層只修改自己的 `i`。

---

### 錯誤 13：過度依賴全域變數

函式表面上沒有參數，卻偷偷讀寫全域狀態，會讓功能難以理解與測試。

---

### 錯誤 14：組合呼叫的括號錯誤

正確：

```c
max2(max2(a, b), c)
```

要確認內層呼叫的右括號位置。

---

### 錯誤 15：`print_stars()` 內每個星號都換行

錯誤：

```c
printf("*\n");
```

這會讓三角形變成垂直排列。

---

### 錯誤 16：`print_triangle()` 忘記每列換行

`print_stars(i)` 完成一列後仍要：

```c
printf("\n");
```

---

```mermaid

    A[呼叫端遇到函式呼叫] --> B[計算引數表示式]

    C --> D[執行函式本體]
    D --> E[執行 return 或到達 void 函式結尾]
    E --> F[回到原本呼叫位置]
```
